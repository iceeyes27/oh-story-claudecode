## 阅读理解摘要

- 谁：玛莎和埃德蒙。从“妈妈”这个称呼看，玛莎是埃德蒙的母亲。
- 在哪里：避风的屋檐下，周围有“来往的旅客”。具体是车站、街口还是别的公共场所，正文没交代。从“今天带你去对角巷”看，他们此刻还不在对角巷。
- 行动：玛莎替埃德蒙拢紧粗呢斗篷的领口，从内衬口袋拿出粗布旧袋，先把两枚金加隆倒进他掌心，又拿出一小卷用红棉线扎好的六张十镑纸币。她交代钱的用途，提醒柜子里的八个加隆是全家的救急钱，不准动，再把那卷英镑压进他手里，说这是她这个月多接了四件翻领大衣的针线活挣来的，今天带他去对角巷买齐缺的药草和羊皮纸。
- 结果和结尾状态：埃德蒙手里握着两枚加隆和六十英镑，答应“救急的钱不动”。八个加隆留在家中柜子里。
- 不确定处：
  1. “这是你下学期要补的耗材钱”里的“这”，指加隆、英镑还是全部，读不准。
  2. 两笔钱各自管什么不清楚：“下学期耗材”和“今天去对角巷买药草、羊皮纸”是同一件事还是两件事？今天的东西用哪笔钱买？
  3. “开学那趟置办齐整”说的是已经过去的采购，还是今天或以后的采购？所以“八个加隆”是现在的余额，还是买完以后的余额，读不准。
  4. 第2段“内衬口袋”大概是玛莎自己的，但上一句她正在整理埃德蒙的斗篷，所以有一点不确定。这一点不影响理解，不单列问题。

## 前文不足/供给待核

1. 场景开头的地点和来由：第1段“避风的屋檐下”和第6段“来往的旅客”说明这是公共场所，但没交代是车站、街口还是别处，也没交代母子为何在此、埃德蒙是否刚从学校回来。前文没有供给，不按 L2-5 定级。需要补读的范围：直接前场的完整原文，或者上一章结尾的完整场景。
2. “柜子里还稳稳留着八个加隆”“开学那趟”：这是家里存钱和以前采购的旧事，前文可能交代过余额和那次采购。需要补读：交代家中积蓄或开学采购的更早原文，如果有的话。补读后要用新上下文重新盲读，再判断 CE-4 是否成立。
3. “下学期要补的耗材”具体缺什么、为什么要补：前文可能写过缺耗材的原因，比如课程要求或用完了。需要补读：提到耗材短缺的原文，如果有的话。CE-2 指的是本场内两个“这”的所指和两笔钱的分工，不依赖这段前因，所以照样定级。

## 保留项

| 原文位置 | 原句 | 保留理由 |
|---|---|---|
| 第3段 | “两枚金加隆滚进埃德蒙掌心，微微一沉。” | “微微一沉”省了主语，但沉下去的只能是掌心，压缩自然，符合文风样本里“门轴一声轻响”这种短句写实物和动作的写法。 |
| 第4段 | “跟着取出来的，是……” | 先说“取出来的”再揭出是什么，取的人承前省略，就是玛莎，主语没换。除 CE-3 指出的量词堆叠外，句式本身不算错。 |
| 第6–7段 | “玛莎目光掠过来往的旅客，轻声嘱咐：”下一段接对白 | 动作和台词分成两段，形式上不符合 L2-2，但文风样本（“他笑眯眯的，话里却裹着刺。”“他顿了一下，那双小眼睛眯起来。”各自成段）证明本书惯用短段、动作和对白分段；冒号已指明说话者，不会读错。 |
| 第5段 | “这是你下学期要补的耗材钱。”（没有说话标记） | 在场只有两个人，埃德蒙是收钱的一方，下一段立刻标出玛莎在嘱咐，说话者不会读错。这一句的问题只在“这”的所指（见 CE-2），不在归属。 |
| 第7段 | “是全家的救急底子，谁也不准动。” | 母亲口吻的口语，“底子”“谁也不准动”合乎身份，不需要书面化。 |
| 第8段 | “这是妈妈这个月多接了四件翻领大衣的针线活挣来的。” | 母亲用“妈妈”自称，口语自然，量词和语序也没问题。 |
| 第10段 | “我知道，妈妈。救急的钱不动。” | 短句回应，复述上文的“救急”，表示记住了，这个重复有用，与上文呼应。 |
| 第9段 | “埃德蒙握紧掌心” | “握紧掌心”是常见口语化写法，读者不会停顿。问题只在后半句的并列搭配（见 CE-1）。 |
