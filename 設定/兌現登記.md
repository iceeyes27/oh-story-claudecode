# 兌現登記

> 所有要讓讀者看到的設定與場面、要遵守的規則、要持續感受到的特質，都登記在這裡。編號只增不重用。

## 類型

| 類型 | 用途 | 位置欄怎麼填 |
|---|---|---|
| 兌現 | 要讓讀者看到的設定、能力、名場面、結果 | 目標章節或章節區間；遠期可先寫卷 |
| 約束 | 規則、能力邊界、資源限制；適用時必須遵守，不必每次解釋 | 觸發條件 |
| 常駐 | 需要持續感受到的人物特質、關係或氛圍 | 窗口（每幾章出現一次） |
| 儲備 | 暫時不進正文的點子 | 預期啟用階段 |
| 退役 | 明確放棄的規劃，保留編號 | 放棄原因 |

## 狀態

- 兌現：規劃中 → 已排入 → 部分兌現 → 已兌現（也可能延期或退役）
- 約束：生效中／退役
- 常駐：在「狀態」欄寫最近一次出現的章節
- 儲備：儲備

## 填寫要求

- **兌現方式要寫成讀者可見的事件**，不要寫結論。
  - 不合格：展現主角的聰明
  - 合格：主角用對方自己說過的話設套，讓對方當眾自相矛盾
- **前置條件**：兌現之前讀者必須先知道什麼、哪些伏筆要先埋（伏筆編號見 `追蹤/追蹤.md`）。
- **只有作者回覆「通過」之後才能改成「已兌現」**，並填入證據原句與出處。部分兌現要寫明剩餘義務。
