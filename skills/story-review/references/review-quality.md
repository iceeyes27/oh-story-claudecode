## 一、通用检查

### 章节结构
- [ ] 开头让读者知道当前人、事或场景中哪一项值得继续读；天气、风景、日常有叙事功能时可直接开场
- [ ] 中段没有丢失本章主要行动、问题或情绪进程
- [ ] 章节对当前故事有可说明的功能；过渡、观察、休息也可成立
- [ ] 结尾完成本章的当前任务或留下自然的后续方向，不强制悬念或四类结尾

### 开篇检查
- [ ] 读者能在当前题材所需的时机建立人物、场景和近期问题
- [ ] 开场素材承担了信息、氛围、人物或因果功能，而不是可删的通用铺垫
- [ ] 主角或当前视角的延迟出场有明确意图
- [ ] 题材卖点、危机或关系张力在本书承诺的时机可见
- [ ] 开局不与同题材默认套路撞车（有钩子≠不同质；能整体换到任意同类书就是同质化）

### 章节推进
- [ ] 本章的行动、信息、关系、情绪或氛围功能与细纲和本书节奏一致，不为达标硬造变化或爽点
- [ ] 不是水字数（删掉这章会损失哪项状态变化？答不出才需压缩）
- [ ] 任务卡点有用：卡住之后是否带来上述状态变化？
- [ ] 推进强弱是否符合本书已建立的题材、兑现节奏与对标，而非套固定通用字数

### 信息传递
- [ ] 没有大段设定说明文
- [ ] 信息跟着冲突走（通过事件传递设定）
- [ ] 新设定的数量、出场顺序与解释程度不超过当前场面的理解需要；不设统一个数上限

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 场景有阻碍（什么挡着）
- [ ] 场景有变化（结束后跟之前不同）
- [ ] 行动、思考、感受或观察与当前场面的叙事任务相匹配
- [ ] 没有可删除的段落

### 章尾
- [ ] 结尾与本章已写行动、画面、对话或情绪自然相连
- [ ] 危机、决定、发现、反转、余韵、休止或阶段性完结任一符合本章功能即可
- [ ] 如有总结，它来自角色当下认知或实际结果，不是叙述者代替读者盖章
- [ ] 续读理由与本书节奏一致，不为每章强造钩子

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 情绪复现时有新的触发、视角、行动或后果，不是换词复述
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 标点节奏符合语气和人物声线：没有通篇句号化，也没有随机堆砌问号/感叹号；正文（含对话）不残留 `……`/`——`，迟疑或打断已改为动作、短句、逗号或句号
- [ ] 情绪表达符合当前视角与声线；可直说、可行动化、也可留白，关键是读者能理解且不被空泛身体反应替代
- [ ] 标题行以外没有章节/写作元信息：不得出现 `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 这类词；需要承接前文时改成角色能感知的事件锚点或相对时间；故事内真实阅读/讨论“第X章”或真实读者身份语境除外

### 连载连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 本章实际触及的伏笔与已接受状态一致；未触及的伏笔不强行推进
- [ ] 故事引擎还在运转

### 水（filler）检测
以下是需要做“删除测试”的信号，不是按段数、字数或章数自动判罪：
- 对话、情绪、场景、回忆或流程细节删掉后，人物、因果、氛围、关系和后续理解都不受损
- 同一信息或情绪只换了表达，没有新触发、反应或后果
- 长时间没有冲突本身不等于水；只检查是否违背本书当前阶段的承诺

## 二、长篇专项

### 黄金三章检查
- [ ] 前三章在本书的题材节奏内建立了视角、核心问题和主要阅读承诺
- [ ] 主角若延迟出场，延迟本身为故事服务，且读者不会误认主体
- [ ] 铺垫、事件、关系或氛围安排能解释“为什么这样开书”
- [ ] 续读动力来自题材契约的逐步建立，不用固定爽点数或逐章强钩校验
- [ ] 世界观信息按当前行动和理解需要给出

### 节奏检查
- [ ] 跨章累积的行动、关系、信息或情绪是否按本书的承诺在发展？
- [ ] 爽点、压力、呼吸和余波的间隔是否与题材、读者承诺和已建立样本一致？
- [ ] 连续低冲突或同情绪章节是否有意图地累积人物、氛围或信息，而不是重复？
- [ ] 全卷张弛有层次，但不按通用压力等级、章数或低压比例判定？

### 人物检查
- [ ] 主角行为符合人设？
- [ ] 配角是否有存在感？
- [ ] 反派逼格是否匹配当前阶段？

### 五维评分标准

每个维度 0-100 分，根据评分结果选择精修策略。

### 维度 1：核心一致度
检查：关键冲突、关键行动、人物动机是否前后一致。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 人物动机突然改变无铺垫 | critical | 补充动机转变的触发事件 |
| 核心冲突前后不一致 | high | 回溯修改冲突设定 |
| 关键行动与人物性格矛盾 | high | 调整行动或补充解释 |
| 次要矛盾遗忘 | medium | 回收或弱化 |

### 维度 2：表层重写度
检查：句式与措辞是否足够原创，避免套路化表达。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 照搬原句导致语气不自然 | medium | 只在确有 AI 腔时改写，正常原句可保留 |
| 大量使用 AI 标志词 | high | 替换为具体描述 |
| 同一句式重复出现 | medium | 变换表达方式 |
| 描写过于文学化（辞藻堆砌、书面腔、比喻成串） | medium | 改为符合本书声线的具体动作/物件/后果；不机械切短，也不强制逗号长句 |

### 维度 3：格式一致度
检查：段落是否按戏剧单元/镜头自然断开，主语/角色名节奏是否自然，开头结尾格式是否统一。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 机械按字数切段或主语过密 | medium | 按戏剧单元重排段落，段首点名、段中代词/省略、关键转折再点名 |
| 章节字数偏离目标 | **high** | 写作/大纲修复时先回到细纲补足计划内情节点，再展开；去AI味已有正文时不得新增剧情 |
| 格式混乱（对话/描写不统一）| low | 统一格式 |

### 维度 4：可读性
检查：是否有啰嗦、AI 腔、空泛总结、套路修辞。

| AI 腔特征 | 如何识别 | 如何修复 |
|-----------|----------|----------|
| 空泛总结 | 「他终于明白了」「一切尽在不言中」 | 删掉，用行动代替 |
| 套路修辞 | 「命运仿佛在和他开玩笑」 | 删掉或换成具体描述 |
| 比喻堆叠 | 连续多处「像/好像/仿佛/如同」，每个画面都靠比喻解释 | 只留最有叙事功能的少数比喻，其余改成动作、物件、声音或后果 |
| 情绪标签 | 「他感到一阵悲伤」 | 改为行为表现 |
| 心理描写空转 | 内心独白无新信息、重复同一情绪或复述读者已知 | 只压缩空转部分；带新信息、决断或情绪转折的独白不按句数压缩 |

### 维度 5：逻辑连贯
检查：句间/段间是否通顺，有无设定冲突。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 设定前后矛盾 | critical | 查找并统一设定 |
| 时间线错误 | high | 标记时间线并修正 |
| 角色信息不一致 | high | 建立角色档案对照 |
| 因果链断裂 | medium | 补充过渡 |

### 精修策略

根据五维评分结果，选择精修策略：

| 主要问题 | 策略 | 说明 |
|----------|------|------|
| 核心一致度低 | rewrite | 围绕核心冲突重写相关段落 |
| 字数超标 | compress | 删减不推动剧情的内容 |
| 无意义卡点 | compress | 保留卡出的变化，压掉流程 |
| AI 腔重 | de_ai | 替换禁用词、改写句式 |
| 小问题多 | polish | 打磨语言细节 |

### 读者契约与终局储备双向审查

审稿先问“无毒吗”，再问“好看吗”：**无毒不等于好看**，没有 契约破坏 只代表不踩雷，还要确认情绪兑现足够强。风险标记三档：契约安全（与开篇承诺一致、主角保有关键选择、收益归属清楚）/ 需补强（可能稀释高光或推进过快，但能靠铺垫、交换、代价修复）/ 契约破坏（核心卖点被没收或无关角色夺走期待所有权，需修纲）。

- [ ] 读者契约：本章/本卷是否兑现开篇承诺，还是把核心卖点交给机构、配角或偶然性？风险标记：契约安全 / 需补强 / 契约破坏。
- [ ] 主角代理权：按因果权 + 结算权审查，而非按出场时长；关键节点核对四问——谁决定事情为什么发生、谁作出不可替代的选择、谁承担或选择关键后果、核心收益/认可/权力结算给谁。配角可执行局部动作，但不能无声夺走期待所有权。
- [ ] 期待债：承诺是否被偿还、延期并支付利息，还是被解释/流程/设定吞掉？
- [ ] 终局储备：本单元是否动用了本阶段还不该解锁的终局底牌（宿敌/真相/身份/金手指上限）？是否让某条升级线逼近天花板、后面没台阶接？两问皆否即放行——单章一战多得（多线齐涨）是好设计，不算超速。
- [ ] 兑现归属：期待所有权是否按承诺结算；自愿让渡只有在“长期净收益为负 + 控制/因果权下降”同时出现时亮红灯，战略性让步的更大控制/未来收益/权力/信息交换是否可见？
- [ ] 节奏续接：高潮/兑现后是否允许短暂低压和小而可见的收益/奖励，而非机械立即加危机？新元素是否支付换书债、没有逃避旧承诺？
- [ ] 题材特定风险：履约爽文/能力幻想中，主角是否反复以愚蠢或可避免的无能制造灾难并由他人收拾，损害因果权与结算信任？
- [ ] 反向审查：若删除“安全解释”，情绪是否更强？若保留风险情节，是否带来更强期待、代价或爽点？
- [ ] 综合线：契约、主角代理权、期待债、终局储备是否互相支撑，而不是只做到“无毒”。

## 三、短篇专项

### 虐爽节奏检查

短篇特有的检查项——虐点和爽点的分布是否合理：

```
理想分布：虐1 → 虐2 → 虐3 → 爽1(小) → 虐4 → 爽2(大)
禁忌分布：虐1 → 虐2 → 虐3 → 虐4 → 虐5（无爽点，读者流失）
禁忌分布：爽1 → 爽2 → 爽3 → 爽4（无铺垫，爽感疲劳）
```

检查规则：
- 冲突、压力或关系变化是否在读者需要时推进，不能长期原地重复
- 虐点是否改变人物选择或代价，而非按间隔重复刺激
- 最大爽点是否由前文蓄力并改变局面，位置服从故事因果
- 结尾是否兑现本篇承诺并形成准确落点

### 对话功能检查

| 指标 | 合格标准 | 警戒线 |
|------|----------|--------|
| 对话与叙述分配 | 服从场景是否需要当面交锋 | 无对话导致关系只靠作者解释，或对话挤掉必要行动与思考 |
| 对话节奏 | 每轮都改变目标、关系、信息或策略 | 重复问答、碎片化接话、说明书台词 |
| 伤人性对话 | 具体揭示权力和人物选择 | 只堆狠话却不产生后果，或全员同声线 |

### 主角冷静度检查（打脸/复仇文专用）

| 检查项 | 标准 |
|--------|------|
| 主角冷静是否有人物依据？ | 用选择、语言、认知或行动体现，不硬塞端杯/转笔 |
| 情绪失控是否有触发与后果？ | 次数和位置服从人物弧，不按比例 |
| 主角与反派的情绪反差是否成立？ | 可同向、反向或错位，关键是符合各自动机 |
| 台词长短是否符合权力与声线？ | 不以“主角更短”作为默认优越 |
| 审判式对话是否适用？ | 只在提问能迫使对方选择或暴露时使用 |

### 证据链完整性检查（复仇/打脸文专用）

| 检查项 | 标准 |
|--------|------|
| 证据是否按调查与行动释放？ | 次数服从证据链；一次给全也必须有获得依据与后果 |
| 每个证据是否有铺垫？ | 前文必须埋过线索 |
| 反派反应是否符合其认知与利益？ | 不按“先得意再打脸”固定拍子 |
| 最终证据是否最致命？ | 最后一个证据要改变全局认知 |
| 是否需要定时证据？ | 只有主角有条件提前布局且因果成立时使用 |

### 毒点/代入感/震惊/开头/结尾/情绪/期待感速查

> 详细的毒点分类、识别方法和修复方案见 `anti-ai-writing.md`。

| 检查项 | 标准 |
|--------|------|
| 爽文不爽 | 金手指效果必须展示清楚 |
| 压制无目的 | 每次压制必须服务于后续爆发 |
| 反派结局与主角无关 | 反派之死必须因主角行动导致 |
| 经济/战力崩坏 | 设定前后一致，以普通人为锚点 |
| 女主/女配降智 | 人设正常可写，老套路别写 |
| 读者期待长时间不满足 | 适时满足或引入新期待 |
| 主角行为不可理解 | 必须能理解、能共鸣 |
| 氛围被突兀梗破坏 | 氛围 > 突兀梗（乐子文除外） |
| 钩子不回收 | 钩子不回收 = 烂尾 |
| 震惊分层 | 点→网→深度，不能只写点震惊 |
| 震惊阶梯递进 | 阶梯式上升，非直线 |
| 震惊有广度 | 关系网都要有反应 |
| 开头建立阅读问题 | 尽快出现人物、处境、异常、欲望或冲突；背景有功能时可先写 |
| 核心矛盾可定位 | 读者在需要作判断前能识别，不按字数硬卡 |
| 开头效果 | 与题材目标一致，不按统一情绪数字打分 |
| 结尾具体且合声线 | 动作、对话、画面、判断、余韵或必要反思均可；拒绝空泛总结 |
| 结尾有余韵 | 读者还想往下看 |
| 结尾情绪效果 | 是否兑现本篇承诺并留下准确感受，不设题材数字阈值 |
| 情绪对等释放 | 虐多少补多少，反派结局关联主角 |
| 期待管理 | 目标、选择、关系、兑现余波或开放问题自然承接；不限定期待线数量 |
