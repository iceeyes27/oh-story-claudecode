# 章末钩子替换 · 低成本收尾精修动作

从《我在越南捞沉船》2026-09 精修轮固化。**为什么是这个动作**：09-06 至 09-14 多轮干预中，与读者人数缓缓回升时间最贴近的干预之一是「章末口号 → 具体落点」的钩子替换（单章 2 行、横跨全五卷 148 章）。**注意**：回升可能与多种干预叠加相关（病灶重修/结构重修/推送节奏），钩子替换的独立效果未做归因；本 skill 只固化动作本身，不声称效果已被证明。

## 核心定义

**章末钩子 = 用具体物件/动作/时间/数字落点收束本章，让读者带着一个可感知的画面或悬念进入下一章。**

**三型病灶（命中即改）**：

| 型 | 特征 | 判据 | 示例（旧 → 新） |
|----|------|------|------------------|
| A 口号式舞台腔 | 章末用抽象大词+排比升华收束全章，像宣传片旁白 | 抽出来读，像不像旁白字幕？像 → 命中 | 「广安楼后院水闸平稳蓄水，整座西贡华埠的商道网络，已然在脚下铺开了一片崭新的天地。」→「广安楼后院水闸平稳蓄水，明早头批货，顺潮就能出关。」 |
| B 总结式叙事 | 章末替读者下全局结论，把一章缩成一句定论 | 这句是不是在'总结本章意义'？是 → 命中 | 「……这些日子，陈海终于明白，堤岸的水比会安的深。」→ 换成具体动作/物证收束 |
| C 待办式空预告 | 章末只报下一步动作，无画面落点（'明天去谈'式） | 下一步有没有具体物件/时间/地点/数字？没有 → 命中 | 「明天一早，他要去找周先生谈那笔资金。」→「周先生那笔资金，明天一早要用那张字据去兑。他摸了摸怀里的信封，硬邦邦的。」 |

## 判定原则

- **改前必读全文最后一段**（±3 行），确认是口号/总结/空预告而非有功能的余韵或悬念。
- **保留**：行动、关系、后果、明确下一步、内心、余韵——只要它具体、可感知、不空泛。
- **保留**：功能性悬念（'门被推开'式硬钩子）、in-world 台词的收尾、角色当下的真实决定。
- **替换方向**：抽象 → 具体；全局 → 局部；预告 → 画面；定论 → 物件/动作。
- **成本纪律**：单章 1–2 行，禁止整段重写；没有问题的章末不动。
- **不新增剧情**：落点必须来自本章已有的事实/物件/计划，不得引入原文没有的情节、设定或人物。

## 高频口号词表（命中后复核，勿同义轮换）

A 类舞台腔词（出现于章末升华语境时优先复核）：传奇 / 史诗 / 启航 / 天梯 / 奏响 / 宏图 / 定鼎 / 崛起 / 巅峰 / 巍峨 / 席卷 / 恢弘 / 惊涛骇浪 / 扬帆 / 气吞山河 / 沸腾 / 浩气 / 磅礴 / 腾飞 / 辉煌 / 铁血 / 铿锵 / 长存 / 震撼 / 霸业 / 里程碑 / 崭新的天地 / 时代的脉搏 / 华丽篇章 / 壮丽华章 / 万川归海 / 大业已成。

B 类总结腔句式：从此…… / 从今往后…… / 这一刻他终于明白…… / 一切……都…… / 整个……的格局 / 属于他的时代（开始了）。

C 类空预告句式：「明天（一早/再去）……」（后无具体物件/数字/地点时）/「接下来要……」/「他不知道的是……」/「更大的风暴即将来临」类。

## 工作流程

1. **确认目标**：按 `.active-book` 解析当前书；若脚本 `--dir` 未指定且 `.active-book` 不可用，明确报错而非默认猜测。可指定卷/章/区间（如 `--from 299 --to 400`）。
2. **提取章末**：跑 `scripts/extract_chapter_endings.py`，批量提取每章最后一段（可带 `--words` 口号词表过滤）。脚本严格识别「第N章_」文件名，**跳过正文根下的 `.claude/`、`_已知实体.txt` 等非章节文件**；报告重号/缺号/读取失败（任一异常即终止，不静默继续）。
3. **逐章判定**：对每章最后一段读上下文，按三型病灶表定性（A/B/C/留）。
4. **定向改写**：只改命中章末，换具体落点；单章 1–2 行；改前记原文。
5. **验证**：改完对实际落盘文件跑 `node .agents/skills/_shared/scripts/check-ai-patterns.js --check --fail-on=blocking <文件…>`，0 blocking 才交付；同时跑章节名/字数门禁（如适用）。
6. **同步台账**：改动涉及时间/承诺/物证的，核对 `追踪/` 五件套与细纲，冲突以正文为准。
7. **报告**：列出 章节号 | 型 | 原文章末 | 改后章末 | 字数变化。默认 report-only，用户确认后落盘。

### 首轮试点新判例（2026-09-14，commit `ac79daba`）

- **ch35**（A 型）：末段「整片南洋水域的暴风雨，正呼啸着席卷而来」→ 落点用章内已有的"木板上四行炭字"（范姓船主/猫牙旺/芦苇港铁壳船/七叔老残党）+ 时间（明晚）：「陈海没再说话，只低头看着木板上那四行炭字……明晚之前，这四笔账，一个都不能漏。」
- **ch109**（B 型）：末段「广安楼…第二座铁堡垒」全局定论 → 落点用章内物件（羊皮纸法文蓝图、钢印年份）+ 约定（天亮前）：「先把最上头那卷羊皮纸法文蓝图摊平在灯下，指尖顺着钢印上的年份一字一字往下走——天亮之前，他要把这栋楼的地契，先对个明白。」
- **ch149**（A+C 混合）：末段「该来的总会来…收旧账」空预告 → 落点用章内"递秤的手"与阿梅的账簿：「可坐在深宅里递秤的那只手还没断。阿梅，那本账簿带好，往后一笔一笔，总有对上的时候。」
- **ch314**（A/B 混合）：末段「两岸商路彻底打通」总结定论 → 落点用章内事实（互保凭条、关闸）：「船头吃水压得低低的——那是第一批领到互保凭条的货，正赶在关闸前顺流出港。」

## 边界

- 本 skill 只做章末钩子替换；章内 AI 味、结构、逻辑、细读层问题交给 story-deslop / ai-flavor-scan / story-review / story-micro-scan（复合检查流水线已覆盖：主语指代、动作归属、语句连贯、时间因果、失真痛感、AI腔、读者理解）。
- 不负责番茄推送（见 `fanqie-chapter-publish` 与 `报告/番茄同步_*`）；推送到线上是独立动作。
- **效果归因未定**：148 章钩子替换与读者回升时间贴近，但回升也可能来自病灶重修/结构重修/推送节奏的叠加，且 272–400 区间 49 章尚未上线。不得把「钩子替换已验证有效」写成对全书的既定结论；验证方式 = 补推 71 章后记录章节/日期/版本，观察七日后台数据。
