# 吸收通用去 AI 味与保真翻译能力

## Goal

在保留现有小说 7 Gate、通用文本 Tier/scope/protected-spans 契约和统一 Skill 架构的前提下，为 `story-deslop mode=general` 补充可安装的按需参考集与结构保真翻译能力，使普通改写、审阅和翻译都能以最小改动保留原意、结构与技术片段。

## Background

- 当前 `skills/story-deslop/SKILL.md` 已具备 `chat/status/docs/public-writing` 场景、Tier、改写档位、scope、protected spans、annotation mode 和两遍回读，但明确排除逐字翻译，并注明通用参考集不随仓库分发。
- 当前小说模式已有 7 Gate、共享禁用词表和确定性扫描器；本任务不得削弱或改写这些契约。
- 参考上游 `OUBIGFA/De-AI-Prompt-Enhancer-Writer-Booster-SKILL` 的 `main` 快照 `b050eefa88af3709ec24fc0b353740ccb151f563`：其可借鉴点是按任务最小加载、AI 痕迹轻量索引、Top 5-10 审阅和结构保真翻译。
- 上游未在仓库根目录提供许可证文件。本任务只独立实现功能思想，不复制上游文本、样本或脚本。

## Requirements

- **R1 — 任务分流**：`mode=general` 必须区分普通改写、审阅/标注和结构保真翻译；翻译只由用户明确提出“翻译/译成某语言/结构保真翻译”触发，不根据外语或中英混排输入自动启用；不得新增独立公开 Skill。
- **R2 — 按需加载**：普通改写只使用 `SKILL.md` 的核心规则；需要定位 AI 痕迹时先加载轻量索引，再按命中类型读取详细参考；翻译只加载翻译护栏。
- **R3 — 保真翻译**：翻译必须保持标题层级、段落、列表项、引用、表格、空行和缩进的对应关系；代码、命令、参数、路径、URL、占位符、标识符及 Markdown 结构不得漂移。
- **R4 — 信息守恒**：翻译与保真改写不得新增或删除事实、条件、限定、结论与责任主体，不得改变信息顺序或把正文压成总结。
- **R5 — 通用痕迹审阅**：审阅只报告最影响读感的 5-10 项，覆盖结构、语气、句式和词语层级；密度型、语境型规则只作 advisory，不以机械命中要求全文清零。
- **R6 — 输出兼容**：保持现有单一推荐版本、annotation mode、protected spans、Tier、档位、scope 与两遍回读语义；翻译默认只输出目标文本。
- **R7 — 边界隔离**：新增通用参考资产归 `story-deslop` 自有目录，不改变 `_shared` 小说扫描器、写作 Hook、小说 7 Gate 或复合检查清单。
- **R8 — 可部署与可验证**：新增引用必须通过 Skill 自包含、链接、跨平台部署和当前契约检查；增加本地回归测试，不创建 GitHub Actions 或其他 CI 配置。

## Acceptance Criteria

- [x] 显式翻译请求能进入 `mode=general` 的结构保真翻译流程，普通改写与审阅的现有路由不变。
- [x] 翻译护栏明确覆盖 Markdown 结构、不可改动片段、信息守恒和译后保真回读。
- [x] 通用 AI 痕迹索引支持按问题族定位详细参考，普通任务不要求加载完整检测清单。
- [x] 审阅输出限制为最重要的 5-10 项，且语境型命中不会被定义为必须清零的 blocking 问题。
- [x] `mode=novel`、共享扫描器、写作 Hook 和现有小说测试无行为变化。
- [x] 新增资产由 `story-deslop` 自包含引用，所有 Markdown 链接有效，公开 Skill 数量不变。
- [x] 新增或更新的契约测试覆盖翻译路由、按需加载、结构保护、信息守恒与小说边界。
- [x] 与变更范围对应的本地静态检查、契约测试、平台适配检查、共享资产检查、现有小说扫描器回归和 `git diff --check` 全部通过，证明更新后项目框架仍可正常执行。

## Out of Scope

- 导入 `good-writing` 的特定作者样本、作者 DNA 或半文半白风格。
- 直接复制上游 `style_audit.js`、绝对禁词表或面向单一作者的量化阈值。
- 新增通用写作 Skill、改变公开 Skill 清单或修改 GitHub Actions。
- 扩大到小说正文自动翻译、书籍导入或多语言项目管理。
