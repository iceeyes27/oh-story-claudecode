# 技术设计

## 1. 设计边界

本任务只扩展 `story-deslop` 的通用模式。小说模式、`skills/_shared/`、写作 Hook、复合检查清单和公开 Skill 集合保持原样。

权威源码继续位于 `skills/`。仓库内 `.agents/skills` 指向 `skills`，Claude、Codex 与 WorkBuddy 的 Skill 入口再指向 `.agents/skills`；因此只修改权威源码，不维护多份内容副本，交付前用 adapter manager 验证解析目标和哈希。

## 2. 路由契约

`story-deslop` 先判 `mode`，再在 `mode=general` 内判任务：

| 输入意图 | 路由 | 读取资产 | 输出 |
| --- | --- | --- | --- |
| 明确要求翻译、译成指定语言或结构保真翻译 | `general/translation` | `references/translation-guardrails.md` | 仅目标文本 |
| 明确要求审阅、评分、标问题 | `general/review` | `references/general-ai-trace-index.md`，再按命中读取详细指南 | Top 5-10 问题 |
| 普通去 AI 味、润色、改写 | `general/rewrite` | `SKILL.md` 核心规则；确需深查时才读取索引和相关章节 | 单一推荐版本 |
| 小说正文或显式 `mode=novel` | 既有小说流程 | 既有 7 Gate 与 `_shared` 资产 | 保持原契约 |

外语、中英混排、英文术语或代码片段本身不构成翻译触发信号。用户没有明确翻译意图时，继续按现有场景路由处理。

## 3. 参考资产

新增资产均放在 `skills/story-deslop/references/`：

- `general-ai-trace-index.md`：轻量索引，列出问题族、优先级、详细章节锚点和适用场景。
- `general-ai-trace-guide.md`：独立编写的通用文本审阅指南，按结构、语气、句式、词语和格式分组；每组包含信号、修改动作、允许保留的边界和反例。
- `translation-guardrails.md`：结构保真、不可改动片段、信息守恒、术语策略和译后回读契约。

不复制上游的 24 项原文。详细指南从当前 `story-deslop` 的 Tier、scope、protected spans 与真实场景约束重新组织，避免作者特定规则进入通用模式。

## 4. 翻译数据流

1. 识别用户明确的源语言、目标语言和结构保真要求；未指定目标语言时根据请求语义确定，无法确定才询问。
2. 在改写前标记 protected spans：代码块、内联代码、命令、参数、路径、URL、邮箱、占位符、标识符、版本号、链接目标和 Markdown 控制符。
3. 按段落、列表项、引用和表格单元一一翻译；允许句内重排，不允许跨结构单元合并、拆分或换序。
4. 做信息守恒回读：事实、条件、否定、限定、数字、责任主体和语气强度均可对应回源文。
5. 做结构回读：标题层级、列表编号、引用层级、表格列数、代码围栏、链接目标、空行和缩进保持一致。
6. 仅输出目标文本；用户同时要求译后去 AI 味时，在翻译完成后执行一次保守的 `general/rewrite`，仍受翻译护栏约束。

## 5. 通用审阅语义

索引只选择最影响读感的 5-10 项，不把完整规则表返给用户。详细指南的规则分为：

- 高置信内容污染：模型身份、知识截止说明、无源权威归因、虚构引语。需要删除、降级或明确缺证据。
- 结构与语气问题：段落同构、步骤讲解、协作口吻、空总结、宣传式拔高。结合场景处理。
- 句式与词语密度：二元对照、工整排比、条件句堆叠、抽象隐喻、分析术语。只作 advisory，先读上下文。
- 格式问题：PPT 式粗体、内联标题列表、表情、标点混排。保留 README、正式文档和引用中的功能性格式。

本任务不新增确定性运行时扫描器。通用问题高度依赖语境，先以参考契约和回归测试约束 Agent 行为，避免把小说扫描器扩大到技术文档后产生误报。

## 6. 测试设计

新增 `skills/story-deslop/tests/general-mode-contract.test.js`，静态验证：

1. 三种 general 任务路由和显式翻译触发存在。
2. 外语输入不得自动触发翻译。
3. 翻译分支只加载翻译护栏，审阅分支先索引后详细指南。
4. 翻译护栏包含结构保护、不可改动片段、信息守恒和两类回读。
5. 索引中的详细章节均能在指南中解析到，Top 5-10 和 advisory 语义存在。
6. 小说 7 Gate、共享扫描器引用和既有模式入口仍存在。

把新测试加入 `npm run test:contracts`，使既有本地契约入口覆盖本功能。

## 7. 兼容性与恢复

- 不修改 Skill 名称、版本发现方式、公开清单或命令入口。
- 不增加依赖，不要求联网，不新增 CI。
- Markdown 静态检查负责死链与跨 Skill 边界，adapter manager 负责平台入口。
- 若新增路由产生行为异常，恢复范围仅为 `story-deslop/SKILL.md`、三个新参考文件、对应测试和 `package.json`；小说共享资产无需回退。
