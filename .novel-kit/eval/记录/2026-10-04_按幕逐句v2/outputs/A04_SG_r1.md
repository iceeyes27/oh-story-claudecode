## 第1幕

| 句号 | 结论 | 说明 |
|---|---|---|
| 1-01 | 待核 | “两人”无前文可判定是谁，要到 1-03 才知是埃德蒙与红发学长（前文不足，暂不报）。“檐下”与“立在雪里”“撑着油纸伞”并置：人在檐下一般不淋雪、不必撑伞；读者画面会在“檐下躲雪”与“站在雪地里撑伞”之间摇摆 |
| 1-02 | 待核 | 上句已撑伞（至少占一只手），本句“怀里抱着几卷新宣纸”，只剩一臂抱纸；单臂抱几卷宣纸可行，但需记住双手全占，后续动作要受此限制 |
| 1-03 | 通过 | 数十米、雪中，能认出两人的身影，可接受；“并肩行走”与 1-01“走向街口”一致 |
| 1-04 | 问题 | “对着自己的左边袖口”——“自己”可指姜小满也可指埃德蒙（语文规格 L1-5 原例几乎一样）。另：数十米外、雪中，姜小满能看到他侧头对着袖口动嘴，但“轻声说了一句什么”的“轻声”她如何判断，感知上只能看不能听，属轻微越界 |
| 1-05 | 问题 | 她一手撑伞、一臂抱几卷宣纸，“收拢伞沿”——若指合伞，双手已占，合伞需腾手，没写怎么做到；且合伞后快步走入雪幕，与前面撑伞避雪的状态相反。若“收拢伞沿”指压低伞沿遮脸，则可行，但措辞会被读成合伞。另“长睫在雪风里眨动”——她在檐下又撑伞，雪风能吹到眼前，可接受 |
| 1-06 | 通过 | “傍晚”“红砖巷的小屋里”标明时空跳转，按新时空重建状态 |
| 1-07 | 通过 | |
| 1-08 | 待核 | 埃德蒙已在小屋内，回家过程省略，属跳转可接受；但小屋里还有谁未交代（后文玛莎、亚瑟在场，此处未写），红发学长是否同来也未交代——读者默认只有埃德蒙一人 |

## 第2幕

| 句号 | 结论 | 说明 |
|---|---|---|
| 2-01 | 问题 | “不仅无一遗漏”缺主语，须补成“要买的东西不仅无一遗漏”，复述时得自己补。“母亲给的两枚”——两枚什么（加隆？）未写；“那卷英镑”用“那”指已知的一卷钱，前文不足。状态上：余钱写在“兜里”（西可）和“那卷”（四张十镑），没写拿出来放到桌上 |
| 2-02 | 问题 | “看着桌上的余钱”——上句余钱在兜里／那卷钞票，没有写埃德蒙把钱掏出来摆到桌上，钱的位置无动作改变。玛莎首次出现，“出来”交代了从里间（推测厨房）进入，可接受；她双手端汤，此句只看、愣住，做得到 |
| 2-03 | 问题 | 对白独立成段，没有说话者标记。上句主语是玛莎，下句是亚瑟乐呵呵，读者无法判定是谁说的（“这孩子”语气两人都可能）。另：“从小把钱攥得紧”与 2-01 钱已花得见底相对照——若指“节省、剩下了钱”可通，若读成“舍不得花”则与刚花光对不上，语义取决于说话者，属待核 |
| 2-04 | 问题 | 亚瑟此前从未写在场，直接“大口喝汤”，在场者突兀出现。玛莎刚端汤出来、愣在原地，汤没有写放下、盛碗，亚瑟已在喝，顺序跳过。“摸着脑袋”可读成摸自己的头，也可读成摸埃德蒙的头（长辈对“这孩子”的动作），且一手摸头、一手喝汤可行但若摸的是埃德蒙则需他坐在旁边，位置未交代。埃德蒙在场却全幕无反应 |
