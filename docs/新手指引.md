# 新手指引：十分钟上手写书

这份是简化版，只讲“怎么用”。规则细节、原理和讨论项见[完整使用指引](novel-kit-使用指引.md)。

## 一句话说明

**你当作者，AI 当写手和审稿团队。** 每次只写一个场景，几个 AI 审稿员分别挑错，最后由你看全文决定要不要。你说“通过”，这一场才算定下来。

## 第一步：准备（只做一次）

需要：

- 电脑上装好 **Python 3.9 或更新版本**（终端输入 `python3 --version` 查看）
- 装好 **Claude Code**（桌面版或命令行都可以）

然后：

1. **一本书一个文件夹。** 把整个工具组（包括 `.agents`、`.claude`、`.novel-kit` 这些隐藏文件夹）复制到一个新文件夹，比如 `我的新书/`。
2. 在这个文件夹里打开终端，运行配置：

   ```bash
   ./novel setup --agent claude
   ```

   Windows 用 `.\novel.cmd setup --agent claude`。

3. 运行自检，看到“配置一致”就行：

   ```bash
   ./novel doctor --agent claude
   ```

4. 用 Claude Code 打开这个文件夹，开一个**新会话**。

> 以后搬了文件夹或换了电脑，重新做第 2、3 步。

## 第二步：开书

在 Claude Code 里直接说人话，例如：

```text
开一本新书。题材是……，主角是……，我想写的故事大概是……
```

AI 会和你一起建立：

| 内容 | 存在哪里 |
| --- | --- |
| 世界观、规则 | `設定/設定.md` |
| 角色卡（一人一份） | `設定/角色/` |
| 全书大纲 | `大綱/大綱.md` |
| 要兑现的伏笔和承诺 | `設定/兌現登記.md` |
| 你认可的文风样本 | `設定/文風樣本.md` |

**文风样本最好由你提供**一段自己写的或喜欢的文字，AI 会照着这个风格写。

已经有旧稿？改说“**导入我的旧稿，文件在……**”。原稿会先备份，不会被改动。

## 第三步：规划一章

```text
规划第一章，按场景详细给我确认。
```

AI 会把这一章拆成几个场景，每场写清：谁、在哪、想做什么、遇到什么阻碍、结束时发生了什么变化。

你看完回复“**确认**”，或者直接提修改意见。**细纲没确认，AI 不会动笔。**

## 第四步：一场一场写

```text
按已确认细纲写当前场。
```

AI 写完会先自动审一遍，然后交给你：

1. 这一场的**完整正文**
2. 哪些地方被改过：原句 → 改句 → 为什么改
3. 这一场改变了什么：人物位置、道具、谁知道了什么秘密……
4. 还有哪些问题需要**你来拍板**

**交付完 AI 会停下来等你。** 你只要回一句：

| 你回复 | 会发生什么 |
| --- | --- |
| **通过** | 定下这一场，然后停下 |
| **通过，继续** | 定下这一场，接着写下一场 |
| **修改：**（你的意见） | 按意见改这一场，再交给你看 |
| **重写：**（新方向） | 这一场推倒重写 |
| **只检查，先不改** | 只给检查报告，不动任何文件 |

⚠️ “还行”“差不多”“继续”**不算通过**。要定稿请明确说“通过”。

## 第五步：整章收尾

一章的最后一场通过后，AI 会把各场拼成整章，顺一下衔接，再整体检查一遍。

衔接时如果动到了你已经通过的场景，会单独指出来让你再确认。你对整章回复“通过”后，这一章才正式写进 `正文/第001章.md`。

然后回到**第三步**，规划下一章。

## 常用说法速查

| 想做的事 | 直接这样说 |
| --- | --- |
| 不知道进行到哪了 | 检查当前状态，恢复已有任务 |
| 规划下一章 | 规划下一章，按场详细给我确认 |
| 写下一场 | 按已确认细纲写当前场 |
| 改已经定稿的章节 | 逐场优化第 003 章，只改对白和动作 |
| 自己手改了正文，想让 AI 看看 | 只审我手改的版本，先不改 |
| 打磨对白、动作、道具细节 | 精修第 005 章的对白和动作 |

## 文件夹地图

```text
設定/   世界观、角色、文风      ← 你可以看、可以和 AI 一起改
大綱/   全书大纲和每章细纲
追蹤/   全书进度、伏笔、场景状态  ← 由工具维护，别手改
草稿/   正在写、还没定稿的场景
正文/   正式定稿的章节          ← 你的书在这里
審閱/   审稿记录、采用记录
導入/   旧稿备份               ← 永远不会被改动
```

## 新手常见问题

**问：为什么 AI 不肯写下一场？**
答：通常是上一场你还没说“通过”，或者这一章细纲还没确认。说“检查当前状态”，它会告诉你卡在哪。

**问：每场都要我看，好麻烦，能一次写一整章吗？**
答：不能。这是这个工具组的核心设计：逐场把关，防止 AI 一路写偏。熟悉之后可以用“通过，继续”加快节奏。

**问：我想改已经定稿的章节怎么办？**
答：直接说要改哪章、改什么。AI 会开一个“修订任务”，也是逐场给你看。修订期间暂停写新内容，免得后文建立在旧版本上。

**问：交付里写着“审阅不完整”是什么意思？**
答：有审稿员没跑成功。你可以要求重跑；也可以明确告诉 AI 你接受这个缺口，再说“通过”。

**问：我自己直接改了正文文件，可以吗？**
答：可以。改完说“只审我手改的版本”，AI 只给意见，不会自动动你的字。

**问：会话中断了 / 电脑关了？**
答：开新会话，说“检查当前状态，恢复已有任务”。进度都存在文件里，不会丢。

**问：我还看到 `/story-long-write` 之类的命令，能用吗？**
答：那是另一套网文工具，和本书的状态记录不互通。在这个文件夹里写书，请只用上面列出的说法，或者 `/new-book`、`/plan-chapter`、`/write-scene`、`/revise`、`/import-book`、`/fiction-scene-polishing` 这六个入口。

## 记住三件事

1. **一次只写一场**，你说“通过”才算定稿。
2. **重要的事你来定**：剧情、设定、新角色，AI 只会提建议。
3. **卡住了就说“检查当前状态”**。
