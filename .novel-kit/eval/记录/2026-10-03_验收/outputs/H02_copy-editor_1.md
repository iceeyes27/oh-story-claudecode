## 阅读理解摘要

埃德蒙带着折过的羊皮纸来到球场场边，把有关扫帚升力的图交给队长。队长和队员传看后无法理解，现场出现嘲笑；队长把图压在水壶下，劝他别再添乱。埃德蒙不再争辩，用“输球的是你们”回应。

伍德抽走图纸。他并不声称已经看懂理论，而是认出箭头与自己练习、摔跤得到的经验相合，因而兴奋地抄图。加文愿意照图尝试，比尔也练了几回，两人都没掌握动作。查理出现后指出，计算结果必须拆成能够练习的动作，并示范抬臀、压腕、顺风切出的顺序。

随后马尔科姆从西看台下来，对埃德蒙说“决赛见”，形成当场挑战。埃德蒙捡起、抹平并收好羊皮纸，回应“决赛见”。结尾袖内名为傻妞的声音安慰他并承诺陪他参加决赛；埃德蒙笑了笑，没有接话。最后明确可见的状态是：羊皮纸已收进埃德蒙怀里，马尔科姆与跟班离开，决赛尚未发生。

当前阅读不确定处：伍德拿走原件后，它怎样回到埃德蒙手里，以及后来怎样到了地上，文本没有交代；这两处见下列问题。看台旧事、秃扫帚和袖内声音的前因属于未供给范围，见“前文不足/供给待核”。不据此推测人物身份背景、扫帚原理或傻妞的具体形态。

## 问题

### CE-1：原件从伍德回到埃德蒙手里的承接缺失

```yaml
- id: CE-1
  severity: S2
  category: 承接
  location: "H02/正文.md，‘埃德蒙把羊皮纸往他手里一塞。’所在段"
  evidence: |
    就在这时，一只手从旁边伸过来，把那张皱羊皮纸抽走了。
    奥利弗・伍德。
    他凑到场边，把羊皮纸举到眼前，越看眼睛越亮。
    ……
    埃德蒙把羊皮纸往他手里一塞。
    “抄吧。”
  reference: "同一份 H02/正文.md 中伍德抽走、举起原件至埃德蒙塞纸的动作链；省略号仅略去引文间的对白和描图段落。"
  issue: |
    L2-3（先写出，再提及）。正文先明确原件已由伍德抽走并举起；
    随后写他拿铅笔、摊开自己的笔记本并描图，没有写原件交回埃德蒙。
    读到“埃德蒙把羊皮纸往他手里一塞”时，埃德蒙突然成为持纸人，
    读者需要回读，寻找原件何时从伍德手里回到他手里。
    两人的动作主体本身明确，因此不定 S1；损失在于同一现场的持有承接断开，定 S2。
  fix: |
    先确定描图和这段问答之间原件由谁持有。
    若保留埃德蒙塞纸的动作，应在此前补一处伍德交回原件的承接；
    若伍德一直持有原件，应改写该段，使许可继续抄图的意思与实际持有状态相符。
    不自行编造交回的动机，不删除允许继续抄图的信息。
    补写或改写衔接后，回读前后各两段。
```

### CE-2：原件到地上的位置变化缺少承接

```yaml
- id: CE-2
  severity: S2
  category: 承接
  location: "H02/正文.md，‘他一个翻身落在场边，目光在地上那张被踩脏的羊皮纸上走了一遍。’所在段"
  evidence: |
    埃德蒙把羊皮纸往他手里一塞。
    “抄吧。”
    ……
    他一个翻身落在场边，目光在地上那张被踩脏的羊皮纸上走了一遍。
    ……
    埃德蒙弯腰，把地上那张被踩脏的羊皮纸捡起来。
  reference: "同一份 H02/正文.md，伍德收到原件、加文与比尔练习、查理落地看图及结尾捡纸的段落。"
  issue: |
    L2-3（先写出，再提及）。原件最后一次明确转交是在伍德手里，
    此后没有写抄完、放下或掉落；查理落地时却直接把它作为地上已被踩脏的物件提及。
    读者在“地上那张被踩脏的羊皮纸”处需要回读：伍德是否已经放下原件，
    纸为何从抄图时的持有位置变成地上的图？回读仍找不到位置变化的承接。
    练习耗时可以从出汗等动作推知，但不能直接推出原件已落地。
    结尾再次从地上捡纸，使这个位置参与后续行动，故不是只需忽略的背景细节。
    这与 CE-1 分别发生在不同转移点：补写交回或塞纸动作，并不能同时补上落地的承接。
  fix: |
    在伍德描图至查理落地看图之间，补一处简短动作交代原件何时被放下或落到地上，
    具体采用哪一种须先确定原意。无需交代每个脚印，也无需擅定是谁踩脏了纸。
    保留查理看图与埃德蒙结尾捡纸的动作，补写后回读前后各两段。
```

## 保留项

| 原文 | 保留理由 |
|---|---|
| “这啥？”／“你会说人话吗？”／“小家伙，心是好的。扫帚嘛，骑上去就知道了。” | 都是现场口语；问话、嘲讽、劝退的意思清楚。匿名起哄者用“终于有人”交代，辨认其姓名不是理解动作所必需。不补书面关联词，不磨平语气。 |
| “大概不会。”／“大约的确不会。” | 外在平静回答与内心自嘲有层次，同义接近的表达在这里承担不同功能，不作无功能重复删除。 |
| “你看得懂？”／“看不懂。”以及伍德随后解释箭头与摔跤方向相合 | 后续立即区分“理解理论”和“认出经验中的方向”；这不是前后自相矛盾。保留短问短答。 |
| “这份，能抄我一份吗？” | 请求获得一份抄本的口语意思可以辨认，后文也直接写他动手描图。不仅凭口语省略或请求与随后自行动手就判病句。 |
| “风阻拿什么测的？”／“摔的。”／“摔够十回，就知道哪儿漏风。” | 说话轮次与埃德蒙的答话标记清楚，承接伍德此前用摔跤理解飞行的说法。保留简短、省略的回应；不擅自补成技术解释或裁定原理真伪。 |
| “我守门的，手腕最熟。”／“压半寸，到底是多半寸？” | 符合当场自信尝试又难以掌握尺度的口语表达。后者能读作“这半寸到底有多少”的疑问，不因量词或省略改成书面语。 |
| “场边另一块空地上，比尔也陪着练了几回。” | 地点、人物与行动一并交代；此处可以理解比尔加入练习，不要求另外补一个形式化入场段。 |
| “算出来的东西，不能直接让人照做。”／“得拆成动作。” | 直指前面的练习困境，随后以三步示范兑现；省略的主语和承接关系可判定，无须扩成说理长句。 |
| “奥利弗・伍德。”／“查理・韦斯莱。”及随后身份、动作段 | 名字紧接伸手或红影的出现，随即给出人物说明，是即时揭示，不是无标记地换行动者。 |
| “公式画得挺热闹。”／“决赛见。”／埃德蒙收纸后回应“决赛见。” | 挑衅与回应的功能不同，重复比赛约定有对峙作用。没有必要补出双方全部心思或让埃德蒙解释为何没接傻妞的话。 |
| “风卷着枯草屑，从场中那道泥径上漫过去。”／“没人说话。” | 场面从嘲笑转为沉默，短段有停顿作用。文风样本中“门轴一声轻响，先钻进鼻子的不是饭香。”与“是浆洗过的旧布味，混着一点炭火的暖。”亦以短段和现场感受推进；此处不因短段或省略就定节奏错误。 |
