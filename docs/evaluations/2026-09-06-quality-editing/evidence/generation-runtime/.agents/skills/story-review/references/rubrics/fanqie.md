# 番茄小说审查参考

先按 `quality-rubric.md` 确定题材、本书承诺与章节功能。本文件只补阅读呈现与本书的连载期待，不能把平台等同于强冲突题材。

| 观察项 | 适用时检查 | 不适用或可保留 |
|--------|------------|----------------|
| 开篇进入 | 人物、处境或当前问题能在需要判断前看懂 | 有人物、气氛或因果作用的描写可以先出现，不设前三段钩子门槛 |
| 当前回报 | 本章对本书承诺有可说明的贡献 | 日常相处、休息、试错和余波可成立，不要求每千字情绪起伏 |
| 手机阅读 | 信息顺序、指向与分段是否实际造成回读或跳读 | 长段、短段、独白与对白按内容决定，不套统一长度或比例 |
| 连载承接 | 前事后果、人物期待或下一步自然衔接 | 不要求逐章强钩、反转或危机，完结章可收束 |
| 题材承诺 | 按本书的甜宠、悬疑、手艺、成长等真实承诺判断兑现 | 未承诺的爽点、感情线、金手指记 N/A，不要求补写 |

适用项用 PASS / WARN / FAIL；不适用项标 N/A 并说明原因，证据不足单列。仅作 advisory，严重度来自具体阅读损失；不凭平台名推断算法偏好，不从钩子、节奏推算完读率。修改建议优先选择 1～2 个最高阅读损失，不按表逐项加戏。
