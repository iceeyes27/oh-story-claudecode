# C01 第5幕 逐句逻辑读者报告（sentence-reader）

## 现场摘要

- 在场者：埃德蒙（陈放）与刚撞进门的黑发女孩（会说中文，穿大一号新黑袍，拎小藤箱）；地点是列车车尾一节空隔间。
- 埃德蒙此前把皮箱推上行李架、坐下，从内袋摸出装在翻盖龙皮皮套里的手机，已拨开铜扣，屏幕亮着；第4幕末女孩撞见他“对着口袋动嘴皮子”。
- 本幕中女孩把藤箱推到座底坐下，抱起胳膊，盯着他膝头的皮套追问他念的是什么咒。
- 本幕结束时：埃德蒙把手机翻面扣在膝上，露出深灰龙皮纹，改口称是家传的东西、上面有字、他照着念；女孩仍坐在隔间里，问话未了结。

## 逐句表

| 句号 | 复述 | 结论 | 说明 |
|---|---|---|---|
| 5-01 | 女孩问埃德蒙：你刚才在跟谁说话？ | 通过 | 对白口语；说话者由上段“她抬起头”承接，唯一候选是女孩。“说话”预设她听到声音，与 4-04“默念”的关系见 SR-5-09-1 |
| 5-02 | 埃德蒙答：我在练发音呢。 | 通过 | 对白口语，省略主语，说话者由问答轮次可判定为埃德蒙 |
| 5-03 | 埃德蒙接着说：刚背下来的咒语太拗口，我舌头总转不过来。 | 通过 | 对白口语；“舌头总倒不过来”属口语说法 |
| 5-04 | 女孩把藤箱往座位底下一推，（在他对面的座位上）坐下，可眼睛一直没离开埃德蒙膝头上那只皮套。 | 问题 | 不得不补：前文只写他从内袋摸出手机、拨开铜扣，没写把手机（皮套）放到膝头；第4幕末又写她看见他“对着口袋”说话，口袋与膝头位置对不上。坐在哪一侧也需自补（轻微） |
| 5-05 | 女孩问：（你念的是）哪个咒？ | 通过 | 对白口语，问句用句号属文风样本约定（样本“月月是不是该有我一份。”）；说话者由下句“啊？”与 5-07 推知是女孩 |
| 5-06 | 埃德蒙一愣：啊？ | 通过 | 对白语气词 |
| 5-07 | 女孩追问：你刚才念的是哪一个咒语？ | 通过 | 对白；问句句号同 5-05 |
| 5-08 | 女孩抱起胳膊说：一年级的咒语我在开学前就全背完了。 | 通过 | 主语“她”唯一女性候选；她已把箱子推开，双手空出可抱胳膊 |
| 5-09 | 女孩接着说：（一年级咒语里）没有一个是（你刚才念的）那个腔调。 | 问题 | 互相冲突：她能判断“调”，必须听见了声音；但 4-04 写他是“默念了两遍”，4-09 她撞见的是他“动嘴皮子的脸”（视觉）。读者会回头核对他到底出没出声 |
| 5-10 | 埃德蒙把（装在皮套里的）手机翻过来，屏幕朝下扣在自己膝上，（朝上的一面）露出深灰色的龙皮纹路。 | 问题 | 只能猜：皮套是翻盖式、铜扣已拨开，翻面时翻盖如何处置没交代，为何不直接合上翻盖；“露出”暗示龙皮纹此前被遮住，但 5-04 女孩已在盯着“那块皮套”看，皮面本就可见。另：前文皮面上的是他描的“云纹”，此处只写“龙皮纹”，读者可能分不清是皮料纹理还是那圈云纹 |
| 5-11 | 埃德蒙说：这是家里传下来的东西，上面有字。 | 问题 | 只能猜：他刚把有屏幕的一面扣下去，朝上的只有龙皮纹，“上头有字”的“上头”指哪一面、字在哪里，读者需猜（屏幕？皮面云纹？）。另：5-02/5-03 他说是“刚背的咒语”，此句改成照家传物上的字念，前后说法不一，读者会停下判断这是人物临场改口还是写漏 |
| 5-12 | 埃德蒙说：我（是）照着（上面的字）念的。 | 通过 | 对白口语，承前省略宾语，补全后无歧义 |
