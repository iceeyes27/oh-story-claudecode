# P0 修订与首稿试验计划

日期：2026-10-06。授权：作者“按建议实行。”。范围为本次审阅建议中的规则、模板、技能、生成适配及有限质量试验，不含正式小说采用、发布或 Git 提交。

## 实施与保留边界

先更新三层细纲与写手创作护栏，保留必要事件、原文供给、旧细纲语义及简短语义自检；读者体验仍按场景功能整体审阅。再统一三类默认自动修及裁决缺席边界；原意明确不要求措辞唯一，作者已授权的优化继续执行，未处理严重问题保留未决。展示先给导航，仍默认详细交付。

标准文件名暂保留，补充规则不合并到编辑输入。正式正文、已确认细纲、场景状态和旧评测不修改。原有 README、新手指引和 .DS_Store 用基准清单核对未变。变更前来源已保存，生成副本只由 setup 更新。

## 工程检查

来源检查后按既有双宿主部署生成适配（保留 quality 策略），运行来源、副本一致性、doctor 与完整 unittest 回归。新增检查仅验证创作护栏词语泄漏检测的真实行为；不以匹配规则措辞的测试证明文学质量。运行技能前言校验、差异格式检查，并核对三层标题可被现有细纲解析识别。doctor 只能证明配置与启动命令检查，不能代替实际宿主信任或 Windows 会话。

## 单场旧新对照

先完成一场历史书稿材料的隔离重创作对照，再交作者判断；本轮不自动推进第二场。材料取自已有 K02 真实原稿样本：保留父亲进门的前文，只按同一组事实和必要事件写接包、扶坐、准备热水的当前场片段。所有输入在开读前冻结哈希；旧写手收旧细纲与旧语文规格，新写手收语义相同的三层细纲与创作护栏，前文、事实、文风样本、字数参考完全相同。两位写手独立新上下文，继承同一宿主配置，不读对方输出、目标原稿后半或评测答案。

这是协调器根据已读原稿准备的历史重创作与提示组织试验，不是未见真实续写保留集，也没有作者事先认可的新增规划。共同事实中明确单只铜壶的状态，避免沿用历史原稿的壶接口疑点；这项共同补核不能算新版收益。没有本场独立的作者修改偏好材料，不伪造作者判定。

旧新输出完成后保留纯正文和写手回报，随机映射阅读版甲乙。独立编辑、裁决、事实、角色、自然度和结构审阅均使用同一套新版评价口径，首轮互不接收其他角色意见；编辑与裁决不收细纲、事实或版本标签。需要修正则保留首稿、根因与修后版本，再做独立复读；不把转为建议的发现从指标里删除。未确认作者方向的文学建议不自动执行。

记录每版初稿的未决严重问题、确定性问题、文学建议、必要事件与出口证据、保护项误改、模型执行耗时和调用数。原始报告与分歧全部保留。作者首次交付采用意愿、对白/节奏读感、修改轮数与判断负担保持待作者判断；单场结论只能支持继续试用，不能宣布普遍提高首稿质量。

每个子任务在开读前记录派发与输入版本，原则上限时 240 秒，异常至多重试一次，保留失败记录。每批不超过三个并发角色；等待期间持续提供简短阶段更新，不无限等待或扩大样本。工具输出齐备、模型读感与作者采用分开报告。

## 边界复核

对多种等义赘字修法、原意不明指代、删除必要事实、S2 文学建议、作者授权对白优化、裁决缺席六类情况逐条核对新流程的真实决策。保留模型原始意见，争议回到规则与作者范围，不为对齐评分改答案。旧细纲继续核对已确认事件及兑现关系；不把语法兼容当成语义迁移完成。
