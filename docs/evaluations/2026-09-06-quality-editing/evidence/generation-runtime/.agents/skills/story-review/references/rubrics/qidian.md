# 起点中文网审查参考

先按 `quality-rubric.md` 确定题材、本书承诺与章节功能。平台可以容纳不同故事，不默认所有书都有升级或金手指。

| 观察项 | 适用时检查 | 不适用或可保留 |
|--------|------------|----------------|
| 能力与成长 | 本书承诺能力成长时，进展、试错、限制和代价是否成立 | 无升级线时 N/A，不规定多少章必须突破 |
| 特殊能力 | 已有能力对当前行动有关系时，知识与限制是否一致 | 无金手指或本章未用时 N/A，不要求每章提及 |
| 长线期待 | 人物、世界、目标或关系是否按本书节奏持续展开 | 观察、过渡、休息与余波可以积累，不设情绪节点字数配额 |
| 视角安排 | 当前视角是否承担读者可理解的作用，切换是否清楚 | 配角章、群像章可成立，不要求主角每章出场 |
| 兑现与承接 | 已承诺的结果是否兑现，下一步与当前后果是否相连 | 不要求每章制造未解问题，阶段收束也可成立 |
| 篇幅约定 | 采用作者已确定的篇幅与更新安排，报告实际偏差 | 未提供更新计划时记录未确定，不把日更计划当正文质量 |

适用项用 PASS / WARN / FAIL；不适用项标 N/A 并说明原因，证据不足单列。仅作 advisory，严重度来自具体阅读损失；不从章尾钩子或情绪连续性推算追读比。修改建议优先选择 1～2 个最高阅读损失，不为符合平台模板补升级和配角反应。
