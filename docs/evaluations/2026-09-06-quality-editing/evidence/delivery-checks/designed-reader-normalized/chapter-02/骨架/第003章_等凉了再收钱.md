# 第003章 等凉了再收钱

## 章节契约

- 来源细纲：大纲/细纲_第003章.md
- 最终正文字数目标：2500 字
- 目标情绪：事业；急于结单到凭结果被信任
- 读者获得：看懂修好后还须等柜温的原因，获得鱼货回柜与服务费结清的兑现，看到客户开始找小满本人。
- 禁止提前释放：不靠父亲解决问题；不新增故障危机；不直接许诺排风扇必能修好；维修共300，临存另30。
- 开场动作：小满带合适配件回市场，在何桂香同意下断电完成维修。
- 章尾钩子：陈望请她明天看时好时坏的排风扇，她只约看现场；当天账单结清后记下具体下一单。

## 场景 1

- 时空与人物：下午，鱼摊；小满、何桂香
- 场景目标：完成修理并让结果可靠，既想收款又不省掉等待
- 阻力：柜子刚恢复运转尚未足够冷，何桂香想把货留在自己眼皮下，小满也盼早结单
- 动作链：带件归来 -> 断电修理完成 -> 通电降温 -> 何桂香提出付尾款搬货 -> 小满暂不收钱说明实际标准 -> 等候中谈到叫老周还是叫小满 -> 柜温及运转稳定
- 结果变化：冷柜实际达到存货条件；何桂香能理解小满为何不急着拿钱，开始按她自己的名字称呼
- 情绪转折：修复后的轻松 -> 等待中的急切 -> 用结果换来踏实
- 信息/伏笔：不写具体带电维修步骤；父亲不参与；称呼变化只兑现本次独立接单
- 台词意图与潜台词：何桂香催促因惦记自己鱼货，不是刁难；小满不端师傅架子，坦率承认想拿钱但还没到收尾节点
- 正文字数预算：1500 字

## 场景 2

- 时空与人物：傍晚，包子铺后间、鱼摊、修理铺；小满、何桂香、陈望
- 场景目标：归还临存空间、结清此单，接下可验证范围内的新预约
- 阻力：收尾仍要把鱼货搬妥、借位清干净；小满不能因为被信任便预报下一次必修好
- 动作链：三人搬四箱回鱼摊 -> 清理归还临存位置 -> 何桂香付二百元 -> 说愿介绍小满生意 -> 陈望约看排风扇 -> 小满只约明天看现场 -> 记清已收款和新预约
- 结果变化：鱼货回柜、维修费结清、借位归还；获得口碑与排风扇查看预约
- 情绪转折：忙碌收尾 -> 熟人肯认自己 -> 带具体下一单结束
- 信息/伏笔：总维修300，余款200；临存30已另付；排风扇仅查看预约
- 台词意图与潜台词：何桂香用付款和介绍表示认可；陈望先说明时好时坏，小满先看再说的口吻延续清晨
- 正文字数预算：1000 字
