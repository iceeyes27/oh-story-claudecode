## 决策路由

| 你在做什么 | 查阅哪个模块 |
|-----------|-------------|
| 写完正文后做去AI自检 | 先通读定位阅读损失，再选对应模式；不默认全量读取 |
| 编辑已确认的问题段 | 只查对应模式与范例，并保护原文事实与声线 |
| 检查是否用了禁用词 | 禁用词与句式速查 -> AI高频词（模式1） |
| 用户明确要求分遍编辑 | 系统性去AI三遍法中的适用视角，不自动叠加轮次 |
| 检查章尾是否有总结升华 | AI写作指纹 -> 章末总结体 |
| 判断情绪表达是否重复或不清 | Show Don't Tell原则 + 去AI味补充技法 |
| 快速扫描全章质量 | 快速自检口诀 + 质量维度检查 |

## 指令语气

本文件中的模式是候选线索。扫描实际 severity、来源与作用域由共享实现输出，不在参考文档另设 blocking 类别。作者明确禁令遵守已验证的来源与作用域；语境和密度提示先核对阅读损失，有功能可保留。规则加载失败先排查规则输入，不当作正文问题。

普通编辑首轮只处理 1～2 个最高阅读损失，一轮局部修订后回读；确定性阻断另外定点修正或报告。目标解决就停止，未改善可恢复原文。同一问题仍在时查输入、细纲、信息顺序或执行根因，不按词频、心理比例和标签密度开启全章重写。

## AI写作指纹（语境复核）

### 高频AI用词

> 完整禁用词表见 [banned-words.md](banned-words.md)

**补充线索**（用于定位语境，不扩充作者禁令）：

| 类别 | 替代原则 |
|------|---------|
| 抽象升华词（命运、宿命、注定） | 判断是否重复盖章；人物偏见、世界设定或有效反思可保留 |
| 万能比喻（像潮水般、如闪电般、仿佛春风） | 是否遮住信息或反复解释同一意思；适合声线且有作用时保留 |

### 引号只承载真实引用，不给普通名词加戏

不要用双引号给普通名词、常见动作或作者临时概括的概念做“引号强调”。这类写法会把没有特殊含义的词硬包装成术语，连续出现时尤其像模型在替读者划重点。`check-ai-patterns.js` 的 `quote-emphasis-tic` 只负责提示，最终按语境判断。

- **应改**：所谓的"机会"、完成这次"蜕变"、找到真正的"答案"。这些词若只是普通语义，直接去掉引号，用事件本身体现分量。
- **应保留**：角色对话、逐字直接引用、书名/篇名、确有设定含义的代号，以及手机消息、公告、系统播报等场内载体展示的原文。
- **边界**：第一次定义术语时可以用引号，但后文不要反复加；讽刺、反话或角色刻意咬重音时可以保留，前提是上下文能看出是谁在强调、为什么强调。

### 章末总结体

先核对本章承诺与视角：总结、感悟、哲理、预告并不因形式自动判错。重复已知结论、无依据拔高、越界泄露或替代了应有的兑现才修；角色当下认知、有效反思、批准的前瞻与余韵可以保留。动作、对话、明确后果、内心或开放问题都可收束，不统一换成安静物件或强悬念。

### 叠加式描写（同一动作掰开写三遍）

**检测模式**：一个动作/情绪先写发生，再补感知细节，再补身体反应，分三段依次写完。读者看到的是同一个动作被掰开写了三遍。

**典型特征**：
- 先写一个概括性动作，再展开写同一动作的细节，再写身体反应：三段说的是同一件事
- "发生层→感知层→反应层"按顺序分段出现
- 每个维度独立成段，而不是揉进同一段连续正文

**需复核示例**：
> 林父低着头，左手把文书压住，右手拿笔，往纸上落。
>
> 手从肘到腕都在抖。
>
> 笔尖在纸上停了停，写了一横，又停。那个"林"字的撇写歪了。

→ 手抖、落笔与停笔可能有递进；签字犹豫本来就是场面重点时，分段可以成立。只有连读确实在重复同一紧张、延迟结果时才合并。

**可选处理**：如果三个段落重复同一瞬间而拖慢阅读，可合并已有信息；分段有停顿或焦点变化时也可保留，不要求凑齐三个维度：

> 林父左手压着文书，右手拿笔往纸上落，笔尖一触纸面就偏了，从肘到腕止不住地抖，那一横斜着拖出去。

→ 发生、感知、反应在一段里同时呈现

**处理原则**：保留有功能的情绪细节，把同一瞬间的重复描写合并成连续画面。若合并后明显变薄，优先恢复原文中有功能的信息，或把既有信息改成更自然的动作/对话表达；不要新增原文没有的情节、设定、关系或时间线。

## 核心规则

> **句长以规则 3 为准**：规则 1-4 和本文件其他地方的「短句 / 拆短 / 能删就删」说法，与规则 3 冲突时按规则 3 执行。

### 规则 1：段落密度诊断

段落长短没有固定优劣。检查重点是朗读和手机阅读是否卡顿：

- 一段通常只承载一个动作、一个信息变化或一组紧密相关的反应。
- 逗号串太长、多个完整动作挤在一段里，读起来需要换气时，按动作或信息变化拆开。
- 连续短段碎成提纲时，合并同一镜头内的相邻句，让画面保持连续。

```
过密：他看着窗外的雨，心中涌起一股说不清的感觉，这些年走过的路和很多已经忘记的事都在这一刻涌上心头。

更自然：他盯着窗外的雨，雨从下午下到天黑。
"你还在想她？"老刘问。
他没说话。
```

### 规则 2：按信息功能选择表达

动作、对话、心理、直写情绪、物件和后果都可以推进场面，不按固定循环轮换。先问读者此刻缺什么：缺选择就写行动，缺立场就写台词，缺推理就保留必要心理，缺强度就落到具体后果；一句直写最清楚时直接写。

- “他很紧张”若只是重复已知情绪可删；若读者需要明确烈度，可以保留或接任务失败、判断改变等具体后果。
- 身体反应只在伤势、生理限制、人物习惯或动作结果有信息时使用，不把每个情绪词翻译成手心、指尖、呼吸。
- 心理段数由视角、题材和当前判断链决定；完整推理不能为追求短促而截断，重复结论才压缩。

### 规则 3：句长跟随功能、视角与本书声线

没有全题材通用的“默认逗号长句”或“默认短句”。先读 `设定/文风.md` 与题材正文卡，再让句法服务当前镜头：连续动作/判断需要保持因果时可以写长；重拍、惊觉、对话和视角贴近时可以短；两者都不应机械复制。

**需要复核的不是长度本身，而是信息是否被句法损坏**：
- 多个 ≤5 字片段连排，删掉主语、连接或结果，读者无法恢复谁为何做什么；
- 通篇 3-8 字句像提纲，人物情绪和因果只剩标签；
- 长句塞入多个时间层、视角或因果，主干无法定位；
- 一长一短机械交替，或全章同一节拍，暴露模板而非人物/场景需要。

> **语料校准只作参考**：七猫长篇样本的逗号间隔和整句均值能帮助发现异常，不是生成配额或硬门。短篇、悬疑、喜剧、意识贴近与作者自定义声线可以显著偏离；最终由本书文风、清晰度证据与盲读效果裁决。

### 规则 4：口语化表达

- 允许用俚语、粗话（符合角色身份）
- 语域服从说话人的身份与场合；正式发言可以用书面语，私下交谈别无故端着
- 叙述服从本书声线；确认修辞遮住意思时再改清，不把视线词统一换成眼珠或身体动作
- 短语优先于成语（"无可奈何" -> "没办法"）——只管对话和贴角色声口的叙述；旁白常用成语（不动声色、心不在焉一类）照留

## Show Don't Tell 原则

| 当前需要 | 可选表达 | 不应机械处理 |
|----------|----------|--------------|
| 明确人物立场 | 必要心理或直写 | “她不想答应”可以保留，不必补手抖 |
| 跟随行动后果 | 展开原文已有的失败、选择或物件变化 | 不为展示紧张新增摔杯、掀桌等行为 |
| 已理解的承接 | 简写、并句或删重复 | 不把每段都扩成感知与反应 |
| 角色主观感受 | 直说、比喻、内心或留白 | 不能因为文学化或“感到”起句就判错 |

**核心方法**：在行为、细节、对话、心理、直写和后果之间选最清楚的一种；只有原句空泛、重复或无证据时才换表达，不设单向替代公式。

## 质量维度检查

### 1. 核心一致性（权重最高）
- 剧情是否与大纲/前文一致
- 人物行为是否符合人设
- 设定是否有前后矛盾

### 2. 表面改写（防AI指纹）
- 模式命中是否实际误导、重复或拖慢，正常用法可保留
- 章尾是否兑现本章功能，有无重复盖章或越界信息
- 心理是否有新认知、选择或关系作用，而非按长度判错
- 段落是否按戏剧单元/镜头自然断开，避免机械单句成段或为凑短碎成提纲（网文段落规则）

### 3. 格式一致性
- 对话格式统一：按项目/平台约定保持同一引号风格；知乎盐言短篇可用「」
- 标点节奏匹配语气：迟疑、打断、未尽、强调成立时保留相应省略号、破折号或问叹号；只处理无功能堆砌和错误语义，不统一换动作或句号
- 场景切换有明显标记
- 时间线清晰可追踪

### 4. 可读性
- 是否有连续多个长句压住阅读节奏，且缺少动作、对话或短句换气
- 对话是否口语化
- 是否有未解释的生僻词/设定术语
- 当前节奏是否服务本章功能，平稳可以成立；不按长短或快慢交替模板修文

### 5. 逻辑连贯性
- 角色动机是否合理
- 事件因果链是否清晰
- 时间线是否对得上
- 角色的知识范围是否合理（不能"开上帝视角"）

## 快速自检口诀

```
意思相连，自然来断段。
对话要像人说话。
心理直写看作用。
结尾兑现本章事。
打斗跟清楚后果。
日常相处有意味。
```

> 网文段落规则：按戏剧单元/镜头/一件事结束自然断段；短段快读，长段承载完整推理、氛围和情绪链，避免机械单句成段或通篇同长度。

---
> **番茄高分样本校准**：番茄正文更接近“手机端短段 + 自然虚词 + 场内动作/对话推进”，不是机械指标达标。番茄高分样本 305 章窗口显示：段落中位约 23.5 字，50-60 字行宽平均只占 5.1%；平均对话占比约 20.6%，对话≥50% 仅 3/305，开篇对话 59/305；`地/得` 305/305、`很` 275/305、`像/好像/仿佛/如同` 267/305、顿号 176/305、省略号 281/305。结论：这些只能按语境复核，不能做 0 容忍硬禁令。
>
> **反投机边界**：不要为了“反检测”强制每句换行、把 `……` 改成 `........`、把 `地/得` 全改成 `的`、禁用所有顿号/“很”/“像”、强行开篇对话或按三番四证重排章节。去 AI 味是润色，不是结构重写；除非用户明确要求重写，否则不改变章节顺序、伏笔分布、对话占比和人物信息释放节奏。

### 正确替代示例

- “她很伤心”若是此处最准确的表达可以保留；情绪已由上下文成立则删重复，不补攥袖口。
- “好的。”他说道。若标签用于识别说话人就保留；双方话轮已经清楚才考虑省略，不凭空增加门卡动作。
- “他深吸一口气”在运动换气时可保留；无功能反复垫在对白前才删并。

## 10 种 AI 写作模式检测

### 模式 1：AI 高频词

“仿佛、不禁、心中暗道、沉声道”等只能提示复核；普通语义、人物声线和场景功能成立时保留。具体作者禁令按共享规则的来源与作用域执行。本节不提供禁词到动作的替换表。

### 模式 2：弱化副词泛滥

“微微、淡淡、缓缓、轻轻”密度只帮助定位重复窗口，不设每千字上限，也不把单次真实幅度或轻重描写判成 AI 签名。删掉会损失强度或动作结果时保留。

### 模式 3：意义膨胀

当“意义深远、前所未有”等结论没有证据或重复已有感受时改清；具体影响、直接判断与原句保留均可，不必须新增后果。

### 模式 4：万能结论

“未来可期、前途无量、充满希望”要看是谁的判断、此时为什么说。只处理无功能的旁白盖章，角色偏见、愿望和真诚表态可以保留，不统一换悬念。

### 模式 5：论文体段落结构

“不难看出、由此可见、事实上、综上所述”是否脱离本书语域或重复解释，需看上下文。专业发言、推理和角色口气成立时保留，不能仅凭起句判错。

### 模式 6：书面语连词泛滥

连词是否把关系说清、造成冗余或错配语域。必要的于是、因为、与此同时等连接保留；不按词类或数量删一半。

### 模式 7：三连排比癖

重复句式是否增加排除、辩解、讽刺、递进或声线作用。`formulaic-parallelism` 等 advisory 只作语境复核；无新作用才压缩，不固定保留几句。细纲多个字段重复同一要求，正文可合并兑现，不逐项复述。

### 模式 8：解释腔 / 上帝视角 / 安排感

先核对批准的 POV 与信息边界，不强制所有题材深度限知。**首次交代闸**：首次必要动机、关系、能力来历和事件因果不算解释腔，应保留或补清；前文已给足、无新增作用的重复说明才可删。原句已经清楚就不用再改成动作。角色主观判断、第一人称讲述、全知叙述与批准的前瞻各有合法功能。

| 表现 | 语境判定与修法 |
|------|----------------|
| 反复解释 | 读者已懂后又以对白、心理和旁白重说，删并没有新作用的一处 |
| 知识越界 | 指出当前 POV 不可能知道的具体信息；按已批准边界核对，不按“多年以后”等词形判断 |
| 替读者定性 | 判断是否有角色偏见、关系认识或有效反思；有功能保留，空盖章才删并 |
| 动机与结论链 | 核对是否提供关键选择依据；必要推理可完整直写，重复结论才压缩 |
| 载体信息 | 原有手机、公告、规则或物证按其实际形式保留；不为去书面腔误改内容含义 |
| 生造任务卡点 | 没有原文任务或缺口时不加手续、门禁、排队等流程；已有卡点也不逐步展开凑篇幅 |

“这是储存记忆的装置”可以在读者需要理解蓝晶时直写；如果原文已有使用场面，也可由既有行动说明。不能为避免解释新增装置效果，更不能只丢生词让读者猜。第一次说明与重复解说分开处理。

### 模式 9：过度压缩（电报体）

去AI味删过头的反向指纹。每句都压到最短、结构虚词扫光、每个动作都补一个「了下/了一下」式轻反应。单句看着干净，连读像提纲，读者的体感是"不流畅、喘不上气"。删减的目标是删废话（解释、注水、凑数），不是删中文的自然冗余。

| 表现 | 修法 |
|---|---|
| 非峰值叙述句也全部压成最短句 | 重拍句（动作/情绪/悬念峰值）保持短促；铺垫、过渡、日常动作写成自然白话句，保留 了/的/就/的时候 等结构虚词 |
| 「扯了下/停了一下/拍了两下/松了半圈」式微动作高密度复现（check-ai-patterns.js 报 micro-action-tic） | 合并动作，换具体细节；不是每个动作都要接一个反应尾巴 |
| 强调副词（连/才/又/只/全/反而）被扫光 | 删前判语义：承担人设、对比、讽刺义的保留（"才二十三天"删掉"才"，人设强调就反了） |
| 对话语气词归零 | 按角色保留自然低频的 呢/吧/啊；也不反向猛加——人味来自结构自然，不是聊天腔 |
| 叙述残留公文/文言腔（不得/须/未/已然/当前） | 换白话（不能/要/还没/现在）。系统公告、规则条文、面板播报可以保留冷硬功能；若 `system-notice-formality-tic` 报警，只在原载体内白话化一部分，不改成叙述者解释 |
| 长文本里短叙述段成片（`overcompressed-prose-tic`） | 不是把所有短段拉长。先人工通读：重拍短句、密集镜头如果上下文顺，就保留；只处理读起来像提纲的过渡句，把它们并回同一镜头，让读者顺着动作、空间、因果读过去 |
| 引号外叙述低连接密度且缺中长句（`low-connective-density-tic`） | 不是全局补“的/了/就”，也不处理台词/弹幕/系统播报的天然短促。先找叙述层读起来像提纲/电报体的断裂处，恢复必要连接、指代和中长承接句；有中长句链条的低功能词文本可保留 |

自检：删完连读一遍，读感像提纲或流水口令，就是删过了——把非峰值句恢复成自然白话，不是接着删。

本模式防止修订损害理解：必要的原句、心理、连接和声线可以恢复。普通表达按语境判断，不因被某个模式点名就继续清洗；作者明确禁令仍按来源和作用域执行。

### 模式 10：二修伪自然（油腻倒装 / 监控动作清单 / 对话指标化）

一些“反检测提示词”会把文本推向另一种模板：为了提高突发性而乱倒装，为了真人感而机械加口误和脏话，为了手机阅读而强制每句换行，为了对话占比而把心理和叙述硬改成台词。这些不是自然网文，是二修痕迹。

| 表现 | 修法 |
|---|---|
| 无功能倒装 | 伴随动作前置可以成立；只改主语错接或明显不合声线的句子，不为换句首新增物件和身体反应 |
| 监控摄像头式动作清单 | 同段连续“伸手拿起、取过、挑开、放下、转身……”像步骤表。合并琐碎动作，只保留有情绪、情节或空间功能的动作；必要时用角色犹豫、误判、旁人反应或环境反馈做缓冲 |
| 高压场景误脱水 | 冲突、追杀、打斗也要保留必要主体、空间和因果；各类场景只压缩重复，不删理解所需的连接 |
| 吃字漏词 | 去 AI 后如果动词没有对象、动作指向不清、读者不知道谁对谁做了什么，要补回必要宾语、承载物或物理反馈；中文可省略，但不能省到像提纲 |
| 对话指标化 | 不为凑 50%-60% 对话占比硬扩台词。台词只在角色真会说、此刻必须说时增加；长对白可拆动作，解释性对白优先压成冲突、回避或半句信息 |
| 硬格式投机 | 不强制每句换行、50-60 字一行、不把省略号改成英文点、不把 `地/得` 全改错。按平台和项目既有格式走 |

`check-ai-patterns.js` 的 `action-list-tic` 只提示监控动作清单，不是 blocking。功能性打斗/追逐/仪式步骤若动作链本身承担信息，可保留或标 `[需复核]`。番茄高分样本中该类命中为 0，因此适合作为“需通读”的风格提示，而不是硬性失败项。

#### 工具提示处理

`check-ai-patterns.js` 是本地写作 lint；沿用实际 severity、来源和作用域，不在说明中另定类别。确定性错误和有来源的作者禁令按原因处理，规则加载失败先排查输入；advisory 不作完成门槛。用户贴其他工具报告时，只把能落到正文的句式、段落、词汇问题转成具体修改点，不写“0% AI / 100% 真人”或“固定公式”，也不围绕分数反复微调。

语境提示不高于正文功能。参考文本中的“仿佛/非常/感到”等普通表达先看实际作用；不要机械补词、故意错字或按题材套壳。

**去 AI 味补充判断**：
- 优先处理已确认的阅读损失；“他意识到 / 这意味着”等句子可能是首次关键推理，也可能重复已知结论。前者保留，后者删并，不以起句决定修法。
- 场内载体优先：原文已有手机、屏幕、公告、门牌、表单、账单、物证、规则行时，保留为角色看见/读错/处理的文本或物件；不要把同一信息改写成叙述者解释规则。
- 白话但不注水：少用精致戏剧反应短语（头皮发紧、眼皮一跳、心口一沉、胃里翻涌）连续替代剧情推进；能写普通动作/普通感觉就写普通动作/普通感觉，并保留自然的“的/了/就/但是/已经/之后/没有”等连接。
- 题材文风优先：文风对标有帮助，但必须来自目标题材/本书文风指纹；不要把盘龙腔、旧网文腔、第一人称声口等当成跨题材万能修法。
- 不要当通用修法：单纯加标题、补物件、补动作尾巴、拉长/压短句子、增加排队/门禁/记录体，不能替代具体的情节、视角和语言问题处理。

#### 把提纲句写成连续段落

当文本已无 blocking / 明显 advisory，但读起来仍像提纲时，只处理断裂处：

1. 标出读起来像逻辑报告的段落：连续出现“他知道/他明白/这意味着/真正的问题/必须/需要”等判断链，却缺少当下动作、物件或对话反馈。
2. 补清缺失的主体、依据、选择或后果；原文所需的推理和直接判断可以保留，不把所有结论换成物件或动作。
3. 只在断裂处恢复自然连接和结构虚词；不设比例目标，不机械补连接。
4. 系统公告、规则条文、面板播报可以保留冷硬短句；`system-notice-formality-tic` 报警时，只在原载体内白话化一部分硬规则词，或让角色当场看到具体后果，不改成叙述者解释。

`overcompressed-prose-tic` / `low-connective-density-tic` 的具体修法：

1. 圈出连续短叙述段，逐段标注功能：爆点/反转/恐惧重拍、密集镜头可继续短；铺垫、空间、因果、动作承接应并回同一镜头。人工读着顺，就不因该 advisory 继续拉长。
2. 合并时优先补“动作顺序、空间方位、因果承接”，例如“抬头时/门外/已经/还/就/被”，而不是给每句硬塞“的/了/就”。
3. 合并后核对意思与声线；只删无新作用的重复，不按“仿佛/感到/非常/好像”词形再次清洗。

复核处理：相关提示处理后读感仍不稳，停止自动微调，核对根因与原段；较差改法恢复原文，额外重写需要具体证据和相应授权，不以提示清零决定完成。

示例：

```
过度压缩：
林遥抬头。
雨棚外的街灯灭了。
风也停了。
柜台上的纸杯晃了两下。

读顺后：
林遥抬头时，雨棚外的街灯正一盏盏熄下去。风忽然停了，柜台上的纸杯还在原地轻轻打转。
```

## 系统性去AI三遍法

这是三个可选的观察视角，只在用户明确要求分遍编辑时按授权范围使用；普通编辑不因“AI 味等级”启动整章三遍，也不把三遍叠成生成次数。研究 P0/P1 继续服从冻结协议与不可变边界，本节不追加调用或修订许可。

### Pass 1：去泛化（Strip Generic）

识别空泛且重复的结论、模糊指代和没有作用的修饰。保留首次必要信息与原文事实；能直接说明就直写，不统一补动作或删连词。没有可指出的阅读损失时不改。

### Pass 2：去书面化（Cut Professional Diction）

检查语域是否符合说话人与场合，压缩非必要的术语解释。正式发言、行业操作和角色既定声口可以保留专业表达，不因词类出现就换白话。

### Pass 3：回自然感（Restore Natural Presence）

回读主体、连接、人物意图、声线和阅读回报是否仍成立。恢复被误删的必要信息或原句；不为自然感新增停顿、粗话、口头禅、感官细节或长短交替。

### 选择与停止

普通编辑首轮选 1～2 个最高阅读损失，一轮编辑后回读；目标解决即停。额外分遍只在明确授权范围内进行，不能以“仍有可改词”无限续轮；未改善时保留原文并报告根因。记录变化与未解决项，不声称去掉某个百分比的 AI 味。

### 自检清单

- 原问题是否缓解，是否引入理解、事实或声线损害？
- 需要保留的人物意图、关系、因果与原句是否还在？
- 这次改动是否值得，还是只让表面词形变化？

## 去AI味补充技法

### Show vs Tell

直写与展示都可成立。人物目的、判断和必要心理可以直说；行动后果需要跟读时展开原文已有的动作。情绪已成立就不必再命名，也不必添身体反应；实际选择不能靠换一种修辞代替。

### 心理描写润物细无声

按本书视角和人物需要保留内心，篇幅由信息与体验决定。“她感到”“她意识到”不是缺陷判据；无新作用的结论复述才压缩。括号、停顿和反思是否有效由声线与上下文判断。

### 代入感检查

- 读者能否凭正文理解人物为什么这样做？
- 本书需要对手时，其阻力是否真实；无对手的日常场面不补反派。
- 行为、语言和思考是否属于这个人物？
- 信息差、相处或余波是否服务本章体验，而非强制造情绪波动？

## 改写范例库

以下只说明同一信息的表达选择，不能把范例的物件、动作或态度移植进正文。按原文事实和当前功能决定保留、删并或局部重组；更短不自动更好。

### 情绪外化范例

- 原句：“她很伤心。”必要直写时保留；前文已完整表达时可删重复。不能默认补“攥皱袖口”。
- 原句：“他手在抖，笔尖刚碰到纸就偏了。”动作失败已有信息，可保留；不再补一轮心跳、喉咙和呼吸来说明同一紧张。
- 原句：“她感到一丝失落，心仿佛被什么东西揪住了。”若只是重复表达，可压成“她很失落”；不擅自新增锁手机等动作。

### 场景描写范例

“屋里飘着一股腥味”在真实鱼摊可以保留；“冰冷的鱼”描述温度也可成立。环境只有在无新作用地铺陈时才压缩，不能为去词新增钟声、时间或天气变化。

### 结尾改写范例

“她知道明天还得再来一趟”若交代已批准的下一步可以保留；前文已经说过、结尾只是复述时才删并。明确下一步、有效反思和余韵都不必改成关门、熄灯或掐烟。

### 节奏调整范例

- “他推开木门，屋里昏暗，墙角堆着几个落灰的箱子。”连续观察可以保留，不能为短句指标强拆。
- “门开了。里面没人。”短促且指向清楚也可保留，不能为反电报体强加反应。
- “他抬头。她抬头。他低头。她低头。”若连续动作没有新作用，需回到这场戏的意图删并；不能只换几个动作词算修好。

## 冲突对话改写范例

### 温和表达与强烈表达

“能不能先考虑一下我的感受？”与“你眼里还有我吗？”代表不同态度和关系。前者可以是真人在克制，后者不能作为统一升级答案；只有原文人物意图确实不匹配时才调整。

### 必要解释与回避

“我没答应，因为那笔钱不够付房租。”若首次提供决定依据可保留。不能为了对白不完整把它改成“你能怎么着？”或凭空增加重放茶杯的动作。

### 对话情绪五级递进范例

客观陈述、建议、指责、命令和羞辱可用于比较人物策略，但不是由弱到强的质量阶梯。当前角色怎样说取决于关系与目标；修订不能未经授权改变其意图、承诺或行为后果。

### 震惊分层改写范例

“他张了张嘴，没说话。”可能已经足够；若原文只有一人的反应，不新增全场手抖、后退与拍摄。多人反应确实改变局面时按原文因果保留，不强制逐层加码。

### 代入感修复范例

“她很害怕，不知道该怎么办。”可以是角色此刻真实的无助；只有本章承诺了行动却没有兑现时才回查原因。加锁门、录音会改变事件，应交给剧情修改而非自动去味。

## 质量检查清单

本轮按具体问题选择适用项回读，不要求每次逐项全扫：

- [ ] **段落控制**：段落按动作/信息变化断开，读起来不卡
- [ ] **标点功能复核**：`……`/破折号/双连字符逐处看打断、拖长、强调和人物声线；无功能才改，本书文风需要可保留
- [ ] **AI高频词扫描**：高频词只作候选；机械密集、误导或拖慢才修，普通语义用法不清零
- [ ] **弱化副词复核**：只处理连续堆叠和无信息重复，不设每千字统一上限
- [ ] **排比功能**：复沓、递进、排除或声线成立时保留，无新作用才压缩
- [ ] **工整否定清单已复核**：跨段「不是A / 也不是B / 只是C」及其他 `formulaic-parallelism` advisory 已连同台词逐条复核；功能性修辞可保留
- [ ] **语域与说明**：正式表达和推理可成立，脱离声线或重复解释才处理
- [ ] **无书面语连词堆砌**：无"于是乎/与此同时/从而/因而/诚然"泛滥
- [ ] **章尾功能**：行动、内心、反思、明确后果或余韵服从本章承诺，无重复盖章或越界信息
- [ ] **心理描写有功能**：段数服从视角与题材；没有重复结论、停住当前行动或替读者过度解释
- [ ] **情绪表达准确**：动作、台词、直写、物件或后果择最清楚的一种；不把直写情绪机械换成身体反应
- [ ] **对话合人物**：语域、意图与当下关系匹配，说话人可区分
- [ ] **标点不压平**：没有把质问、爆发、犹豫全部压成句号；也没有随机堆砌 `？`/`！`，或用 `……`/`——` 硬造停顿
- [ ] **表达方式有功能**：行为、细节、心理或直写都服务当前理解，没有为套 Show/Don't Tell 公式而删掉必要信息
- [ ] **句法服务叙事**：句长符合本书文风与当前场景；没有因极简/省略丢失主语、连接和结果，也没有长句塞入多层信息而失去主干；异常由证据和盲读裁决，不用数值硬改
- [ ] **detector advisory 逐条复核**：`micro-action-tic` / `stock-reaction-tic` / `abstract-summary-tic` / `cliche-density-tic` / `metaphor-density-tic` / `reasoning-chain-tic` / `system-notice-formality-tic` / `overcompressed-prose-tic` / `low-connective-density-tic` / `action-list-tic` 命中时按脚本给出的修法处理：先通读判断是不是机械复现，确属再改；功能性写法保留或标 `[需复核]`，不做同义词轮换、不机械注水
- [ ] **不做硬指标投机**：不为反检测强制每句换行、50-60 字一行、对话 50%-60%、英文点省略号，或把 `地/得` 全改成 `的`
- [ ] **任务卡点服从原文边界**：抽象总结若改成角色办事被卡住，必须来自原文已有任务/证据/手续/物件缺口；不新增原文没有的事件链
- [ ] **范围与停止**：首轮只选最高收益问题，回读未改善可恢复原文，不按档位继续清洗
- [ ] **对话自然度复核**：按人物与场合判断，不以消除书面语作为通过条件
