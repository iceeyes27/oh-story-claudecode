# 律政实务与证据合规 · 扫描法（司法实操与取证真实度）

从《法援律师：我专打赢不了的官司》全书证据链和司法实务体检中提炼固化的专项扫描 skill。
核心原则：**律政小说要有真正的行业厚度与证据法硬核感，杜绝外行/程序员视角对法律实操的生搬硬套**。

---

## 核心审查维度（六大实务硬伤）

### 1. 电子取证“自证清白”硬伤（最常见）
* **违规表现**：律师作为一方代理人（利害相关方），自己坐在电脑前插个移动硬盘、录屏、算文件 Hash，然后宣布“生成了谁都改不了的闭环铁证”。
* **实务硬伤**：律师自制电子数据在法庭上属于证明力极弱的「当事人自制视听资料」，对方律师只需质疑“操作电脑是否清洁、本地是否用代理/抓包篡改了前端响应”，证据就会被当场动摇。
* **专业改法**：
  - 改用 **国家授时中心可信时间戳（UniTrust/TSA）**、**司法区块链存证平台（存证云/权利卫士）** 进行一键固化与链上存证；
  - 或明确这是“**律师工作底稿与初步提取**”，必须同步向仲裁庭/法院递交《证据保全申请书》或申请公证处出具《公证书》。

### 2. 技术动作与行业术语错位（IT 视角的生搬硬套）
* **违规表现**：让文科律师去“逐行计算代码哈希值”、“解压数据包校验 MD5”。
* **实务硬伤**：律师不是算法工程师，律师审查的是**版本管理系统的业务与审批留痕**。
* **专业改法**：
  - 将“计算代码哈希”改为“**提取版本控制系统（GitLab/SVN）的 Commit ID、提交时间戳、Merge Request 记录及负责人（审批人）的线上签字留痕**”。

### 3. 证明力背书主体错位（“签律师工号/执业证号”当公信力）
* **违规表现**：律师在取证包首页签上自己的工号，声称“给证据赋予了法律效力”。
* **实务硬伤**：律师签字只是律师事务所/法援中心的**内部经办留痕**，对外不具备国家公信力。能够赋予公信力的是出证机构公章、公证员印章、或授时中心时间戳。
* **专业改法**：
  - 律师签名是作为《证据目录及提取说明》的**经办代理人签字**，证明力来源于附带的《时间戳存证证书》或第三方平台回执。

### 4. 调查取证权限越界（违背《律师法》与法定程序）
* **违规表现**：律师私自黑进对方数据库、调取公民通话记录、银行流水、住宿轨迹，且能在法庭上作为合法证据出示。
* **实务硬伤**：我国《民事诉讼法》《律师法》对律师调查取证有严格程序限制，涉及隐私与金融数据必须凭**法院调查令**或申请法院调取。非法获取的证据属于“非法证据排除”范畴。
* **专业改法**：
  - 描写中必须出现《律师调查令》、《调取证据申请书》，或由合法授权人（如死者法定继承人持身份证与死亡证明）依法向平台主张数据访问权。

### 5. 私了协议/免责条款效力一刀切（案情定性过于机械）
* **违规表现**：一见免责协议就简单写“绝对无效”，或一见签字就写“彻底死局”。
* **实务硬伤**：实务中争议的是《民法典》第 506 条“造成对方人身损害的免责条款无效”、重大误解、显失公平，以及民事免责不能免除法定义务（如劳动安全保障法定义务、养老照护法定义务）。
* **专业改法**：
  - 准确击穿：**“协议可以免除补充民事补偿，但不能约定免除企业法定的安全生产保障义务”**，或**“格式条款排除消费者主要权利、免除自身法定照护责任自始无效”**。

### 6. 法庭对抗口吻轻浮/违背辩论规范
* **违规表现**：律师在法庭上直接人身攻击、拍桌子、长篇大论背诵法律主旨金句。
* **实务硬伤**：法庭对抗讲求“质证三性（真实性、合法性、关联性）”、“证明目的”、“程序回击”。
* **专业改法**：
  - 严格按照“证据编号+证明内容+质证意见”推进，逼迫对方就具体时间戳和空白签字做事实解释。

## 典型正反案例速查

| 违规写法（外行/脱离实操） | 真实实务做法（专业硬核） |
|---|---|
| 苏青岚自己导出文件，计算哈希值，签上自己的工号封包钉死。 | 苏青岚通过**司法可信时间戳客户端**取证，实时将**GitLab 提交日志（Commit ID）及审批人时间戳**同步存证链，附上存证证书与经办人提取说明。 |
| 江澈私自查到了对方公司的内部服务器数据库日志。 | 江澈根据当事人账号留存的会话异常，向仲裁委紧急申请**《调取后台原始服务器日志申请书》**，迫使对方在举证期限内限期交出。 |
| 律师自己拍了段视频，说这已经是推翻不了的铁证。 | 律师将录像通过第三方存证固化，并与**门禁读取记录、派车单回执**做三方交叉验证，锁定事实矛盾。 |

## 扫描与执行工作流

1. **关键词筛查**：
   - 检索 `哈希|hash|自制|工号|封包|固定包|录屏|私了协议|调查令|存证|公证|时间戳` 等相关段落。
2. **实操合法性与证明力评估**：
   - 检查取证动作是否具备独立性与客观性（是否有第三方工具/司法令状依托）。
   - 检查证据术语是否符合法律专业表达。
3. **精准就地修复**：
   - 替换为：**司法可信时间戳（TSA）/ 司法链存证 / 仲裁调查令 / GitLab提交日志 / 提取说明与存证证书**。
