# 渐进式披露与流程恢复

协调器在选择 skill、恢复或切换阶段时读本协议，只载入当前所需规则与资料。不替代作者关卡，不新增可手改的流程状态。

## 核对当前位置

先依本次指令和已授权范围，再读必要索引：场景状态、修订任务、采用 journal；导入另查清单。先确认文件存在，需要时再读对应细纲、候选、正式正文和交付。不凭文件存在或最新章号判断采用。

1. 有 applying/reverting：先依 adoption 恢复或取消，授权不清只询问必要决定。
2. 有待审交付：展示当前场全文和详细对照，处理修改或等待明确通过；单说继续不算采用。
3. 有未完成修订或待复核：回到既有任务，不重复开任务，不写下一场。
4. 有撰写中或自动审阅中：核对开读输入和候选版本，恢复当前场；变化则重审。需先修前置内容时依授权 withdraw，保留稿件历史。
5. 无阻塞才选已确认细纲的下一场；全场采用后准备收尾。上一章收尾或导入确认未完成不能规划下一章，未确认细纲不能写场景。

“检查”“先不改”严格只读，发现中断也不自行写入。状态、版本与原文冲突时附证据交作者，不手改状态。

## 分阶段资料

| 阶段 | 当前需要 | 延后读取 |
|---|---|---|
| 开书 | new-book、构想、相关设定与作者文风 | 审阅循环和采用交易细节 |
| 导入 | import-book 当前步骤、原稿索引和确认范围；抽取逐章读原文 | 未轮到原稿、可选体检 |
| 规划 | plan-chapter、追踪、到期兑现、分卷大纲、相关设定与角色 | 全书正文、写手修正模式 |
| 写当前场 | write-scene、写手模式、该场细纲三层及必要事件、角色与兑现、创作护栏、已采用文风片段与作者确认理由（如有）、冻结前文原文、最新累计事实 | 未来场正文、无关角色及编辑完整诊断表 |
| 自动审阅 | 选定模式、角色规则、开读冻结版本、各角色允许资料 | 其他审阅者首轮意见 |
| 作者待审 | 正文、决定项、重要变化导航，以及默认详细展示的完整候选、保留项、修改证据、事实变化与覆盖缺口 | 下一场正文 |
| 采用恢复 | 指定交付版本、交易或任务状态及 adoption 操作 | 无关任务与章节 |
| 章节收尾 | 全部已采用场、细纲、兑现、追踪、整章独立盲读 | 下一章写作资料 |
| 修订 | revise 类型、当前场授权范围、可靠基准、最新正式相邻原文和依赖证据 | 未授权修改及无关卷 |

## 原文与事实供给

写手和 copy-editor 使用同范围冻结原文：叙事顺序的直接前场完整原文＋协调器按证据选择的必要前因。跨章读最新正式正文，不能以旧场景草稿代替修订章；没有可靠前场边界时给上一章全文。上下文清单只记录来源和范围，不成为另一份可编辑正文或状态。

写手可另收累计事实、设定、角色知情、资源、出口状态；copy-editor 不收这些解释及意图。累计事实从最新有效采用版本派生，修订时替换失效增量，不将旧新事实都追加。

写前准备及作者已确认的修改理由只供写手；不进入 copy-editor 的盲读输入。旧细纲继续保留已确认事件与兑现，不因三层模板上线而批量迁移或自动改成可选。

前因疑点先补已采用原文，更新冻结范围并重新独立盲读。前文不足不是已证实的正文缺陷；设定或摘要不能替读者补理解。预算不能截掉必要证据，抽样不冒充全书检查；完整导入、整章盲读和授权范围审阅仍须完成。

## 交互与持久化

切阶段简短说明当前位置、动作和真正缺失资料，不固定输出状态卡；已有资料和授权不重问。确认、采用及范围外变更仍等明确决定。

每次只写或优化一场，逐场交付并等作者。对话直接提供本场全文和详细要点；长稿打开含全文的交付并展示原句、改句、理由和事实变化，不只报路径或计数。整章修订的场景确认不直接更新正式整章，完整目标仍按 adoption 采用。

已完成动作写入既有场景状态、交付、journal、修订任务或导入报告。恢复重新核对来源与版本；无持久证据明示未登记，不补造审阅或授权。
