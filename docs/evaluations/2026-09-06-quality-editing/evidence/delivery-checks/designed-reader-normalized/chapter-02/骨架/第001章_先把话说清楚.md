# 第001章 先把话说清楚

## 章节契约

- 来源细纲：大纲/细纲_第001章.md
- 最终正文字数目标：2500 字
- 目标情绪：事业；受窘与急迫，转为有限信任
- 读者获得：能理解为何不能立即修、为何先保鱼；看见小满冒着失去订单的风险拒绝假保证，何桂香仍付定金。
- 禁止提前释放：不谈成借柜，不搬鱼，不修好，不收尾款，不让父亲或新配角兜底。
- 开场动作：何桂香进修理铺找老周，小满迎上去接单。
- 章尾钩子：小满带何桂香走到陈望包子铺，在门口请他先听借位条件；停在即将谈条件。

## 场景 1

- 时空与人物：清晨，修理铺到鱼摊；小满、何桂香
- 场景目标：拿到亲自看故障的机会，并判断当下该先做什么
- 阻力：何桂香认老周的手艺，不熟小满，鱼货等不起
- 动作链：找老周 -> 小满承认父亲在家养腿 -> 何桂香让她到摊位 -> 同意断电检查 -> 小满确认需等合适配件
- 结果变化：何桂香接受由小满查看，但无法得到即刻修好的结果
- 情绪转折：被当代班的不服气 -> 必须把不利事实说清
- 信息/伏笔：配件需下午取；鱼货尚有冷量但不能空等；故障限定一台柜
- 台词意图与潜台词：何桂香用找老周试探可靠性；小满想证明能做，急时辩一句，但不堆经验履历
- 正文字数预算：1000 字

## 场景 2

- 时空与人物：清晨，鱼摊到包子铺门口；小满、何桂香，末尾陈望
- 场景目标：在不乱许诺的前提下拿到授权和定金
- 阻力：何桂香想花钱换立即修好的确定性；小满怕订单丢掉
- 动作链：何桂香问保证 -> 小满讲明下午与临存方案 -> 讲清服务费和付费节点 -> 何桂香付定金 -> 小满想到陈望空位并带她去开口
- 结果变化：小满接到三百元订单并收一百元，能着手安排临存，借位仍未确定
- 情绪转折：担心说实话丢单 -> 客户给出有限信任
- 信息/伏笔：维修总额300；定金100；修复验证后200；临存另议
- 台词意图与潜台词：何桂香撤回付款动作测试底气；小满忍住即刻收钱，提供自己能负责的范围；门口先征求谈条件的意愿
- 正文字数预算：1500 字
