# 语文规格

本档是 L1“语文正确”与 L2“段落与衔接”的诊断标准，copy-editor 照它检测，review-loop 照它定级与选择修法。scene-writer 默认读《创作护栏》的写作取舍与简短语义自检，不按本档逐条改写。补充规则仍只给 adjudicator，不合并到编辑读取的文件。

本书的地区用语、引号与标点约定，以 `設定/文風樣本.md` 为准。本档例句只示范句子结构，用语不作依据。

## 一、L1 语文检查规则

先检查保护清单和实际语义，再判断错误。下表是诊断依据，不把省略、句式标签或关联词出现方式自动当成硬错；定级须有具体阅读损失。

| 代码 | 规则 | 错例 → 正例 |
|---|---|---|
| L1-1 成分可判定 | 动作主体、动作和必要对象能由本句或前文判定；承前省略、对白省略和压缩句式按保护清单处理。 | 不知谁被淋湿时，“看着被雨淋成这样，他心软了”→“看着那只猫被雨淋成这样，他心软了” |
| L1-2 搭配得当 | 主谓、动宾、修饰语与中心语要搭得上；并列成分要同类。 | “寒意和信纸贴在一起”→“信纸贴在掌心，带着寒意” |
| L1-3 比较对象同类 | 拿来比较的两者必须同类。 | “她的笔迹和那封信一模一样”→“她的笔迹和那封信上的一模一样” |
| L1-4 语序清楚 | 修饰语、状语的位置不造成歧义。 | “三个学校的老师”若指三位老师，改“学校的三个老师” |
| L1-5 指代明确 | 他／她／它／这／那／自己，读者能立刻判定所指。同段有两个以上同性别人物时，换主语用名字或无歧义称呼。“自己”放在转述或兼语句中容易歧义。 | “她看见他对着自己的袖口说话”→ 改写为“她看见他低头，对着他袖口说话” |
| L1-6 逻辑关系清楚 | 关联词可按语义省略；“虽然……”不必出现“但是”，“但……却”等搭配不自动算错。只有关系错配、歧义或重复造成阅读损失时报告。 | “因为他没来，但是大家等到半夜”若实际是因果，改“因为他没来，大家等到半夜” |
| L1-7 不重复赘字 | 同义成分不重复。 | “大约三十岁左右”→“三十岁左右” |
| L1-8 用字正确 | 没有漏字、错字、同音误用。 | “露身后的门”→“露出身后的门” |
| L1-9 标点规范 | 引号、句末标点、省略号（……）、破折号（——）用法正确；全角标点前后不加空格；书名用书名号；文风样本另有约定的（例如问句用句号）从其约定。 | “‘走吧。’ 他说”→“‘走吧。’他说” |
| L1-10 段内不自相矛盾 | 同一物件在同一段、相邻句中的名称、材质、数量不互相冲突。 | 先写“一张黄纸”，下句“纸是羊皮”→ 二择一 |

## 二、L2 段落与衔接规则

### 硬规则

| 代码 | 规则 |
|---|---|
| L2-1 主语切换点明 | 换人行动或段首开新动作时，主语用名字或无歧义称呼。 |
| L2-2 一段一个说话者 | 对白段只属一个说话者；说话者的动作和他的台词放在同一段。 |
| L2-3 先写出，再提及 | 对白或叙述提到的动作、物件、状态，必须先写出，或能由前文直接推知。例如有人说“把刀放下”之前，要写到对方拿刀。 |
| L2-4 时空转换有标记 | 换时间、换地点时，用时间或地点短语、空行或过渡句。同一场景内的陈设与在场者，不能没有过渡就改变。 |
| L2-5 开头接得上前文 | 场景开头的时间、地点、在场人物与人物状态，能从前文结尾推出；跳接时，开头一两句就要交代。 |
| L2-6 人物进出场 | 在场人物离开或加入要写出，不让人物无声消失又出现。 |

### 阅读风险提示（按功能和实际损失判断）

下表用于定位风险，不是错误标准。多个主语、多个焦点或长段本身不构成问题；有实际歧义、无功能重复或节奏停滞才报告，轻微损失仍可报 S3，明显损失按 S2 细则。文风样本与表达功能优先，不把所有段落修成一样长。

| 代码 | 规则 |
|---|---|
| L2-7 多主语长句 | 核对动作归属及句子层次，不按主语数量机械判错。 |
| L2-8 焦点转换 | 核对转换是否可跟随、信息有无无功能复述，不强求一段只含一个动作。 |
| L2-9 段长与节奏 | 参照样本及本段功能判断阅读节奏，不把长段本身当错。 |

## 三、保护清单（不算错）

- 人物对白中的口语省略、方言、语病和口语量词，只要符合身份、说话者明确且不导致关键语义误读。对白口语不需要文风样本作证；不能为了书面语齐整磨平声线。
- 人物刻意的错误、夸张、反讽、错引、贬损。
- 作者文风中的特色句式与标点，以文风样本或本书已采用正文为证。
- 承前省略主语，而主语没有换。
- 同一场景内随后立即交代的悬念。
- 与文风一致的压缩写法：并列名词短语、省略“的”的短定语，读者顺读无碍时不算 L1 错误。

除对白口语外，保护的特色表达引用文风样本或已采用正文；缺证据先核对，不仅因形式不齐整就推定错误。保护不掩盖行动者、事实或关键逻辑的实际误读。

**前文不足不是错误**：提到场景外的旧事、前文可能已交代的人物与物件，而审阅时没有拿到那段前文，不按 L2-3、L2-5 定级，列入“前文不足”，写明需要补读的范围。

## 四、严重度对应

| 层 | 问题 | 严重度 |
|---|---|---|
| L1 | 指代错到读者会误解是谁做了什么 | S1 |
| L1 | 违反 L1-1～L1-10，读者会停顿、回读或读错 | S2 |
| L1 | 合法但别扭、累赘，读者顺读无碍 | S3 |
| L2 | 违反 L2-1～L2-6，读者会读错人物、位置、时间或动作 | S2 |
| L2 | L2-7～L2-9 提示处存在轻微累赘或节奏拖沓 | S3；明显损失依 S2 细则 |

**S2 判定**：指出普通读者首次阅读会在哪里误解、停顿或回读，并附原文依据；回读后能猜出原意不自动降级。没有具体损失，不能仅凭句式或个人偏好定为 S2。合理悬念、对白口语和供给不足先按保护清单处理。

落在保护清单的情况不报；前文不足的情况不定级。

严重度只看读者损失。另有“性质”（错误／别扭）与 L1-11～L1-13，见 `roles/adjudicator.md` 与 `语文规格_补充.md`；它们只用于裁决环节，自动修改范围见 review-loop。

## 五、修法对应

| 层 | 修法 | 修后回读 |
|---|---|---|
| L1 标点、错漏字（L1-8、L1-9） | 直接改正该处 | 所在句 |
| L1 其他 | 原意明确时用必要的最小修改消除错误；不强制重写整句 | 所在整段 |
| L2 | 先诊断动作、信息或转换缺口，按授权修必要段落；不默认补解释句 | 前后各两段 |

修后不能引入新的 L1 错误，也不能动保护项。不能靠删掉信息来消除问题：句意不明时，按上下文补全；判断不了原意（例如不确定某个词是设定还是笔误）时，不修，回报作者。改写后的句长、用语与标点仍要符合文风样本。

## 六、写手与诊断分工

写手的整场顺读及简短语义、事实自检见 `创作护栏.md`。编辑与裁决者保留本档的独立诊断，不能用写手自查代替盲读。文件名暂保留；历史冻结评测不改写，不把旧证据记作新版验证。
