# 执行顺序

1. 冻结基线与当前 clean 状态，建立独立试验目录。
2. 机械规则组：情绪连排 advisory、候选链与用例、适用范围内的字数规则。
3. 写作流程组：参考加载、可选技法、标点与代词一致性、场景与轻量阅读协议。
4. 主线程整合规范与共享副本，同步生成模板，检查冲突与实际写手输入。
5. 冻结三臂输入并依次生成三章；收集独立盲读，整理待作者/真人验收的阅读包。
6. 运行候选、情绪、引用门、静态、共享、文风政策、affected 等相关检查，修复实测失败；输出范围、验证证据与剩余限制。

并行实现依 Trellis Phase 2 分派独立有界子任务，主线程负责合并与样章试验。所有代理禁止 commit/push 和自行同步共享副本。
