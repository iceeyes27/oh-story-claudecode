# 第二轮小说质量优化：实现与试写验收

本轮六项改造和工程交付已完成，作者与真人阅读验收待进行。固定故事的局部编辑、重新设计人物互动的试写，以及另一题材《空着的位置》的三章复验都已归档。模型观察支持局部阅读改善，尚不支持“已能稳定写出读者满意的长篇小说”。没有采用到真实书籍，也没有提交或推送。

## 已完成的改造

| 改造 | 当前行为 | 核验方式 |
| --- | --- | --- |
| 场景安排 | 按故事需要选场景数；1、2、3、7 场均可，保持顺序、内容覆盖和篇幅预算 | 骨架正反例；实际三章写前检查 |
| 人物材料 | 只交接本章欲望、顾虑、关系经历和说话特点；欲望落实到具体选择，设计先接受轻量反馈 | 完整写手配置与实际输入归档；独立人物阅读 |
| 局部编辑 | 一次只处理最主要的 1～2 处阅读损失；保留有效心理、停顿和关系互动 | 五处实际编辑及逐处差异，原稿保留 |
| 规则分级 | 普通词形、生活动作和感官表达不自动阻断；作者禁令有原话、来源与作用域；确定性错误仍阻断 | 15 组规则作用域测试、跨端一致性与前轮九章复扫 |
| 日常修订 | 可准备原稿／候选／差异，绑定上下文阅读，检查后由作者采用；中断可恢复，完成后通过新修订恢复原文 | 真实三章只读预检；事务与故障注入回归 |
| 题材审稿 | 按题材和章节任务审读，不适用的金手指、反转等项填 N/A；不凭模型分数预测留存 | 契约测试与日常、轻悬疑试写 |

普通修订沿用原有追踪状态。改变事实必须走事实修订并扩大后文核查；改措辞可以刷新同章既有事实的引用，但不能改变数值和事实章。研究项目已有 HEAD 时仍走原生命周期。

## 三章对照观察

| 比较 | 读者 A | 读者 B | 可以得出的结论 |
| --- | --- | --- | --- |
| R31 原稿 → R69 局部编辑 | 小幅偏好 R69 | 很小幅偏好 R69 | 少绕几轮费用、时间、空间确认，读起来更顺；追读动力没有明显增强 |
| R31 直接规划 → R58 互动设计 | 有保留地偏好 R58 | 小至中幅偏好 R58 | 人物犯错、改主意、互相补位更有性格；不能归因于纯粹压缩语言 |

R69 保住了父亲没有指挥时握住手机的停顿、矮凳和袜子的生活细节、顾客叫出“周小满”的认可。代价也保留在评审中：第二章少了一层摆放空间的展示，第一章删掉“三两下修完”的问答后，下一章回顾的直接对应略弱。没有为了追求更低扫描数再次清洗。

R58 改变了实际行动、付款时点、票据持有人和父女对话。虽然共同主线和金额边界保留，不能把它当成相同情节的措辞实验。其中“傍晚前归还”的明确兑现证据弱于 R31，已作为不足记录。两位读者均认为，单靠下一台排风扇待修，尚不足以建立强烈追读欲。

阅读顺序 A 为 R31 → R69 → R58，B 为 R58 → R69 → R31。配对两侧先后相反，但熟悉同一故事仍会影响判断；两位均为模型读者，不是独立真人样本，不能给出胜率或市场结论。

## 另一题材的三章复验

《空着的位置》写照片展整理者为合影中被裁去的人补回姓名，三章依次交付“照片多出一人”“衣服借来、寄件者是女儿”“本人相认并同意署名”。原稿为 H74，一次局部编辑稿为 H82。

原读者按 H74 → H82 顺读，保留六份逐章报告；其配对汇总因中断未完成，没有代填。收尾时增加一位无前文上下文的读者，按 H82 → H74 顺读并先保存每章意见，再写[独立配对报告](evidence/blind/reviews/resume-reader-c-paired.json)。此前未完成的另一位读者只留下 H82 前两章记录，也原样保留，不计作完整审读。

新读者轻微偏好 H82，与原读者的编辑稿末章意见方向一致。较确定的收益是第三章让齐叔亲口承认记混了箱子，读者不必替人物补上纠正。第二章提前交代母女关系、删减职业推断，读起来稍快；代价是原稿“获得抄录许可后才说明关系”的信任变化少了一层。因此这不是单纯压缩字数的试验，也没有把所有删减都判为收益。

两版的原则解释与暂缓问答仍偏多。三章作为温和的小故事有完整回报，继续写成长篇还需要新的具体人物愿望与关系变化。顺序虽相反，重复阅读仍有熟悉效应；这两位都是模型读者，没有真人满意度或留存结论。

试验的工程不足也已收尾并留证：

- 原稿三章最初都因提取材料使用 `O-01`、骨架使用 `O1` 而被拒绝。在新检查目录中按编号映射，生产校验器、原始输入和原稿未改；三章随后通过。阅读指出的原稿局部推断、回忆矛盾仍保留在报告，预检通过不等于正文没有问题。
- H82 第 1 章使用节奏修订；第 2、3 章涉及信息披露和记忆纠正，保守地走事实修订，并绑定实际前后文。首次试验事务多提交了人物快照，校验器拒绝；改为仅提交本次改变的人物后，两章复核通过。失败目录未覆盖。
- 编辑保持一次、每章最多两个主要问题；没有根据后续审读再洗一遍。修订检查只演练准备和只读检查，没有作者采用。整套编辑稿另做了连续上下文候选检查，避免把各章对着原稿的局部检查冒充整套通过。
