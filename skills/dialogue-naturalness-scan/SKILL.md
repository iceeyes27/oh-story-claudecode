# 台词自然度 · 扫描法（真人会不会这么说话）

从《法援律师：我专打赢不了的官司》全书自然度体检中固化出来的专项扫描。
判定口径来自作者偏好：**即便不构成"行业词硬当动词"，不自然的口语表达（谁会这么说话）也要改**——本 skill 把它固化成可复现命令，把"grep 书面腔词根 + 模糊指代代词 + 只读子代理通读"固化成一条流程。

## 核心定义

**违规 = 台词不像真人在那个场面、对着那个人会开口的话。**
八类重点：
1. **模糊指代**（最该报）：台词用虚空代词（那页东西/这东西/那玩意/那事/这事…），读者或在场角色无法立刻知道指什么（没有就近清楚 antecedent）。
2. **书面腔混进口语**：普通人/当事人/律师在非正式对话冒出公文词（予以/并非/实则/换言之/方才/透过…）。
3. **别扭动宾/搭配**：动词+宾语组合读起来拗口，不像活人嘴里的话（参照已改判例：拆干净→拆了、那页东西→那份材料）。
4. **说明文式对仗 / 解释逻辑不表态度**（新，高频）：台词用对称工整的「不是 X，是 Y」「X 不是……X 是……」式冷静给对手/自己下定义，或用成语/书面总结收尾（不了了之/可想而知/说到底），读起来像**作者在旁白解释逻辑**，不像角色带着情绪和具体画面在开口。真人说话会断句散、带立场、用口语短句，不会冷静地自我对称纠正、也不会用四字成语给一件事定性。判定关键：这句是在「表达态度/情绪」还是「向读者解释因果」？后者即违规。
5. **抽象隐喻动词 + 浮空抽象形容词（不接地气 / 概念化）**（新，高频）：台词用抽象比喻动词代替具体动作（"跑=追查线索"、"拽=引导注意"、"带=转移焦点"），或甩一个浮空抽象形容词给事定性（"最虚"、"空"、"飘"、"虚浮"），读起来像**写者在用概念推演而不是活人在说话**。真人开口会用具体接地气的动词（带/耗/钻/追着打转）和具体可感的评价（没底/站不住脚/心里没数/心虚），不会用"跑"这种文学隐喻去追一条线索，也不会单甩一个"虚"字给一件事定性。判定关键：把这句里的动词/形容词换成最土最具体的口语说法，如果原文那个词是"概念"而不是"动作/状态"，即违规。
6. **点题式 / 扁平说理金句（新，advisory）**：角色用一句可脱离剧情成立的"道理 / 格言 / 书的主旨"向读者宣讲，而非在具体场景说具体的话。典型结构：工整的「论点句 + 理由句」（或「前提 + 结论」）两句呈现，常用词、语法干净、无禁用词、无对称对仗、无浮空形容词——所以词表与正则全盲，只能靠语义通读复核。判定：把这句抽掉角色名和场景，若它仍是一句"成立的人生道理 / 书的主旨"，且用论点 + 理由两句呈现 → 标 advisory 通读复核（不 blocking，避免误杀活人真在讲道理的场景）。反例（Ch002 江澈对周母）：「绝望也得讲证据。现在证据还没看完，还轮不到谈绝望。」把全书主旨浓缩成金句念给读者，论点句 + 理由句工整，不像人在现场安慰绝望的当事人，像作者旁白点题。修法方向：改成角色在现场对那个人说的、具体不念主旨的话，落到具体物件 / 动作 / 对方状态（如「先别急，这些票据我还没看完，里头说不定还能找出东西」）。
7. **流程式通牒（新，高频）**：角色在气头/对抗场面，却把台词说成"时间+条件+后果"三段式完整递进，像 HR 念流程或行政通知。气头上的通牒砍解释、省条件、用口语短句砸后果，不把流程交代清楚——因为说话人懒得跟对方解释流程，对方自己知道。判定：抽出来看，这句是**在砸人**还是在**交代流程**？如果信息太完整、太递进、太清楚（时间节点+条件长定语从句+公文词收尾），就是在交代流程。常伴随公文词（"办离职/办手续/予以处理/按程序"）收尾，气头上不会用这类词。反例（Ch001，韩克勤扔完材料后）：「十分钟后，楼上评审会开。你要还是拿不出能留下你的理由，月底办离职。」——时间+条件长定语从句+公文词"办离职"收尾，三段式太完整太递进。正例（Ch001，已修）：「十分钟后楼上开会。」韩克勤没看他，「这案子接不住，月底自己走。」——砍长定语、砍公文腔、"办离职"换"走人"、加动作锚点"没看他"。修法方向：砍解释、省条件（对方自己知道）、用口语短句砸后果、公文词换口语、必要时加动作锚点托住台词温度。
8. **人物声口错位（新，语义层）**：台词不符合说话人的职业身份与性格底色——不是"像不像人说话"，而是"像不像'这个人'说话"。两道关：① 专业性匹配——职业决定用哪套词，资深律师/法援主任说法律人逼证据口吻（"空口无凭""你想清楚"），不冒市井江湖腔；有黑道前科、市井出身的人才说"这钱是封嘴的"这类市井类比。② 性格底色匹配——硬冷稳的人短促压人少解释，市井圆滑的人可插科打诨但玩笑落回行动，规矩型的人用词准确不掺情绪词。反例（Ch002 韩克勤）「这一句，讲得圆吗？」——"讲得圆"是市井/江湖腔，江澈这种有黑道前科的人说合适，韩克勤是法援中心主任、资深律师，声口一贯短促压人的公事腔，不这么说话。正例（Ch002，已修）「空口无凭。」——法律人逼证据标准口吻，四字短促压人，且和后文江澈翻协议拿实据严丝合缝。判定口诀：把台词抽出来、不看名字，猜不出是谁说的、或跟这角色的身份/性格拧着，就是声口错位。详见 `创作偏好.md`「人物声口铁律」段。

**第 8 类高频子型（碎句电报体 / 提要腔，2026-08-20 补）**：声口错位最常见的一种表现，是把**叙事的短促节奏**当成**说话节奏**——无主语短句一顿一顿、一句话拆成三四个句号、刻意逗号停顿（「你，也别留了」），硬凹「狠角色」。但真人说话有惯性：会带连接词、把几件事捋成一口气，**体制内领导 / 资深专业人士尤其从容连贯**，威胁包在场面话里（「你自己掂量」「月底怎么安排你清楚」），不会像发电报。与第 7 类配对分流，**碎不碎不是绝对好坏，取决于说话人身份 + 当下情绪**：气头 / 对抗场面该砍成短句砸后果（第 7 类，太完整 = 违规）；领导公事施压 / 日常甩活该连贯从容（本子型，太碎 = 违规）。另一相关表现是**提要腔台词**——台词替旁白交代案情，把一堆事实按逻辑顺序码进嘴里，像案情摘要卡（「工伤，私了协议签了字、按了手印，人躺在病床上又想翻」）；真人图快图发泄时语序是乱的、带情绪的，修法是先甩具体的人 / 物再补事实、语序随情绪走。判定口诀：领导 / 专家的台词读起来像**发电报或念摘要卡**而非**从容开口**，即本子型违规。

「病历比谁说的话都作数」——把"客观证据优先于言词"压成单句打包的「X 比 Y 都 Z」式法则金句（区别于上例"论点句+理由句"两句式，本例是单句打包变体），抽掉场景与角色仍是成立的道理而非具体有用的话，像作者旁白点题、无体温；用户定性为「说明书式表达，没有人味」。修法方向：把"定律"落回人物当下的具体物件/动作/声口，绑到眼前物证（翻到病历时间点、手指点着说；或「这份病历上，急诊、麻醉、复苏的时间点一个都卡着钟——他按手印那会儿清不清醒，纸面上写得明明白白」）。

判定口令：抽掉场景后，这是"一句有用的具体话"还是"一句成立的人生道理"？后者即违规倾向。

**判定口令（最关键）**：把这句台词换成**一个普通人在那个场面、对着那个人**会怎么开口？
- 真人会带具体指代、用短句、顺着对方话说；原文却用了模糊指代/书面词/别扭搭配 → 违规。
- 立刻懂、像活人说话 → 不违规。

**本质**：不是"某个词能不能用"，而是"这句台词读起来像不像人说的话"。

| 这协议不是赔钱，是封嘴的。他们给钱这么急，急的不只是医药费。 | 第4b类主宾类别错配变体：X"协议"（一张纸）与 Y"赔钱"（钱的性质/用途）类别不一致，比较基准错位，读者要猜说话人指的对象其实是钱；且"给钱这么急，急的不只是医药费"两"急"连用、"急的"指代滑移到"医药费"（着急对象应是"给钱/签字"这件事） | 统一到同一类别、主语就是钱：改为「这钱不是赔医药费的，是封嘴的。他们给得这么急，是怕他缓过神来，反悔。」——"协议"→"钱"、"给钱急/急的"→"给得这么急"+落到具体怕因（呼应前文止痛针灌下去迷迷糊糊按手印那段） |

| （韩克勤开场甩案）工伤，私了协议签了字、按了手印，人躺在病床上又想翻。中心没一个人愿意碰。接不住，月底自己走。 | 第8类·碎句电报体 + 提要腔子型：法援主任被写成无主语短句一顿一顿蹦豆子，又把案情按逻辑码成摘要卡塞进台词；且"人躺在病床上又想翻"与当事人已坐轮椅到中心闹的现场状态冲突（上下文错误） | 连贯从容的领导声口，先点当事人再补事实、威胁藏场面话、修正状态：「十分钟后我上楼开会。周春来，工地摔的工伤。私了协议签了字、按了手印，钱也拿了，这会儿又反悔，闹到中心来。几个人都看过，都说没得打。这案子搁你手里，接不接得住，月底怎么安排，你自己掂量。」 |
| （韩克勤）三天。三天拿不出方向，案子换人，你，也别留了。 | 第8类·碎句电报体子型：同角色同毛病，"你，也别留了"刻意逗号停顿硬凹狠；"三天"作情绪重音可留，坏在后半截碎 | 保留重音、后半连贯：「三天。三天拿不出方向，这案子我另外找人，你也别留了。」 |

> 规律：本书自然度问题多是"虚空代词指代手边具体物"（那页东西/这页东西），真人会直接叫出物名。扫台词优先查"代词+无清楚 antecedent"。另一类高频是"对称对仗的定性台词 + 成语收尾"（见第 4 类），读起来像作者旁白而非角色说话——其中"不是X是Y"若 X、Y 类别不一致（物 vs 行为/用途，如"协议不是赔钱"）即第 4b 类主宾错配变体，先统一比较基准再谈改法；还有一类是"抽象隐喻动词 + 浮空抽象形容词"（见第 5 类），用"跑=追查"这类概念动词、单甩"虚/空"这类浮空形容词，不像活人说话；还有一类是"点题式 / 扁平说理金句"（见第 6 类），角色用工整的"论点句+理由句"向读者宣讲可脱离剧情成立的主旨，词表与正则全盲，只能靠语义通读复核；还有一类是"流程式通牒"（见第 7 类），角色在气头/对抗场面却把台词说成三段式完整递进的流程交代，常配公文词收尾，不像气头上的人会开口；还有一类是"人物声口错位"（见第 8 类），台词不符合说话人的职业身份与性格底色——语义层，只能靠通读对照角色设定判。六类（含 4b 变体）扫台词时一并查。

## 边界（不误杀，不要报）

- **角色身份使然的正式腔**：公司代理、对方律师、公权力机构在正式场合（法庭、书面答复、正式谈判、听证）说的正式立场，用正式词（贵司所称/并非/客观上/依据/予以）是专业身份使然，**不报**。
- **这玩意儿就近有清楚指代**：如指着某份材料/某个设备说"这玩意儿"，属口语自然，**不报**。
- **文学性叙述语言（非台词）**：叙述/心理描写里的书面表达不在此 skill 范围，**不报**。
- **正常法律动词**：立案/举证/保全/答辩等，读者从语境能懂，**不报**。
- **本书文学隐喻**：裂痕/壳等非台词描写，**不报**。

## 三层扫描法（逐层做，缺一不可）

### 第 1 层：已修判例复扫（必须 0 命中）
Grep 全正文目录，确认历史违规已清零：
```
那页东西|这页东西|页东西|拆干净
```
任何命中都直接报（历史回归），定位到 章节:行号。
第 4b 类属语义层（比较基准错位），正则只能盲抓句式，第 1 层暂用句式宽松提示、最终以第 3 层重写对照为准：
```
不是(协议|合同|钱|协议|条款|文件)[^，。！？!?]{0,6}(赔|封|是)
```
命中后 Read 上下文判 X/Y 是否同类；仅提示，不机械报。

### 第 2 层：书面腔词根 + 模糊指代代词 定向 Grep
对下列词根做 Grep（带 `-C 1 -n`），命中后 **Read 上下文逐条判**"是不是真人在说、有没有清楚指代"。这些词出现在台词（引号内）且非正式场合才重点看：

- 书面腔词根：予以 | 进行(处理|调查|沟通|说明|核实) | 实施(该|上述) | 并非 | 实则 | 换言之 | 某种程度 | 值得一提的是 | 不可否认 | 经由 | 透过 | 乃是 | 方才 | 未曾 | 颇为 | 甚是 | 其一 | 其二 | 此番 | 故而
- 模糊指代代词（最该报）：那页东西 | 这页东西 | 那玩意 | 这玩意儿 | 那事 | 这事 | 那档子事 | 那桩事

> 第 2 层只缩小范围，命中不代表违规——必须 Read 上下文判：是台词还是叙述？是正式场合还是日常？代词有没有就近清楚 antecedent？

### 第 3 层：分批重写对照通读（兜底语义盲区，主力层）
第 1–2 层是词表下限，抓不到词表外的别扭台词。本层是主力兜底，两条纪律是召回率的来源：

**纪律一：分批派发，禁止单代理通读全书。**
- 每个只读子代理一批最多 **5 章**（可调，见「可调项」）；全书按批切分，批与批并行派发。
- 单代理通读全书会摊薄注意力、事实上退化成抽查；分批 + 逐句强制覆盖才能穷举。
- 输出**不设字数上限**，要求穷举列出每一处；禁止"只报最明显几处"。

**纪律二：重写对照法，禁止判别式提问。**
不问子代理"这句有没有问题"——这些台词多半就是同系模型写的，在它自己的语言分布里读着"很正常"，判别式提问天然不灵敏。改为强制它**先把每句台词按"真人在那个场面会怎么开口"重写一遍，再 diff 原句**：生成比判别灵敏得多，重写后差异大的就是嫌疑句，即使归不进已知六类也要报。

子代理提示词（直接复用，替换本批章节范围；general-purpose 类型偶发瞬时失败可改 Explore 重试）：
```
你是一个只读的中文小说台词自然度审查代理。任务：对指定章节做逐句台词审查，找出对话里"真人不会这么说话"的自然度问题。只读不改。
文件范围：<本批章节文件列表，不超过 5 章；只审 第XXX章_*.md，跳过目录.md/大纲>。
方法（重写对照法，必须按此执行，禁止凭整体印象直接判"没问题"）：
1. 逐章顺序读，把每一处引号内台词单独拎出来（叙述/心理描写不在本层范围）。
2. 对每句台词先重写：这个角色（身份、情绪、对着谁）在这个场面，一个活人会怎么开口？写出你的重写句。
3. 对照原句与重写句：差异只是措辞习惯 → 放过；重写后指代更具体、句子更散更短、动词更接地气、态度/情绪更明显 → 原句有自然度问题，必须报。
4. 覆盖率硬要求：不许抽查，每句台词都要过第 2–3 步；输出末尾报告本批共审台词句数。
重点参考七类：1) 模糊指代（那页东西/这东西/那玩意/那事/这事等虚空代词，无就近清楚 antecedent）；2) 书面腔混进口语（予以/并非/实则/方才/透过…）；3) 别扭动宾/搭配（参照判例：拆干净→拆了、那页东西→那份材料）；4) 说明文式对仗/解释逻辑不表态度（对称工整的「不是X，是Y」式定性句、成语收尾给事定性，像旁白解释逻辑而非活人开口）；5) 抽象隐喻动词+浮空抽象形容词（"跑=追查线索"这类概念动词、"最虚/空/飘"这类浮空形容词定性，像概念推演而非活人开口）；6) 点题式/扁平说理金句（抽掉角色名和场景后仍是"成立的人生道理"而非"有用的具体话"；含"病历比谁说的话都作数"式"X比Y都Z"单句打包变体；**台词侧口号家族亦归此类**——「不胜不休/正义必胜/正义绝不（缺席|低头）/胜利终将属于/依法维权到底」等口号套话，有人称承载但仍是作者借角色念普法词，按角色声口改回具体证据/下一步动作）；7) 流程式通牒（角色在气头/对抗场面却把台词说成"时间+条件+后果"三段式完整递进，像HR念流程；常配公文词"办离职/办手续/予以处理"收尾，气头上不会用）；8) 人物声口错位（台词不符合说话人的职业身份/性格；高频子型：碎句电报体/提要腔——领导或资深专业人士被写成无主语短句一顿一顿蹦豆子、或把案情按逻辑码成摘要卡塞进台词，应连贯从容、威胁藏场面话；与第7类配对分流：气头对抗该砍碎，领导公事施压/日常甩活该连贯，太碎即违规）。但不限于这八类：只要重写对照差异大，归不进任何一类也要报。
不要报：角色身份本就该正式（公司代理/律师/法官在正式场合说贵司所称/并非/客观上/依据等）；这玩意儿就近有清楚指代；文学性叙述语言（非台词）；正常法律动词；活人真的就事论事讲具体经验（如老警察随口传授办案的具体教训）。拿不准的不要吞掉，单列「边界待定」。
输出：只读不改；中文，不设字数上限，穷举列出每一处（章节:行号 + 原文短摘 + 你的重写句 + 差异说明/归类），分「确认违规 / 边界待定」两组；最后一行报告"本批共审 N 句台词，确认违规 M 处，边界待定 K 处"。
```

## 工作流程

1. 确认扫描目标：默认扫当前书 `正文/` 全卷；可指定单卷/单章。
2. **第 1 层** Grep 已修判例 → 若有命中，记录为历史回归。
3. **第 2 层** 对书面腔词根 + 模糊指代代词 Grep → 命中处 Read ±3 行判留/清（注意台词 vs 叙述、正式场合 vs 日常、代词有无清楚 antecedent）。
4. **第 3 层** 全书按 5 章/批切分，并行派只读子代理做重写对照通读；每批要求穷举输出并报告"共审台词句数"，用句数核对覆盖率（明显偏低说明该批退化成抽查，重派）。
5. 汇总：合并各批输出，分「确认违规 / 边界待定」两类，附 章节:行号 + 原文 + 重写句/建议改法。
6. **默认 report-only**：不擅自改正文。用 AskUserQuestion 让用户选「全改 / 只改确认违规 / 只改指定处 / 不改」。
7. 改：单处用 Edit；每处先校验 old 串唯一再写回。改完 Grep 验证目标 pattern 0 残留。
8. 写/更新项目 `.workbuddy/memory/YYYY-MM-DD.md` 工作日志。

## 判定原则（区分 违规 vs 可接受）

- **违规**：台词模糊指代无 antecedent、非正式场合冒书面腔、动宾搭配别扭、用对称对仗的定性句/成语收尾向读者解释逻辑而非表达态度、用抽象隐喻动词/浮空抽象形容词概念化表达而非具体接地气的动作/评价、用工整的论点句+理由句向读者宣讲可脱离剧情成立的主旨（点题式金句）、在气头/对抗场面把台词说成三段式完整递进的流程交代（流程式通牒） → 改具体指代 + 口语短句 + 带情绪/具体画面 + 接地气动词与评价 + 落到具体场景的话（不念主旨） + 砍解释省条件砸后果（不念流程）。
- **可接受**：角色身份使然的正式腔、就近有清楚指代的口语、叙述语言、正常法律动词 → 留。
- **改前必读上下文**：Grep 命中务必 Read 那行 ±3 行，确认是台词还是叙述、场合正式与否、代词有无 antecedent，再决定。误清会伤 voice。
- **小修大不动**：本书此类问题通常极少（75 章仅 2 处历史违规），发现即外科手术式单点修，不批量重写。
- **改写纪律：换词必查因果方向 + 顺链核后续**：为去 AI 味替换台词时，不能只把浮空/书面词换成接地气词、却保留原因果结构——新词与旧逻辑打架会引入回归。例：Ch008「越想让我跑，越说明这句最虚」改「越盼着我们往这儿钻，越说明他们自己在这句上最没底」，"最没底"虽接地气却与"往这带"因果拧反（对手不会在自己最心虚的点上主动引你），最终顺"鼎衡死咬饮酒=别处没招"重排递进才通。三查：① 替换后因果方向对不对（谁因谁果、谁主动谁被动，是否被新词拧反）；② 递进/转折是否仍成立（"越X越说明Y"里 X、Y 是否真有该递进）；③ 顺前后文链核一遍（前句说什么、后句接什么、后续章节是否验证该判断）。详见 `创作偏好.md`「改写纪律」条。

## 可调项

- 书面腔词根表按项目世界补：新题材（古言/医疗/玄幻）有各自书面表达，加到第 2 层。
- 新增判例：发现新的自然度违规，补进「已知已修判例」表，并同步回 `创作偏好.md`。
- 子代理提示词可随判定口径收紧/放宽（如把"正式腔不报"收紧为"全文统一口语"）。
- 第 3 层分批大小默认 5 章/批：报告的"共审台词句数"与正文实际台词量对不上（覆盖率退化）时缩到 3 章/批；台词稀少的书可放宽到 8 章/批。
