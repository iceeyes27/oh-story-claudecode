# B03 幕2 逐句逻辑读者报告（SR r1）

读取范围：语文规格、语文规格补充、文风样本、B03/幕2_已读.md、B03/幕2.md。B03 无前文.md。

## 现场摘要

- 时间地点：深夜，宵禁钟声已过很久，城堡走廊拐角。
- 埃德蒙：从三楼空教室出来，怀里揣着三张废符纸；靠在石柱阴影里，手里拿着手机，刚用手机放了一段中文歌（吉他扫弦＋男声），按侧键掐断。幕2 未交代手机此后是否收起。
- 姜小满：从暗处出声，抱着厚厚的《魔法史》立在暗处，随后逼近埃德蒙一步。
- 本幕结束时：两人面对面，姜小满以告发费尔奇相威胁，要埃德蒙“拿出来”；埃德蒙尚未回应。

## 逐句表

| 句号 | 复述 | 结论 | 说明 |
|---|---|---|---|
| 2-01 | （埃德蒙刚掐断歌后，）一个（此时尚未交代是谁的）声音从他身后问：你在跟谁说话 | 问题 | 说话者到 2-03 才揭晓，属随即交代的悬念；但她听到的是一段歌（1-07、1-08），却问“跟谁说话”，下文 2-05 又说“那是歌”，前后判断不一，读者可能停一下。另：文风样本对白中有问句用句号的例子（“月月是不是该有我一份。”），本句用“？”，是否构成书内约定待核，暂不列候选 |
| 2-02 | 埃德蒙（听到身后有人问话，从靠着石柱的姿势）转过身（面向声音来处） | 通过 | 触发为 2-01 的问话；靠柱→转身可顺推 |
| 2-03 | （埃德蒙转身后看见）姜小满站在暗处，双臂抱着一本厚厚的《魔法史》 | 问题 | 人站在“暗处”，深夜走廊，埃德蒙却能辨认出书的厚度和书名《魔法史》；看不清却写出书名，需补光源或改为他认得那本书。姜小满是谁、为何此时在此，无前文，待核 |
| 2-04 | 姜小满说：（你刚才发出的）那个声音说的不是英语 | 通过 | 对白口语；“那”指 1-07、1-08 的人声，可判定 |
| 2-05 | 姜小满（改口）说：那（个声音）是一首歌 | 通过 | 对白口语；与 2-01“跟谁说话”的出入并入 SR-2-01-1 |
| 2-06 | 姜小满说：你身上（藏着）某样东西在唱歌 | 问题 | 埃德蒙在 1-05～1-10 是手拿手机播放、掐断，幕2 没交代他把手机收起；若手机仍在手里，“身上有东西”与 2-12“拿出来”都不得不补“他已把手机收起”或“她没看见手机”。按侧键后屏幕熄灭、她在暗处看不清，可勉强推出，但原文未给 |
| 2-07 | 埃德蒙对姜小满说：小满同学，你宵禁时间在外面乱逛，（被）费尔奇（抓到）会关你禁闭 | 通过 | 对白口语（“宵禁乱逛”压缩）；说话者为在场唯一另一人，可判定；他本人也在宵禁外出，属转移话题，2-08 随即点破 |
| 2-08 | 姜小满（对埃德蒙）说：少跟我打马虎眼 | 通过 | 对白口语；说话者由轮次与语气可判定 |
| 2-09 | 姜小满（抱着书）朝埃德蒙逼近一步 | 通过 | |
| 2-10 | 姜小满说：你（之前）在（某辆）车上时就已经在自言自语 | 待核 | “车上”是哪一趟车、何时，无前文，无法判断；“自言自语”与 2-01“跟谁说话”一致 |
| 2-11 | 姜小满说：今天（某堂课上）（某口）锅底的那张纸（上画的东西），根本不是炼金术的画法 | 问题 | “锅底那张纸”的所指无前文，待核；另“那张纸……不是……画法”主宾不搭，复述时不得不补“上画的图／符”（对白口语，可能属保护） |
| 2-12 | 姜小满说：你现在就把（那样东西）拿出来，不然我马上去找费尔奇，告发你私藏违禁品 | 问题 | “拿出来”的宾语省略，候选有二：2-06 会唱歌的东西（手机），或 2-11 那类纸（埃德蒙怀里正揣着三张废符纸，但她未必知道）；另，她自己也在宵禁时外出（2-07 已被点出），以告发相威胁的分量读者可能起疑 |
