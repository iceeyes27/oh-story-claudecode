# 行业词硬当动词用 · 扫描法

从《法援律师：我专打赢不了的官司》全书 75 章黑话体检中固化出来的专项扫描。
配套规则已写入项目 `创作偏好.md`（去 AI 味/通俗度红线）与 `设定/文风.md`（禁写栏），本 skill 是它的**可复现扫描实现**——把"grep 词根表 + 只读子代理通读"固化成一条命令，避免每次手拼流程。

## 核心定义

**违规 = 行业词/专业名词（或需猜的比喻名词）硬当动词用。**
即：把一个名词硬拗成动宾或动词短语，真实动作被藏进行话，非从业者（普通读者）要猜才懂。

**判定口令（最关键）**：把这个"动词"换成一个**非从业者普通读者**听得懂的话，他能不能一眼说出"这人到底在做什么"？
- 说不出、要猜 → 违规，改回「具体动作 + 具体对象」。
- 立刻懂 → 不违规（多半是全民惯用语或正常法律动词）。

**本质**：不是"某个词能不能用"，而是"名词＋硬当动词"结构把动作藏进了行话。

## 已知已修判例（正文里不应再出现，出现即报）

| 原文（违规） | 真实含义 | 应改为 |
|---|---|---|
| 接案源 | 把案子接下来 | 接案子 |
| 补窟窿 | 自己把事压下去/捂住 | 把事压下去 |
| 往后刨 | 往更早的环节查下去 | 往更早的环节查下去 |
| 顺杆往下 / 顺杆逼问 | 顺着话头往下 / 顺着话头逼问 | 顺着话头…… |

> 规律：本书黑话多为"行业词硬当动词用"（接案源/补窟窿/往后刨/顺杆），比单纯名词行话（案源、公理点）更易踩雷。扫黑话优先查"名词+硬拗动词"结构。

## 边界（全民惯用语 / 正常法律动词，不误杀，不要报）

- 全民口语/惯用语：擦屁股、背锅、甩锅、兜底、钉死、翻旧账、翻供、反咬、洗白、压下去、顺了某人的意、接盘、收网、钻空子、露马脚、露馅、留尾巴、堵住退路、露怯。
- 正常法律动词用法（读者从语境/常识能懂）：开庭、立案、上诉、取保、答辩、保全、举证、驳回、改判、发回重审。
- 本书文学隐喻（非黑话，非动词）：裂痕 / 裂缝 / 缝（证据缺口）、壳（责任外衣）。

## 三层扫描法（逐层做，缺一不可）

### 第 1 层：已修判例复扫（必须 0 命中）
Grep 全正文目录，确认历史违规已清零：
```
补窟窿|往后刨|顺杆|接案源
```
任何命中都直接报（历史回归），定位到 章节:行号。

### 第 2 层：隐喻/行业名词根定向 Grep
对下列名词根做 Grep（带 `-C 1 -n`），命中后 **Read 上下文逐条判**"普通读者要不要猜"。这些根若以"动词+该名词"组合出现且非全民惯用语，重点看：

- 风险/陷阱比喻：雷（顶雷/埋雷/踩雷/排雷/爆雷）、套（下套/上套/解套/设套/中套）、坑（挖坑/填坑/踩坑）、窟窿（补窟窿）
- 行话名词：案源（接案源/找案源）、杆（顺杆）、坡（顺坡）、刨（往后刨）
- 常见隐喻：尾巴（卷宗尾巴=卷宗末尾，名词可接受；当动词用才报）、把柄/辫子（抓把柄）、马脚/馅（露马脚/露馅，惯用语）、七寸/命门（抓七寸）、底牌/王牌（亮底牌）、招（出招/拆招）、刀（递刀/补刀）、局（破局）、棋（死棋/活棋）、网（收网）、线（收线/放线）、口子（开口子）、后路/退路（堵住退路，惯用语）、缝、壳
- 行业动作黑话：捂住/捂过、兜底/兜住、擦屁股、背锅/甩锅、接盘、钻空子、抠细节/抠字眼、顺了意、钉死、焊死

> 第 2 层只缩小范围，命中不代表违规——必须 Read 上下文判"普通读者要不要猜"。

### 第 3 层：只读子代理通读（兜底结构性盲区）
第 1–2 层是词表下限，抓不到词表外的"名词硬当动词"。派一个 **只读 general-purpose 子代理** 通读全部章节，按下方提示词做语义判定。这是本 skill 的主力兜底层。

子代理提示词（直接复用）：
```
你是一个只读的中文文本审查代理。任务：通读一本小说全部正文，专门找出「行业词/专业名词硬当动词用」这种黑话写法。
判定口令：把这个"动词"换成非从业者普通读者听得懂的话，他能不能一眼说出"这人到底在做什么"？说不出、要猜，就是违规。
已知已修判例（出现即报）：接案源→接案子；补窟窿→把事压下去；往后刨→往更早环节查；顺杆往下/逼问→顺着话头。
通行惯用语不报（擦屁股/兜底/钉死/翻旧账/收网/露马脚/堵住退路/露怯/正常法律动词等）。
输出：只读不改；按"章节:行号"列确有问题的每处（原文短摘+为什么读者要猜+建议改法）；通读全部章节；最后一句总结数量（0/少量/较多）。
```

## 工作流程

1. 确认扫描目标：默认扫当前书 `正文/` 全卷；可指定单卷/单章。
2. **第 1 层** Grep 已修判例 → 若有命中，记录为历史回归。
3. **第 2 层** 对名词根表 Grep → 命中处 Read ±3 行判留/清。
4. **第 3 层** 派只读子代理通读全本，按提示词判结构性违规。
5. 汇总：分「确认违规 / 边界待定」两类，附 章节:行号 + 原文 + 建议改法。
6. **默认 report-only**：不擅自改正文。用 AskUserQuestion 让用户选「全改 / 只改确认违规 / 只改指定处 / 不改」。
7. 改：单处用 Edit；每处先校验 old 串唯一再写回。改完 Grep 验证目标 pattern 0 残留。
8. 写/更新项目 `.workbuddy/memory/YYYY-MM-DD.md` 工作日志。

## 判定原则（区分 违规 vs 可接受）

- **违规**：行业内部词（案源、窟窿、杆、刨）当动词，非从业者要猜 → 改具体动作+对象。
- **可接受**：全民惯用语（擦屁股、兜底、钉死…）或正常法律动词（开庭、立案…）→ 留。
- **文学隐喻**：裂痕/壳是本书系统性意象，非动词黑话 → 留。
- **改前必读上下文**：Grep 命中务必 Read 那行 ±3 行，确认是字面还是黑话，再决定。误清会伤 voice。
- **小修大不动**：本书此类问题通常极少（75 章仅 4 处历史违规），发现即外科手术式单点修，不批量重写。

## 可调项

- 名词根表按项目世界补：新题材（医疗/职场/玄幻）有各自行业词，加到第 2 层。
- 新增判例：发现新的"名词硬当动词"违规，补进「已知已修判例」表，并同步回 `创作偏好.md`。
- 子代理提示词可随判定口径收紧/放宽。
