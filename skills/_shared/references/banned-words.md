## 旁白口号腔（叙述者跳出来喊口号，出现即改）

**特征**：作者旁白（无说话人、无引号）用排比＋抽象大词（正义/法治/尊严/真相/公道）＋口号收尾（不胜不休/正义必胜/绝不妥协/依法维权到底）替全书点题，读着像电视普法节目的旁白字幕 / 法治宣传片解说词。

**判据口诀**：把句子抽出来读，像不像普法旁白字幕？像 → 命中。

**与已有规则的边界**：
- 引号内台词口号（「正义的审判才刚刚开始」「不胜不休」）归 `dialogue-naturalness-scan` 第 6 类（advisory），由本段**旁白侧**互补，两条口径不重复计。
- in-world 群众/群聊口号（家长群刷「正义必胜」「感谢江律师」）是场面描写，豁免。

**改法**：删掉口号尾，收束成角色当下可见的场景/动作/物件（窗外、白板、证据链、灯光、卷宗、送达回执），情绪留给下一章钩子，不替读者下结论。示例（Ch068 已修）：「法援律师用铁一般的证据与法条……正义必胜！」→「窗外暮色苍茫，会议室内的灯光坚定而温暖。江澈把三份专项法律意见书并排放进卷宗，第一页上，校方的免责协议被红笔划了一道。」

**高频口号家族（命中即改，勿同义轮换）**：不胜不休 / 正义必胜 / 正义绝不（缺席|低头|妥协） / 胜利终将（必将）属于 / 依法维权到底 / 法治的晴空（轨道|底线|威严|蓝天） / 正义的（审判|锁链|巨浪|钟声|铁壁|利剑|铁拳|法网|利刃|防线） / 紧握正义之（剑|笔） / 筑起（铸就）正义的（铁壁|屏障|盾牌|巨伞） / 撕开（击穿）虚伪（伪善）的（面具|外壳） / 真相终将大白于天下 / 光明（黎明）终将来临 / 黑夜终将过去 / 公道自在人心 / 朗朗乾坤（晴空） / 公平正义重见天日 / 告慰……在天之灵 / 法援律师用……筑起…… / 法援律师的目光坚定如铁。

**换皮检测（通读口径）**：口号家族会换皮——同义大词轮换（正义必胜→公理长存/邪不压正/天理昭彰）、武器库轮换（正义的利剑→法治的长矛/法律的雷霆）、排比动词换词（击穿壁垒→碾碎防线/荡平障碍）、收尾口号换字（不胜不休→誓不罢休/战斗到底）。正则只抓已知皮，**未知新皮靠功能判据兜底**：不看用了哪个词，只看这句旁白在干什么——是不是替读者下结论/宣告结局/升华主旨？是 → 命中。通读时遇叙述性收尾句（章末、案件收口、胜负揭晓后）一律先过这道功能问：收束可见场景（窗外/白板/卷宗/送达回执/当事人反应），还是在替全书喊口号？后者即换皮口号，按改法清掉。发现新皮后当场补注册进本段家族 + `check-ai-patterns.js` 的 `NARRATION_SLOGAN_PATTERNS`，防止下次漏扫。

## 最毒禁用句式（出现即修，最高优先级）

写网文最毒的 AI 句式，作者一旦养成就会反复出现。Gate A 第一遍扫描必须命中：

| 毒级 | 句式 | 错误例 | 修法 |
|------|------|--------|------|
| ★★★★★ | "不是A，（而）是B" / "不是A，不是B，（而）是C"（"而"可省略，省掉也算命中）| "他不是冷漠，而是绝望" | 直接写 B 或用更自然的表达 |
| ★★★★★ | 「不是A，是B」主宾类别错配（X 与 Y 语义类别不一致：物 vs 行为/用途，如"协议不是赔钱""合同不是赔偿"）| "这协议不是赔钱，是封嘴的"（协议=纸 ≠ 赔钱=钱的用途，比较基准错位，读者要猜说话人指的对象其实是钱）| 先统一比较基准到同一类别（该指钱就指钱），再把抽象概括落到具体画面/怕因；如「这钱不是赔医药费的，是封嘴的。他们给得这么急，是怕他缓过神来，反悔。」 |
| ★★★☆☆ | 跨段「不是A。/也不是B。/只是C。」 | 「不是嚎啕大哭。/也不是扯着嗓子喊不舍。/只是一个人走远了……」 | 语义复核；重复提纲或拖慢画面时压成 C，有辩解/悬念排除功能可保留 |
| ★★★★ | "，带着……" 万能状语 | "他笑了一下，带着一丝不易察觉的嘲讽" | 删掉状语留主句，或换具体动作 |
| ★★★★ | 无情绪声线 / tell 语气质量："声音不大，却带着……" / "语气毫无波澜" / "平静无波" / "声音平直/平平/听不出情绪" / "把话放得平平的" / "说得平平静静"（同族：把X放得/说得+平/静/冷/稳等质量形容词） | "她声音不大，却带着不容置疑的力量" / "他把这些天数说得平平静静" | 直接写台词内容、声音特征或具体发声动作/生理锚点（没抬声、声没高、压低、放缓、动作），勿用"平/静/冷/稳"等质量形容词 tell 角色语气；区分：把声音压低/把语气压低/把声音调到很轻 是具体发声动作（SHOW，保留），把话说完/把话说得太满 是习语（保留） |
| ★★★★ | "他/她知道……" | "他知道这一切都来不及了" | 用行为展示认知 |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 删掉或白描 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 他垂下眼 / 他嘴角一扯 |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" | 用身体反应 |
| ★★★ | 抽象命运/开端收束："命运……棋局/獠牙" / "这一刻终于明白" / "反击才刚刚开始" | "命运终于露出獠牙；属于他的反击才刚刚开始" | 回到角色当下可见的文件、动作、对话或物理后果 |
| ★★ | 章末预告 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 用具体钩子物件/事件收束，避免空泛预告 |

> 凡命中 ★★★★★ 一处即视为重度AI味的强证据；★★★★ 命中 ≥2 处即触发中度复扫。

`check-ai-patterns.js` 的 `formulaic-parallelism` 还会提示「至于X不X，怎么X」和同动词「不V A，不V B」。这两类可能是功能性口语，因此只做 advisory；Gate B 必须连同台词读语境复核，若只是复述细纲/前文就压成一次判断，不能因 hook 豁免台词而跳过。

**标点**：正文（含叙述和对话）禁用破折号 `——`/`—`、双连字符 `--` 和省略号停顿，改用句号、逗号、短句或动作断句；不设置对话破折号例外。盐言「」引号不在此列。

## 省略过头的作者速记（人工门禁，出现即修）

禁的不是某个动词，而是作者省掉对象、动作或意图后，句子在自然叙述里不能独立成立，只能让读者替作者猜完整意思。判断时把句子单独拿出来读：如果“他没再做什么”“她在反对哪一点”说不清，就是作者速记。

修法不是机械补宾语。优先改成自然叙述，明确“咬牙签下什么”“没接谁的话”“没反驳哪一点”，或者直接写人物当场的停笔、看材料、移开视线、把文件推回去等动作。`咬牙认 / 没再顶 / 不再顶 / 没在顶 / 复了出来` 是自动检测样例，不代表规则只管这几个短语；正常口语中对象明确、现场能直接接上的省略不禁。

### 独立微动作占位句（人工门禁，出现即修）

禁用“人物＋泛动作＋一下/一眼/一秒/一句”充当反应或对白桥，例如“拦了一下”“脚步顿了一下”“沉默了一秒”“看了一眼”“最后只回了一句”。能删就删；确有信息功能时写清动作对象、造成的变化或人物实际选择。对白直接发生，不用“说/问/回了一句”垫场。按钮操作、医疗处置等确有次数意义的具体动作不误杀。

## 抽象对象被当物理对象处理（目光/视线/情绪/声音被"压/钉/砸/拽"等施力，出现即改）

抽象对象（目光/视线/眼神/记忆/念头/思绪）不是物理实体，不能承受物理施力动作（压/钉/砸/拽/扯/拧/掰/塞/抽/挤）。反例（Ch002 韩克勤）「目光压在那份协议上」——目光不能"压"。正例「目光落在那份协议上」。与前「物理清除动词×抽象对象」段互补：本段抓"抽象对象在主语位被施力"，那段抓"抽象对象在宾语位被清除/抹消"。判定：主语能不能真做出这个动作？能→豁免（如"视线扫过""目光追着"是视线自身移动，非被施力）；不能→改"落/停/移/转"等视线自身动作，或改主体为实体。注意：**"声音"不在此列**——压低声音是真实生理动作（声带收紧），"声音压着/把声音压下来"是合法表达，勿判错配；"情绪"亦高度惯用（压抑情绪），不纳入正则，靠 ai-flavor-scan 第 8 层人工通读另判。

以下为正则（每行一条，写在 /.../ 之间，由 check-ai-patterns.js 运行时加载为 blocking 规则）：

## 全知抒情旁白（替角色下情绪结论，出现即改）

**特征**：作者从全知视角替角色"下结论"——用情绪标签词（发懵/愣住/不敢信/没想到/心头一暖）直接宣告角色的心理状态，再用一句抽象收束（"替他往前走一步""替他扛""终于有人愿意"）把感动/转折"点题"出来。读者拿到的是旁白结论，不是角色当下可见的动作、物件、对话或身体反应。

**为什么毒**：① 把本该"演"的反应压成旁白直给（Tell 无 Show 的抒情变体）；② "正确"的感动/释然是道具不是活人（违背「内心要脏要乱」：活人第一反应往往是怀疑、麻木、警惕，不是标准感动）；③ 抽象收束（"往前走一步"）是压缩式文学比喻，无可见对象，读者要靠脑补。

**实案例（本项目 Ch001 原文）**：`周春来还坐在那里，发懵，不敢信真有人愿意替他往前走一步。`
- 问题：作者替周春来宣告"不敢信"，又用"替他往前走一步"抽象收束；他被坑怕了的人，第一反应不该是标准感动。
- 已改法：`周春来还坐在那里，没动。他盯着桌上那叠协议，喉结动了一下，什么也没说。`——用"盯协议/喉结动/没说话"的具体反应留白，信不信由读者自己判断。

**改法**：删掉情绪标签词和抽象收束，换成角色当下能看见的动作、物件、对话或身体反应；情绪如果一定要露，给"脏/乱"的一闪念（怀疑、麻木、怕又是骗局），不要给"正确"的感动宣言。宁可留白，不要点题。

**误杀豁免**：活人台词里的口语（"我真没想到你会帮我""谢谢你替我跑前跑后"）是正常表达，不算本类；本类只针对**作者旁白**替角色下情绪结论。

**脚本拦截**：对应高精度正则已注册进「通感隐喻」段末尾（check-ai-patterns.js 自动加载为 blocking）。

## 主语歧义 / 视角断裂（段首"他/她"承接错位，出现即改）

**特征**：同一场景或相邻段落里，叙述主语从角色 A 切到角色 B，但 B 仍用"他/她"指代且未点名，读者按就近原则会把"他/她"误读成 A。典型是**电影化跳切**：A 定格（坐着/站在原地没动）→ 切到 B 的动作/心声，中间无过渡、无点名。

**实案例（本项目 Ch001 原文）**：
```
周春来还坐在那里，发懵，不敢信真有人愿意替他往前走一步。
楼道尽头，午后的日光斜斜照进来，把他半边脸压进阴影里。
他没回头。只是更用力地攥紧了手里的协议。三天。够了。
```
- 问题："三天。够了。"是江澈对韩克勤期限（"三天拿不出方向，案子换人"）的回应，主语已切到江澈；但"他"紧跟在周春来后面，读者误读为周春来。"攥紧手里的协议"也属于江澈（他按平要带走核查的那份）。
- 已改法：`江澈走到楼道尽头，午后的日光斜斜照进来，把他半边脸压进阴影里。`——切镜头时点名新主语。

**判定口诀**：段首"他/她"的所指，能不能靠性别代词（他/她）、场景连续、前文点名**立即辨认**？
- 能辨认（如"林晚猛地抬头"→"他语气还是平的"，"他"靠性别/在场人物可解）→ 豁免，不算病。
- 会误当成上段角色、或动作归属矛盾（"攥协议/三天"明显不属上段角色）→ 真错位，该点名主语或加过渡。

**改法**：切换视角/场景时在段首点名新主语（"江澈走到…"），或用场景过渡句把镜头交代清楚；短心声（"三天。够了。"）若属另一角色，前一句先落到该角色身上。

**豁免**：正常承接不算（"江澈把协议按平"→"他盯着…"）；对话后接说话者动作（"那就法庭上见。"→"他转身离开。"）若前文已立说话者，不算。

**脚本辅助**：段落级疑似检测见 `.agents/skills/_shared/scripts/check-subject-switch.js`（advisory，输出上段末句+本段首行供人工复核；正常承接豁免）。

## 句内主谓动线与代词指代错位（三项主谓防错，出现即改）

**特征与三项防错铁律（2026-08-20 固化）**：
1. **双人交互连逗号（主语突变）**：句首是人名 A，逗号后无过渡直接用代词「他/她」切换到人名 B 做动作。
   - 反例（Ch036）：「江澈指了指对面的椅子，他把双拐靠在椅背边……」——代词"他"在语法上承接句首主语江澈，读者直接误读成江澈拄拐。
   - 正例（Ch036 已修）：「江澈指了指对面的椅子。周春来把双拐靠在椅背边……」——双人动作交互必用句号断开，或在后句直接点名新主语。
2. **同性同场代词漂移**：同一场景内有两名同性角色（江澈/韩克勤、苏青岚/彭晓蕊），分句使用裸代词「他/她」，导致指代混淆。
   - 反例（Ch106）：「韩克勤总爱先把难处说足，他听归听，手里的材料还是得往下推。」——"他听归听"实指江澈，紧跟在韩克勤之后造成误读。
   - 正例（Ch106 已修）：「韩克勤总爱先把难处说足，江澈听归听，手里的材料还是得往下推。」
3. **物理动线受体脱节（施力者自伤错配）**：施动者扔/甩/推物品，紧接未指明所属的身体受创反应，导致施力者被误读为自残/自伤。
   - 反例（Ch001）：「韩克勤把一沓材料扔到桌上，纸边划过手背，一道细口子，蜇得他缩了一下手。」——施力者韩克勤扔材料，紧接无主语的纸划手背和缩手，语法上直接让韩克勤成了受创缩手的滑稽角色。
   - 正例（Ch001 已修）：「韩克勤把一沓材料扔到桌上。卷宗顺着桌面滑过来，锋利的纸边擦过江澈搭在桌沿的手背，划开一道细口子，隐隐的刺痛蜇得他手指缩了一下。」——补全物理运动轨迹与受体部位。

**判定口诀**：两人物动作必断句、同性同场不省名、物理受击写轨迹。

## 比喻分类（默认复核，不默认全删）

带"像/如/仿佛/犹如/宛若"的比喻不是一律 AI。真正高风险的是：成片堆叠、套用万能文学比喻、用精致比喻替代剧情推进，或在段尾替读者总结意义。本表用于识别需要复核的比喻类型：

| 比喻类别 | 例 | 处理 |
|---------|----|------|
| 生活/角色化 | "像一头被抛弃的野狗" | 若贴角色视角、能传递信息或情绪，可保留 |
| 物品/现象类 | "像一把刀" "脸色惨白得像这漫天的雪" | 普通功能性比喻可留；模板化或重复时改白描 |
| 状态类（陈词滥调） | "梨花带雨" "如沐春风" | 优先删或改成具体动作/表情 |
| 抽象类 | "像命运的齿轮" "像上辈子的尘埃" | 高风险，优先落回动作、物件、声音、后果 |
| 假设类 | "力道大得像是要把骨头捏碎" | 若是角色身体感知可留；夸张堆叠时改事实后果 |

处理原则：先看功能，再看密度。保留最能传递信息或情绪的一两个，其余改为直接描述、动词、名词、作用、结果或事实；不要把删掉的比喻替换成另一批新比喻。例 "脸色惨白得像这漫天的雪" 若只是套话 → "脸色惨白"；若雪景正在压迫角色，可保留或改成角色当下看到的具体画面。

> `metaphor-density-tic` 是 advisory：提示通读复核，不是 blocking；生活化、角色化、单个有功能的比喻可以保留。

## 抽象裁判金句（讲起来像硬话但逻辑不落地，出现即改）

修法例：“海里讲的是水性，不是你嘴上那点威风。”

错误例：“别人认的是水里那口真。”

错误例：“海上先认活路。”
修法例：“海上先把命留住。” / “保命的规矩得先摆出来。”

错误例：“现在就该长骨头了。”
修法例：“现在就该把规矩立起来了。” / “水上的摊子就能立住。”

## 双端悬空的“的”字身份跳转句（主语与身份指代同时悬空，出现即改）

结构为“动作/状态＋的，成了/变成了/换成了＋代词”，如“醒来的，成了他”。左端的“的”字结构省掉中心语或经历者，右端又只用“他/她/自己”代替新身份，再用逗号硬造揭晓式停顿，导致“谁醒来、谁成了谁”同时含混。

判定必须同时满足：左端无明确中心语；中间是身份转换谓语；右端代词后直接收句。正常的“活下来的，是顾青禾”“醒来后，他成了江澈”“留下来的那个人，成了他的证人”不属于本类。修时补齐时间、经历者和新身份中的必要信息，写成完整主谓句；不要改成另一种悬空省略。

以下为高精度正则（每行一条，由 check-ai-patterns.js 运行时加载为 blocking 规则）：

## 反问式内省/伪深刻对比（靠反差+模糊指代+反问做内省，出现即改）

用「倒被X吓住？」式伪深刻反问做内省：靠“过去狠/现在怂”或“如今…倒被…”的反差撑出“人物复杂”，并配模糊指代（一沓纸/那页东西/这玩意）。这是词表扫不出的高级 AI 味——没有禁用词、不是病句，靠反差+反问表演深度。改法：删掉表演式反问，改成角色当下可见的具体动作/生理反应（手抖/手顿/把纸翻过去）或本书招牌“裂痕”装置展示，对象写具体（这份材料/这份协议），去掉文艺腔反问。

## 人物声口错位（台词不符合说话人的职业身份与性格底色，出现即改）

把台词写成"谁都能说"或"跟角色身份拧着"的话。核心两道关：① **专业性匹配**——职业决定用哪套词，资深律师/法援主任说法律人逼证据口吻（"空口无凭""你想清楚"），不冒市井江湖腔；有黑道前科、市井出身的人才说"这钱是封嘴的"这类市井类比。② **性格底色匹配**——硬冷稳的人短促压人少解释，市井圆滑的人可插科打诨但玩笑落回行动，规矩型的人用词准确不掺情绪词。反例（Ch002 韩克勤）「这一句，讲得圆吗？」（市井腔，与法援中心主任身份拧着）→ 正例「空口无凭。」（法律人逼证据标准口吻）。判定口诀：把台词抽出来、不看名字，猜不出是谁说的、或跟这角色身份性格拧着，就是声口错位。此条是语义层门禁，正则抓不住，靠 ai-flavor-scan 第 9 层 / dialogue-naturalness-scan 第 8 类人工通读判。

## 痛感/感受当物理动作的可数宾语（"X出+一道/阵/股+感受"，出现即改）

把痛感、感受、情绪当成能被"刮出/划出/切出/擦出/挤出"的实体宾语。痛感是身体反应不是物体，不能被"取出/产出"。正确写法：写痛感的性质（蜇/灼/锐/钝）或身体反应（缩手/倒吸气/咬牙），不写"出+一道+感受"。本正则只抓高频结构，语义层错配（如"纸的棱角"属性错配、"擦过却刮出"力度错配）需靠 ai-flavor-scan 第 8 层人工通读判。

## 假紧张感/戏剧化关门隐喻（用悬浮戏剧化比喻替代具体程序/事实后果，出现即改）
