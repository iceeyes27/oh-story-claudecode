# Batch Pollution Detector（批量插入污染检测）

## Overview

脚本批量插入句子时，容易把同一句话复制进大量章节，产生三种污染：
1. **复读**：同一长句（≥15字）跨多个文件重复出现，读起来像复读机
2. **错位**：句子被塞进对话引号内、主语与上下文不符（如男性角色说话却插"她说"）、场景不符（电话里冒出"看手里材料"）
3. **工程词泄漏**：细纲/情节点/待补/内档等写作工作语言混入正文

本 skill 定位：**快速定位污染、打印上下文供人工判断**，不自动改文（删除须由人工确认，因部分复读句可能是刻意重复）。

## 触发场景

- 对 `正文/` 做过脚本批量插入（补人物特征、补内心独白、补动作尾巴）之后
- 用户报告"这句话好像在哪见过""这段上下文不通""主角怎么突然说她的"
- 批量生成章节后做质量检查
- 任何对多文件做 replace/insert 操作后

## 检测流程

### Step 1：跨文件重复长句检测（核心）

运行脚本：

```bash
for PYBIN in python3 python py; do "$PYBIN" -c "" 2>/dev/null && break; done
"$PYBIN" scripts/find-duplicates.py <文件或目录>
```

脚本行为：
- 按句号/问号/叹号切句
- 统计 ≥15 字的句子跨文件出现次数
- 输出：`×N 次数 | 句子 | 出现文件列表`
- 次数 ≥3 且句子 ≥18 字 → 强信号（复读污染）

**判定规则**：
- 同一句出现 2 次：可能是有意的重复强调（排比/呼应），人工确认
- 同一句出现 ≥3 次：极大概率是脚本复读污染
- 句内含「他说/她说」但上下文主语相反 → 错位污染，必删
- 句尾带句号却嵌在引号内（`"……他说的。她说这话时不看他……"`）→ 错位污染，必删

### Step 2：引号内插入检查

对 Step 1 命中的每处，打印前后 20 字上下文，人工确认：
- 是否在 `"` 引号内
- 主语是否与说话者一致
- 场景是否匹配（电话里 vs 面对面、白天 vs 夜里）

### Step 3：工程词泄漏检查

```bash
grep -rn "待补\|细纲\|情节点\|内档\|TODO\|待后续\|(待\|【" <正文目录>/
```

以上词汇不应出现在正文。命中即工程词泄漏。

### Step 4：引号/括号平衡检查

删除污染句后，必须检查引号是否失衡（删掉的是引号内内容时尤其重要）：

```bash
"$PYBIN" scripts/check-balance.py <文件或目录>
```

输出失衡文件列表。中文引号 `“”`、单引号 `‘’`、ASCII 引号 `"` 分开统计。

## 清理原则（人工执行）

- **先备份**：`mkdir -p /tmp/<书名>_backup && cp 第*.md /tmp/<书名>_backup/`
- **整句物理删除**：污染句一般是完整句子，直接删除恢复原文衔接
- **删除后必复扫**：重新跑 Step 1，确认重复数归零
- **删除后查引号**：若污染句嵌在引号内，删除后检查引号是否失衡、段落是否变成残句
- **残句修复**：删除后若出现「苏青岚，」「她，」这类缺动词的残句，补"说"字
- **工程词替换**：如「待后续卷追」→ 改为正文可读的自然表述

## 误杀防护

- 不删除刻意重复（角色的口头禅、排比强调、前后呼应）——人工判断
- 不删除承载信息的句子（证据、时间线、关键对话）——只删"复读机器句"
- 复读句若语义自洽且只有 2 处，倾向保留

## 真实案例（2026-08-02，《法援律师》第一卷）

- 污染 1：「她说这话时不看他，看的是手里的材料。刚才那一轮他漏了一个程序点，她看见了，没说。」×20 章——多数嵌在对话引号内、主语错乱（江澈说话却插"她说"）、电话场景里"看手里材料"
- 污染 2：「他在心里过了一下：这套说辞跟上辈子收债时听的话是同一套，只不过换了个公章。」×18 章——江澈内心闪念机械复读
- 工程词：Ch032「待后续卷追」、Ch044「这内档。」（病句残留）
- 残句：Ch027「苏青岚，」「她，」缺"说"字
- 全部整句删除/修复，正文恢复正常

## 预防建议

- 批量插入脚本写入前，先检查目标位置是否在引号内、是否已含同类句
- 插入后立刻跑本 skill Step 1 复扫
- **脚本只用于纯机械操作**（删整句、替换固定词），语义性插入优先手改
