# 小说逐幕精修

用于逐幕修复具体阅读障碍与逻辑裂痕，保住场景效果；案例不等于普遍规律，检查通过不等于作者采用或文学质量已获验证。

## 范围与资料

- 先确定用户要审阅、候选改写还是采用已确认版本。“只分析／先不改”仅在回复中报告，不写正文、设定、追踪或报告文件。
- 修改 skill 不构成修改小说的授权；候选不自动成为正式正文。已有明确授权继续有效，不重复确认已接受的范围。
- 读取目标正文、必要的前后文、相关设定与文风样本。正文和记录冲突时列出差异，不凭旧追踪覆盖当前版本，不把文件存在当作作者采用证据。
- 若项目有特定约束，读取项目设定及文风样本；可参考本地案例。其他作品不继承具体书目的特殊设定和禁词。

## 工作流程

1. **确定保留项。** 明确本幕冲突、人物目标、结束时的变化，以及作者已认可的句子、情节或声线；避免为了统一风格消除人物差异。
2. **按自然场景定位。** 依据地点、时间、行动目标或冲突阶段切分，不规定场景数量。默认聚焦一个问题或一幕；用户明确要求整章处理时按授权范围完成。
3. **先证据，再改法。** 指出原句位置、问题如何影响阅读、成立条件。区分算术或前后冲突等明确错误，与节奏、语气等审美建议。解释根因，避免只替换表面措辞。
4. **最小必要修改。** 简单问题给一个修正；有实质性取舍时才提供备选，说明对人物、节奏或后续情节的影响，不固定 A/B 风格。
5. **保留作者采用权。** 逐幕模式下，作者确认本幕后再推进。已确认内容默认保留；发现新冲突时提出具体回修范围。“锁定”表示不擅自改动，不表示不可修订。仅在现有项目流程要求时记录采用版本，不另造追踪体系。
6. **回读与扩散复核。** 候选完成后检查本幕、整章和受影响的相邻章节；采用时核对的必须是同一版本。钱款、时间、能力或人物知情范围有变化时，沿引用关系查相关后文，不无差别重审全书。授权范围外的问题报告位置与影响，不顺手修改。

## 通用检查方法

### 钱款与资源

- 将现金流、债务口径和资产用途分开。涉及计算时在工作笔记或回复中列出持有人、期初余额、实际收入、实际支出、期末余额；正文不必展示整张账表。
- 核算：`期末余额 = 期初余额 + 实际收入 - 实际支出`。自有存款、借来的钱、赔偿分别记账；转移不产生新收入，归还本金不能又算成自有存款。
- 另列票面本金、实际到账、已扣费用、计息基数、利率、期间及罚金规则。规则不明就指出缺项，不臆造公式；人物故意算错或欺诈时，检查读者能否识别其意图。
- 区分月收入、月结余和偿还时间；比较金额时保持币种与口径一致。货币换算和物价需有适用依据，不能靠总预算反推价格。
- 检查资金用途是否互相争用：若有存款却无钱治病，需要有足够情节依据；不强行添加解释来掩盖矛盾。
- 账目自洽只说明钱的去向清楚，不自动说明行为正当或人物讨喜。不能仅靠更名为“赔偿”改变行为性质。

### 博弈与人物行动

- 对关键决定检查：人物当时知道什么、能做什么、想保住什么、有哪些替代选择。
- 退让需要可信的威胁与退路；查证据是否能保存、送出，对手为何不抢夺、否认或报复。允许有依据的虚张声势、误判和情绪决策，不要求人人完全理性。
- 亏损金额是条件之一，不能规定“亏到某数必然拼命”。也不能用反复描写恐惧替代威胁成立的依据。
- 检查叙述视角：主角的推测与对手内心事实是否混写；遵循作品既有视角，不临时全知来解释所有人。

### 设备与有限能力

- 核对输入状态、调用功能、消耗、输出状态及下一次启用条件。区分待机、休眠、关机，不能只让电量递减却忽略功能限制。
- 低资源时检查调用是否值得、是否有更低成本的办法；不把心算或关机规定为唯一答案。
- 真实技术判断需有适用条件和可靠来源；幻想能力按本书已采用设定复核。没有依据时，不以“专业操作”为名添加数据损坏、扫描能力或充能协议等事实。
- 隐蔽操作检查距离、朝向、遮挡、声光强度与旁人注意力。贴身拥抱者可能更容易听见，不能只写“遮挡/掩盖”就认定保密必然成立。

### 对白、措辞与阅读效果

- 按说话者身份、时代认知、交流对象和现场目的判断措辞；区分当地人物、穿越者内心和现代 AI。先核对作者偏好，不建立跨作品通用禁词表。
- 删减只重复已知信息的独白、威胁或解释；保留改变局势、暴露关系或塑造人物的部分。说话、沉默和动作都可有效，不把“冷淡无声”当作高级感公式。
- 称谓变化以指代清楚为准；币种明确时允许泛称。生理反应是否套话取决于频率和表达作用，不机械替换成另一套微表情。
- **AI 恶癖专项过滤（强制自查）**：
  - **禁指认说明腔（这是/那是）**：检查段落中是否出现高频“这是……”、“那是……”做导游式解释。直接呈现物理事实与感官体验，严禁跳出视角指认。
  - **禁伪成语与生造杂糅**：严禁“寸影随行”、“神情冷凝”等近义词拼凑伪成语；成语必须正规且严格低频，叙述优先用朴素有力的单字动词。
  - **禁机械生理反应标签**：严禁遇变故就“心口发紧/浑身一僵/动作一顿/倒吸凉气”等陈腐垫脚石。
  - **禁产品规格参数腔**：现代物件（手机、仪器）严禁写成电商参数表（如“磨砂背壳，防滑涂层”），转化为具体动作（按键、卡入、握持）。
  - **禁修饰与比喻堆叠**：一段内禁止连续出现多个比喻（如“像干树枝……像干柴一样”），修辞从简。
  - **禁语域方言与术语错配**：西方魔幻题材严禁出现中国本土俚语方言（如“汤子”、“折腾”），非现代科学视角严禁出现“神经末梢”等解剖学词汇。
- 回读修改后的段落：术语、修饰和解释是否超过场景需要，紧急行动是否被说明打断，人物是否仍有各自声线，章末是否保住原有期待。

### 空间、道具与跨章连续性

- 检查人物位置、双手占用、移动路径、视线和道具持有人；损坏物件不会因换段消失。
- **姿态与微动作物理守恒**：身体姿态、双手握持状态前后必须物理守恒。例如前文猝死时双手在键盘上改方案，后文不能无端写成手里攥着手机；道具位置转换必须有合理解释或动作过渡。
- 道具替换要核对获得时间、地点、条件和用途。相邻章已能自然补足的信息不必在章末重复交代。
- 修改结尾后对照下一章的时间、地点、伤势、余额、设备状态及人物知情范围；解释一个接口时不能破坏另一个接口。

## 证据与交付

- **原著／现实事实**：给可定位来源及适用条件；不能因未检索到就断言不存在。
- **本书自设**：标注正文或设定位置、是否已采用；与原著不一致时先检查是否为有意改编。
- **推测／偏好**：明确标识，不冒充硬错误或原著规则。作者明确偏好在约定范围内执行。
- 审阅按影响排序，提供位置、证据、原因和建议；修改交付说明改动范围、复核覆盖和未解决项。候选形成、复核通过、作者采用分别报告，不宣称已提炼“全部法则”或完成未验证的全书检查。
