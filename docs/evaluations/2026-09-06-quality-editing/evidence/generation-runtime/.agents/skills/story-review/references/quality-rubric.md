# 通用网文内容审查 Rubric

> 评估故事文本的实际阅读效果。所有平台都先用本书承诺、题材与章节功能选择适用项，再补平台参考；平台名称不能代替题材。

## 适用范围

审查前从作者要求、本书文风与细纲或正文证据中确认 `题材 / 本书承诺 / 当前章节功能`。功能可以是日常相处、观察、休息、过渡、调查、试错、冲突、高潮、回收或余波；不知道时标“未确定”，不自行补设定。

- 只评价当前功能适用的维度；未发生的高潮、关系跃迁、任务卡点或伏笔操作记 `N/A` 并说明原因，不算 FAIL，也不进入评分分母。
- 日常与休息可以靠人物相处、气氛、认识变化或前事余波成立；不为达标强造阻碍、升级、反转和新悬念。
- 有功能不等于每步都要展开：读者已懂的程序反复确认、没有新作用的情绪复述仍需指出。

## 评分方法

适用项按 PASS / WARN / FAIL 标记；证据不足单独记录。分级依据是阅读损失，不是词频、句长、对白比例或模板完整度：

- 破坏主线、角色动机、世界规则或读者信任 → S1
- 明显影响理解、章节回报、节奏或人物可信度 → S2
- 局部重复、措辞、格式或节奏问题 → S3
- 有功能的风格差异或可选增强 → S4，不阻塞发布

扫描只消费实际 `severity`、来源和作用域；不在 rubric 重建 blocking 类别清单。语境/密度提示必须复核，不能按词类自动升级或清零。

## 核心维度

| 维度 | PASS | WARN | FAIL |
|---|---|---|---|
| 核心卖点 | 本章以行动、关系、气氛或认识服务本书承诺 | 本章作用较弱或被重复内容稀释 | 与本书承诺冲突，或完全没有可指出的故事作用 |
| 冲突推进 | 适用的阻碍、选择或代价按本章功能发展 | 有冲突却只重复同一轮交锋 | 冲突无法成立，或关键选择无因果 |
| 任务卡点 | 已有任务被卡后带来信息、关系、代价或选择变化 | 卡点有用但流程展开过量 | 卡点只剩步骤重复，明显拖住本章回报 |
| 情绪曲线 | 感受与题材、铺垫及当前场面相符，克制与平稳也可成立 | 局部情绪重复或变化铺垫不足 | 情绪转向与已发生事件矛盾，或承诺的情绪兑现落空 |
| 钩子与期待 | 目标、人物相处、关系、后果、余韵或开放问题提供续读理由 | 理由存在但被重复或含糊收束削弱 | 用空钩逃避已承诺的兑现，或前后行动失去联系 |
| 角色动机 | 行为符合目标、性格、处境与关系压力 | 局部选择缺少可恢复的依据 | 人物为推动剧情而失真 |
| 对话质量 | 台词符合说话人意图与处境，指向清楚且有作用 | 有重复信息或声音略同质 | 人人同腔、知识越界或对白导致关键误解 |
| 设定一致性 | 不违背既有规则、时间线和角色事实 | 有模糊点需补证据 | 与正文或已接受事实冲突 |
| 文字自然度 | 直写、动作、修辞和留白服从本书声线，信息清楚 | 局部套话或修饰拖慢，但不妨碍理解 | 措辞、反复清洗或模板反应明显遮住人物与意思 |
| 句长节奏 | 主体、连接、结果清楚，句法随场面变化 | 局部机械碎句、长句或长短交替 | 主干失踪或必要信息被省掉，妨碍理解 |
| 标点节奏 | 标点服务语气、迟疑、打断、未尽与人物声线 | 局部单调或无功能堆砌 | 标点造成错误语义或抹平关键语气 |
| 具体字数表达校验 | 具体字数核对属实且统计口径清楚 | 字数属实但此处表达冗余 | 字数与被指文字不符 |
| 格式可读性 | 按信息与戏剧单元自然断段，对话可辨 | 局部段落或主语组织拖慢阅读 | 机械切段、混杂对白或指向混乱妨碍理解 |
| 剧情循环 | 本章或所在单元的行动、认识、关系或后果有实际发展 | 单元尚能成立，但重复步骤占用篇幅 | 关键行动与结果脱节，或读者等待的变化被流程吞掉 |
| 高潮构建 | 承诺、选择与后果在本书需要的位置有效兑现 | 有兑现但关键前因或后果不够清楚 | 依靠无来源解法，或承诺的回报落空 |
| 关系进展 | 互动符合当前关系，变化有可恢复的原因 | 局部推进略快或重复试探 | 突然亲密、信任或敌对，与既有关系断裂 |
| 伏笔状态 | 当前埋设、承接或回收与读者已知信息一致 | 局部提示重复或需补证据 | 与事实冲突、到期无交代或造成理解混乱 |

## 阅读三问

1. **这一章带来什么体验？** 先按本章功能描述人物、信息、关系、气氛或后果，不预设每章必须是冲突升级。
2. **第一处阅读损失在哪里？** 指出读不懂、想跳过、人物失真或回报延迟的原句；同时指出值得保留的表达。没有损害证据可以无 finding。
3. **哪个证据支持判断？** 没有正文证据只记“证据不足”；不靠填表和猜意图凑问题。

## 发布建议与编辑范围

| 综合情况 | Verdict |
|---|---|
| 无 S1/S2，余项不妨碍阅读 | APPROVE |
| 有具体 S2，或同类 S3 累积造成可说明的阅读损失 | CONCERNS |
| 有 S1，或核心动机、事实与本书承诺崩坏 | REJECT |

所有 finding 包含 severity、category、location、evidence、issue、fix。先列 S1/S2，再列 S3/S4；N/A 与证据不足另列，不计作已通过。报告列全硬问题，首轮编辑只选 1～2 个最高阅读损失，不因建议数量启动全章改写。consistency / factual 类只写事实核对方向；审稿不改正文。模型判断与真人反馈分开，不从 rubric 推算完读率、追读比或跳失率。
