# 试验方法与限制

这是写作资料包的描述性小试验，不是生产采用流程的完整运行，也不是证明效果的正式研究。

- 基线为修改前提交 `21663ad6cc81a3854480b803509affe33cc8b9d7`。先用该提交的隔离快照保留原规则，真实书库不参与。
- 同一题目、人物、章节必须发生的事件、付款条件、目标字数、每章一次创作。每组由同一写手连续写三章，只接收本组前文和当前章事件。三组写手相互隔离。
- 所有成功生成均使用当前任务的原生代理调用，继承相同父模型与推理设置；工具不暴露精确模型快照或采样种子。每组只有一个序列，不能从九章推出稳定效果。
- 最初 CLI 通道在写出正文前因认证失败退出，另有传输错误。随后全部成功组统一采用原生通道。失败原日志留在本机隔离试验目录，不把凭据相关错误文本复制进交付包，也不计为一份差稿。
- 基线资料包为八份强制参考，67860 字符（含拼接空行）；清理包 3084，附加场景小节包 3456。后两者恰好只差 `场景设计` 小节，已做逐字符核对。但两组共同核心本身已经提及目标、行动与后果，因此试验只隔离这一附加小节，不能解释为“完全没有场景方法”与“有方法”。
- 完整首章输入分别为 68945、4169、4541 字符。后续输入包含本组前文，因此长度不同；每章实际输入、正文、文件摘要和计数都在 manifest 中。计数口径在共用提示里写成“有效字”，曾被两个写手自行解释为不含标点；最终统一用项目计数器验收，没有修改原稿。
- 每组规则在开始该组前冻结；汇总 manifest 在基线第一章之后整理。因此不是完整预注册的效果研究。没有掩饰或追改这些时间关系。
- 试验没有装入完整代理模板、生产状态卡、候选事务或正式采用凭证。固定参考减量不等于整个生产调用减量，试写表现也不等于实际部署后的端到端表现。
- 冻结以后，最终部署资料又澄清了计数口径、裸首稿预检顺序、编排器负责审查，以及代理模板允许一句兑现相连语义点。冻结资料包没有回写，详情见 manifest 的 `post_freeze_changes`。本次样章不能作为这些最终澄清版本的精确效果验证。
- 三位审读者分别只读一个匿名版本的三章与同一评审问题，没有设定、大纲、目标答案或其他版本。匿名编号随机分配后固定。模型审读未按意见修稿，未生成赢家或真人分数；不同审读者的偶然差异没有被估计。
- 正文文件按字节保留原样，输入与原稿共 18 个摘要均核对一致。没有为让扫描通过改词、删掉超长章、换稿或重采样。
- 机器扫描与盲读是两个证据来源。禁词命中不等同于阅读困难，愿意继续读的模型回答也不等同于真实留存。完整候选采用检查和真人反馈均未评估。

原始文件位于 `evidence/{baseline,cleanup,combined}/`：`chapter-NN.md` 为原稿，`chapter-NN.prompt.txt` 为实际输入，`policy.txt` 为冻结规则；`reviews/` 保存相同审读问题和一次审读结果。分组由 `mapping.json` 记录。
