# 长篇滚动设计复核

用于新建或扩写剧情单元卡，以及扩卷、开新卷或调整全书规划。复用现有单元卡、总纲和卷纲，不另建故事事实台账；本文件不定义连读检查的运行时命令或收据格式。

## 1. 适用条件与对标选择

- 作者未选择对标（包括明确不用）时，以本书题材定位、读者契约、卷纲、细纲及已有正文为依据，按需使用通用方法，正常继续。没有自定义文风也不因此强制选对标。对标目录存在不等于作者选用了其中的书，不按字典序自动选书。
- 已明确选用对标时才检查相应资料；登记书找不到、必需的情绪模块或节奏资产缺失时，停止受影响的准备并修复，不把损坏改报为无对标。可选资料缺失仍按原有可选规则处理；已有本书文风可替代对标文风，但不能代替已选对标的必需情绪/节奏资产。
- 组装器、直接执行和委托流程使用相同选择依据。未选对标时不调用对标召回、不检查不存在的对标资产；本章情绪和节拍来自本书规划，注明来源，不声称从对标召回。若原字段表示对标引用，填“无”，不把内部材料伪装成对标来源。
- 高压递增、能力轮换、动作外化均是按问题选择的方法，不是全书硬模板。心理直写、安静场景和生活细节有理解、人物、关系或氛围作用时保留。稳定人格与功能性配角允许存在，人物关键选择仍须有动机；不强造成长、反转、身体动作或损失。

## 2. 单元设计复核

每次新建或实质扩写单元卡，在进入该单元细纲前执行；同单元后续批未改设计时复用结论，有新设计或新的连读证据时复核受影响部分。

1. 对照前面最多 3 个已规划单元，可跨卷；不足则用实际已有数量，首单元注明无前序。不把当前单元算进窗口。按相似困境、解法或兑现方式，可再查 1 个更早相似单元，简记选择依据。数量是上下文窗口，不是要求轮换三种套路。
2. 沿用卡上的目标、选择、故事线和回报，比较困境、解法、关系后果、主线条件或兑现体验有什么实质变化。只换地点、敌人名字或数字不足以证明差异；加深、恶化、偿还旧承诺、关系回声与有意义重复均可成立，不要求五项全变或增加反转。
3. 已有正文的单元用有效连读结果校正规划假设，引用实际范围和证据出处。没有阅读结果或证据不足时明确标记，不用规划卡冒充读者体验。未写部分的结论只称“设计风险”，不能宣称读者已疲劳。
4. 疑似重复先复核其作用；确认无新作用且作者未明确保留，返回单元设计。允许说明保留理由，不按文学分数或套路数量自动否决采用。涉及已采用正文、锁定规划或核心承诺时遵守原作者授权边界，不自动改写。

在现有单元卡补一个短小节，不重复抄录全卡，也不写 PASS 代替判断：

```markdown
#### 单元设计复核
> 作用域：单元级 {单元ID}

- 对照：{前序单元ID及规划/正文依据；更早相似单元如有，说明选择理由}
- 变化或重复的作用：{沿已有目标/选择/故事线，指出具体变化或保留功能}
- 阅读校正：{已有连读证据出处与范围；无则写未审读/证据不足，不伪造结果}
- 处置：{继续细化/复核设计/返回设计/作者明确保留；理由及待回应事项}
```

已由连读检查转交“下单元处理”的事项，在本次建卡时逐项回应；可以有理由延期，不能无回应消失。阅读收据仍由既有审读流程管理，本小节只引用，不复制一份可变审读状态。

## 3. 收束复核

以下任一情形触发：扩卷、新增卷、改变核心承诺；或卷内插入/扩写单元导致新增核心债务、挤占收束区间、改变里程碑。普通场景细节调整不触发。新书初次全书规划先建立终点与预算基线，后续只复核受影响部分。

在原总纲或卷级规划中更新“收束复核”增量说明；跨卷影响以总纲为准，卷纲引用对应说明，不维护第二套总账。写在卷纲时，按既有取段器协议给该小节声明适用作用域；总纲中的小节不需要卷纲作用域标签：

```markdown
### 收束复核
- 触发与依据：{本次变动、当前已写位置、受影响规划范围}
- 剩余主问题与人物/关系终点：{哪些仍须解决或落定；稳定人格不强加成长}
- 必兑现承诺与事件依赖：{必要铺垫→选择/行动→兑现；可共用事件，不逐项硬拆章}
- 剩余章节预算：{可用区间、所需粗估区间、估算前提与不确定项}
- 取舍：{可容纳/存在冲突/资料不足；已授权调整或待作者裁定的具体选项}
```

先核对终点是否仍可由已规划的因果链抵达，再估篇幅；不提前写全书细纲，不凭预算差 1 章否决。资料不足就列出缺口，不能声称已验证可收口；重点暴露无法同时满足的承诺与体量。

只在已授权且未锁定的规划内合并、排序或压缩。改变核心承诺、人物/关系终点或全书体量，不由补纲/扩写授权自动涵盖；给出具体取舍供作者决定。作者未裁定前保留相关未决项，其他不受影响的规划可继续，不能静默增加债务或把未采用方案记成事实。

## 4. 设计情境核对

- A-B-A：两个 A 只改地点、敌人与金额，选择和回报都相同且无新作用 → 设计复核；确认后返回设计，不要求先插三种套路。
- 有意义回声：同一解法再次出现，但先前拒绝帮助的人主动合作，兑现既有关系承诺 → 可保留；正文是否呈现此变化仍需实际阅读。
- 首批连建：尚无正文的多个单元同样互相比对 → 只能报告规划风险，不伪造已发生的跳读反馈。
- 卷内挤压收口：卷长未变，新增单元挤掉终局所需铺垫 → 触发收束复核；提供合并、改序或待作者裁定的体量取舍。
- 休息与稳定人格：安静单元兑现陪伴承诺，主角性格未变但选择有动机 → 不强加冲突或成长；日常细节未改里程碑则不重算全书预算。

这些情境用于核对设计决策与边界，不是读者实测或长期质量证明。
