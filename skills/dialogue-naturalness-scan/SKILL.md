# 台词自然度 · 扫描法（真人会不会这么说话）

从《法援律师：我专打赢不了的官司》全书自然度体检中固化出来的专项扫描。
判定口径来自作者偏好：**即便不构成"行业词硬当动词"，不自然的口语表达（谁会这么说话）也要改**——本 skill 把它固化成可复现命令，把"grep 书面腔词根 + 模糊指代代词 + 只读子代理通读"固化成一条流程。

## 核心定义

**违规 = 台词不像真人在那个场面、对着那个人会开口的话。**
六类重点：
1. **模糊指代**（最该报）：台词用虚空代词（那页东西/这东西/那玩意/那事/这事…），读者或在场角色无法立刻知道指什么（没有就近清楚 antecedent）。
2. **书面腔混进口语**：普通人/当事人/律师在非正式对话冒出公文词（予以/并非/实则/换言之/方才/透过…）。
3. **别扭动宾/搭配**：动词+宾语组合读起来拗口，不像活人嘴里的话（参照已改判例：拆干净→拆了、那页东西→那份材料）。
4. **说明文式对仗 / 解释逻辑不表态度**（新，高频）：台词用对称工整的「不是 X，是 Y」「X 不是……X 是……」式冷静给对手/自己下定义，或用成语/书面总结收尾（不了了之/可想而知/说到底），读起来像**作者在旁白解释逻辑**，不像角色带着情绪和具体画面在开口。真人说话会断句散、带立场、用口语短句，不会冷静地自我对称纠正、也不会用四字成语给一件事定性。判定关键：这句是在「表达态度/情绪」还是「向读者解释因果」？后者即违规。
5. **抽象隐喻动词 + 浮空抽象形容词（不接地气 / 概念化）**（新，高频）：台词用抽象比喻动词代替具体动作（"跑=追查线索"、"拽=引导注意"、"带=转移焦点"），或甩一个浮空抽象形容词给事定性（"最虚"、"空"、"飘"、"虚浮"），读起来像**写者在用概念推演而不是活人在说话**。真人开口会用具体接地气的动词（带/耗/钻/追着打转）和具体可感的评价（没底/站不住脚/心里没数/心虚），不会用"跑"这种文学隐喻去追一条线索，也不会单甩一个"虚"字给一件事定性。判定关键：把这句里的动词/形容词换成最土最具体的口语说法，如果原文那个词是"概念"而不是"动作/状态"，即违规。
6. **点题式 / 扁平说理金句（新，advisory）**：角色用一句可脱离剧情成立的"道理 / 格言 / 书的主旨"向读者宣讲，而非在具体场景说具体的话。典型结构：工整的「论点句 + 理由句」（或「前提 + 结论」）两句呈现，常用词、语法干净、无禁用词、无对称对仗、无浮空形容词——所以词表与正则全盲，只能靠语义通读复核。判定：把这句抽掉角色名和场景，若它仍是一句"成立的人生道理 / 书的主旨"，且用论点 + 理由两句呈现 → 标 advisory 通读复核（不 blocking，避免误杀活人真在讲道理的场景）。反例（Ch002 江澈对周母）：「绝望也得讲证据。现在证据还没看完，还轮不到谈绝望。」把全书主旨浓缩成金句念给读者，论点句 + 理由句工整，不像人在现场安慰绝望的当事人，像作者旁白点题。修法方向：改成角色在现场对那个人说的、具体不念主旨的话，落到具体物件 / 动作 / 对方状态（如「先别急，这些票据我还没看完，里头说不定还能找出东西」）。判定口令：抽掉场景后，这是"一句有用的具体话"还是"一句成立的人生道理"？后者即违规倾向。

**判定口令（最关键）**：把这句台词换成**一个普通人在那个场面、对着那个人**会怎么开口？
- 真人会带具体指代、用短句、顺着对方话说；原文却用了模糊指代/书面词/别扭搭配 → 违规。
- 立刻懂、像活人说话 → 不违规。

**本质**：不是"某个词能不能用"，而是"这句台词读起来像不像人说的话"。

## 已知已修判例（正文里不应再出现，出现即报）

| 原文（违规） | 真实含义 | 应改为 |
|---|---|---|
| 那页东西拆干净 | 把那份材料彻底拆开/拆穿 | 那份材料拆了 |
| 那页东西 / 这页东西 | 指代一份具体材料却用虚空代词 | 那份材料 / 这份报告（就近具体名词） |
| 他们不是接小案，他们是替人把小案压下去，最后不了了之 | 说明文式对仗 + 成语收尾，像旁白在解释逻辑而非活人开口 | 改带情绪/具体画面的口语，如「他们哪是接小案子啊，分明是帮人把事按下去，完了就没人提了」 |
| 他们现在最想让我们先跟着这句'饮酒'跑。越想让我跑，越说明这句最虚 | 抽象隐喻动词"跑=追查线索" + 浮空抽象形容词"最虚"给事定性，不接地气，不像活人开口 | 改具体接地气口语，如「他们现在最想把我们往这句'饮酒'上带。越是把我们往这儿赶，越说明他们手里没别的招了——除了咬死'饮酒'，他们挡不住我们。」（仅换"最虚→最没底"会因果拧反，须顺"鼎衡死咬饮酒=别处没招"重排递进） |

> 规律：本书自然度问题多是"虚空代词指代手边具体物"（那页东西/这页东西），真人会直接叫出物名。扫台词优先查"代词+无清楚 antecedent"。另一类高频是"对称对仗的定性台词 + 成语收尾"（见第 4 类），读起来像作者旁白而非角色说话；还有一类是"抽象隐喻动词 + 浮空抽象形容词"（见第 5 类），用"跑=追查"这类概念动词、单甩"虚/空"这类浮空形容词，不像活人说话；还有一类是"点题式 / 扁平说理金句"（见第 6 类），角色用工整的"论点句+理由句"向读者宣讲可脱离剧情成立的主旨，词表与正则全盲，只能靠语义通读复核。三类扫台词时一并查。

## 边界（不误杀，不要报）

- **角色身份使然的正式腔**：公司代理、对方律师、公权力机构在正式场合（法庭、书面答复、正式谈判、听证）说的正式立场，用正式词（贵司所称/并非/客观上/依据/予以）是专业身份使然，**不报**。
- **这玩意儿就近有清楚指代**：如指着某份材料/某个设备说"这玩意儿"，属口语自然，**不报**。
- **文学性叙述语言（非台词）**：叙述/心理描写里的书面表达不在此 skill 范围，**不报**。
- **正常法律动词**：立案/举证/保全/答辩等，读者从语境能懂，**不报**。
- **本书文学隐喻**：裂痕/壳等非台词描写，**不报**。

## 三层扫描法（逐层做，缺一不可）

### 第 1 层：已修判例复扫（必须 0 命中）
Grep 全正文目录，确认历史违规已清零：
```
那页东西|这页东西|页东西|拆干净
```
任何命中都直接报（历史回归），定位到 章节:行号。

### 第 2 层：书面腔词根 + 模糊指代代词 定向 Grep
对下列词根做 Grep（带 `-C 1 -n`），命中后 **Read 上下文逐条判**"是不是真人在说、有没有清楚指代"。这些词出现在台词（引号内）且非正式场合才重点看：

- 书面腔词根：予以 | 进行(处理|调查|沟通|说明|核实) | 实施(该|上述) | 并非 | 实则 | 换言之 | 某种程度 | 值得一提的是 | 不可否认 | 经由 | 透过 | 乃是 | 方才 | 未曾 | 颇为 | 甚是 | 其一 | 其二 | 此番 | 故而
- 模糊指代代词（最该报）：那页东西 | 这页东西 | 那玩意 | 这玩意儿 | 那事 | 这事 | 那档子事 | 那桩事

> 第 2 层只缩小范围，命中不代表违规——必须 Read 上下文判：是台词还是叙述？是正式场合还是日常？代词有没有就近清楚 antecedent？

### 第 3 层：只读子代理通读（兜底语义盲区）
第 1–2 层是词表下限，抓不到词表外的别扭台词。派一个 **只读子代理** 通读全部章节，按下方提示词做语义判定。这是本 skill 的主力兜底层。

子代理提示词（直接复用，注意 general-purpose 类型偶发瞬时失败，可改 Explore 重试）：
```
你是一个只读的中文小说文本审查代理。任务：通读一本现代律政题材网络小说的全部正文，专门找出对话/台词里"真人不会这么说话"的自然度问题（不是黑话定义问题，而是口语不自然、别扭、读者会想"谁会这么说"），只报确有问题的。
文件范围：<正文目录，只审 第XXX章_*.md，跳过目录.md/大纲>。
核心判定：把这句台词换成普通人在那个场面、对着那个人会怎么开口？真人会带具体指代、用短句、顺着对方话说；原文却用模糊指代/书面词/别扭搭配，就是问题。
重点六类：1) 模糊指代（那页东西/这东西/那玩意/那事/这事等虚空代词，无就近清楚 antecedent）；2) 书面腔混进口语（予以/并非/实则/方才/透过…）；3) 别扭动宾/搭配（参照判例：拆干净→拆了、那页东西→那份材料）；4) 说明文式对仗/解释逻辑不表态度（对称工整的「不是X，是Y」式定性句、成语收尾给事定性，像旁白解释逻辑而非活人开口——真人会带情绪/具体画面/口语短句，不会冷静自我对称纠正）；5) 抽象隐喻动词+浮空抽象形容词（用"跑=追查线索"这类抽象比喻动词、或单甩"最虚/空/飘"这类浮空形容词给事定性，像写者概念推演而非活人开口——真人用具体接地气动词带/耗/钻和具体评价没底/站不住脚/心里没数）；6) 点题式/扁平说理金句（角色用一句可脱离剧情成立的"道理/格言/书的主旨"向读者宣讲，而非在具体场景说具体的话；典型为工整的"论点句+理由句"两句，常用词、无禁用词、无对称对仗、无浮空形容词——抽掉角色名和场景后仍是"成立的人生道理"而非"有用的具体话"，即违规倾向，标通读复核不机械删）。
不要报：角色身份本就该正式（公司代理/律师/法官说贵司所称/并非/客观上/依据等）；这玩意儿就近有清楚指代；文学性叙述语言（非台词）；正常法律动词；活人真的就事论事讲道理/总结经验、且非脱离剧情的主旨宣讲（如老警察随口传授办案经验的具体教训）。
输出：只读不改；中文 700 字内，按"章节:行号"列确有问题的每处（原文短摘+为什么真人不会这么说+建议改法）；通读全部章节；最后一句总结数量（0/少量/较多）。
```

## 工作流程

1. 确认扫描目标：默认扫当前书 `正文/` 全卷；可指定单卷/单章。
2. **第 1 层** Grep 已修判例 → 若有命中，记录为历史回归。
3. **第 2 层** 对书面腔词根 + 模糊指代代词 Grep → 命中处 Read ±3 行判留/清（注意台词 vs 叙述、正式场合 vs 日常、代词有无清楚 antecedent）。
4. **第 3 层** 派只读子代理通读全本，按提示词判结构性违规。
5. 汇总：分「确认违规 / 边界待定」两类，附 章节:行号 + 原文 + 建议改法。
6. **默认 report-only**：不擅自改正文。用 AskUserQuestion 让用户选「全改 / 只改确认违规 / 只改指定处 / 不改」。
7. 改：单处用 Edit；每处先校验 old 串唯一再写回。改完 Grep 验证目标 pattern 0 残留。
8. 写/更新项目 `.workbuddy/memory/YYYY-MM-DD.md` 工作日志。

## 判定原则（区分 违规 vs 可接受）

- **违规**：台词模糊指代无 antecedent、非正式场合冒书面腔、动宾搭配别扭、用对称对仗的定性句/成语收尾向读者解释逻辑而非表达态度、用抽象隐喻动词/浮空抽象形容词概念化表达而非具体接地气的动作/评价、用工整的论点句+理由句向读者宣讲可脱离剧情成立的主旨（点题式金句） → 改具体指代 + 口语短句 + 带情绪/具体画面 + 接地气动词与评价 + 落到具体场景的话（不念主旨）。
- **可接受**：角色身份使然的正式腔、就近有清楚指代的口语、叙述语言、正常法律动词 → 留。
- **改前必读上下文**：Grep 命中务必 Read 那行 ±3 行，确认是台词还是叙述、场合正式与否、代词有无 antecedent，再决定。误清会伤 voice。
- **小修大不动**：本书此类问题通常极少（75 章仅 2 处历史违规），发现即外科手术式单点修，不批量重写。
- **改写纪律：换词必查因果方向 + 顺链核后续**：为去 AI 味替换台词时，不能只把浮空/书面词换成接地气词、却保留原因果结构——新词与旧逻辑打架会引入回归。例：Ch008「越想让我跑，越说明这句最虚」改「越盼着我们往这儿钻，越说明他们自己在这句上最没底」，"最没底"虽接地气却与"往这带"因果拧反（对手不会在自己最心虚的点上主动引你），最终顺"鼎衡死咬饮酒=别处没招"重排递进才通。三查：① 替换后因果方向对不对（谁因谁果、谁主动谁被动，是否被新词拧反）；② 递进/转折是否仍成立（"越X越说明Y"里 X、Y 是否真有该递进）；③ 顺前后文链核一遍（前句说什么、后句接什么、后续章节是否验证该判断）。详见 `创作偏好.md`「改写纪律」条。

## 可调项

- 书面腔词根表按项目世界补：新题材（古言/医疗/玄幻）有各自书面表达，加到第 2 层。
- 新增判例：发现新的自然度违规，补进「已知已修判例」表，并同步回 `创作偏好.md`。
- 子代理提示词可随判定口径收紧/放宽（如把"正式腔不报"收紧为"全文统一口语"）。
