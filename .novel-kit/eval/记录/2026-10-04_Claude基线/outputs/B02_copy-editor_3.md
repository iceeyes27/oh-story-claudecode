## 阅读理解摘要

- **时间与地点**：傍晚，大礼堂的赫奇帕奇长桌。
- **人物**：加文、爱丽丝、姜小满、埃德蒙、一个格兰芬多红发高年级男生、斯内普、邓布利多、小精灵。
- **经过**：
  - 晚餐上来了。这次没有水煮卷心菜，赫奇帕奇桌中央放着三大银盆红亮的肉丁（鸡肉），旁边架着一口还在翻滚的小坩埚。
  - 加文和爱丽丝开始抢着吃。香味传开后，别的学院也来要，十分钟里半个礼堂的人在赫奇帕奇桌后排起了队。
  - 姜小满盛菜时看见锅底压着一张黄纸，露出一角符线。她怀疑地看向在一边喝汤的埃德蒙。
  - 斯内普从侧门进来，盯着那口坩埚，指责“霍尔特先生”用魔药器皿煮内脏。埃德蒙从第45段起才被点明是答话的人，读者据此推定他就是霍尔特。埃德蒙说锅是自费买的备用锅，又拿“控温”和“物尽其用”来回应。
  - 斯内普的目光移向锅底时，邓布利多来了，拈起一块鸡肉，问斯内普要不要来一碗。斯内普拒绝，并警告下次再犯就扣学院二十分，然后离开。
- **结尾状态**：邓布利多留下来，弯腰看锅底露出的黄纸，什么也没说，端着一小碗鸡肉走了。黄纸至少被姜小满、斯内普（可能）和邓布利多看到。
- **不确定处**：
  - 从第31段起，场景像是突然到了厨房（出现操作台、小精灵、面粉袋），在场地点读不准。
  - “霍尔特”是谁，要到第45段才能确认。
  - 邓布利多手里的“一小碗鸡肉”是从哪来的，正文没写。

## 前文不足/供给待核

1. **“这一次没有水煮卷心菜的酸气”**（第3段）：“这一次”说明之前有过一顿卷心菜晚餐，可能是一个反复出现的情节。没有给前文，无法判断读者是否已经知道。需要补读：前一场完整原文，以及前文写到礼堂伙食的段落。
2. **“锅底压着的那张黄纸露出的符线一角”**（第25段）、**“那张黄纸的边角”**（第67段）：“那张”是定指，说明黄纸前文可能交代过来历（谁放的、做什么用）。需要补读：黄纸或符纸初次出现的原文。在补读之前，我不把它当作正文缺漏。
3. **姜小满“带着狐疑”看向埃德蒙**（第25段）：她为什么怀疑埃德蒙，取决于两人之前的关系，以及她认不认得符线。需要补读：姜小满与埃德蒙相关的前文。
4. **“霍尔特先生”是谁**（第33、63段）：正文要到第45段才靠“埃德蒙的语气”让读者把霍尔特和埃德蒙对上。如果前文已经交代过埃德蒙姓霍尔特，这里就没有问题；如果没交代过，第33～43段读者会停顿。需要补读：埃德蒙全名首次出现处。
5. **“昨晚刷过三遍”“学生自费买的备用锅”**（第39段）：如果坩埚的购买、清洗在前文写过，这里只是照应；没写过也不影响当场理解。暂不定级。
6. 人物加文、爱丽丝、姜小满、埃德蒙都没有出场介绍，属于正常的承前人物，只要前场交代过就没问题。由于没有前文，无法核对。

## 保留项

| 原句 | 理由 |
|---|---|
| “你用熬制魔药的器皿，煮牲口的内脏。” | 菜其实是鸡肉，但这是斯内普刻意贬损的夸张说法，属于保护清单中“人物刻意的错误、夸张、贬损”，不算事实冲突。 |
| “不知道！”加文一勺子下去把盘子堆成小山，“抢了再说！” | 口语化短句，说话者明确，节奏合适。 |
| “不分！拿布丁换都不换！” | 口语省略和夸张符合学生抢饭的身份。归属的小问题已列在 CE-4，口语本身不改。 |
| “加文猛地弹起来。”／“侧门开了。”／“门在身后合上。” | 单句短段，与文风样本“短段、实物和动作带出压力”一致（例如“门轴一声轻响，先钻进鼻子的不是饭香。”）。 |
| “没有人喊，可那一片的动静自己矮了下去。” | 用“矮了下去”写嘈杂声低下来，属于特色写法，含义清楚，顺读不受影响。 |
| 第43～47段：埃德蒙的台词被“埃德蒙的语气温和得挑不出毛病。”隔成两段 | 同一说话者的话中间插一句叙述，文风样本中格里普斯的对白也是这样分段，说话者没有歧义。 |
| “斯内普的目光往锅底挪了半寸。” | 用动作暗示他注意到了黄纸，属于合理留白，不要求挑明。 |
| “他看了很久，什么也没说，端着一小碗鸡肉慢慢走了。” | 收尾留白，合理；碗的来历另列在 CE-2。 |
