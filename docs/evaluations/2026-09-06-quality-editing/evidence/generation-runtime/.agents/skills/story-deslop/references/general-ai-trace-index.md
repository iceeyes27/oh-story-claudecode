# 通用文本 AI 痕迹索引

本索引用于 `mode=general` 的渐进读取。它是 `advisory` 审稿导航，不是确定性扫描器，也不要求把所有命中项清零。

## 使用方式

- `rewrite`：只有需要深查时才打开本索引，定位问题族后只读取对应细则。
- `review`：先定位高置信问题，再补充上下文型问题；最终只报告 Top 5-10。
- `translation`：不读取本索引，执行 [翻译保护规则](translation-guardrails.md)。

## 问题族导航

| 优先级 | 问题族 | 细则 |
|---|---|---|
| 高置信 | 模型身份、知识范围、协作过程进入成稿 | [模型与协作元话语](general-ai-trace-guide.md#1-模型与协作元话语) |
| 高置信 | 引用、研究、行业共识没有可核查来源 | [无源归因与伪引语](general-ai-trace-guide.md#2-无源归因与伪引语) |
| 结构型 | 段落反复采用相同起承转合 | [结构同构与提纲感](general-ai-trace-guide.md#3-结构同构与提纲感) |
| 结构型 | 结尾重复总结、拔高或宣传 | [空总结与宣传式拔高](general-ai-trace-guide.md#4-空总结与宣传式拔高) |
| 上下文型 | 为显得清楚而制造虚假的二分关系 | [二元对照与工整逻辑](general-ai-trace-guide.md#5-二元对照与工整逻辑) |
| 上下文型 | 用“分析”“揭示”等动作代替具体论证 | [分析动作与戏剧化判定](general-ai-trace-guide.md#6-分析动作与戏剧化判定) |
| 上下文型 | 抽象术语、包装性比喻遮住事实 | [抽象术语与比喻包装](general-ai-trace-guide.md#7-抽象术语与比喻包装) |
| 上下文型 | 大量弱限定词或主体不明 | [过度限定与模糊主体](general-ai-trace-guide.md#8-过度限定与模糊主体) |
| 格式型 | 标题、列表、强调、标点成为表演 | [格式化表演与标点混排](general-ai-trace-guide.md#9-格式化表演与标点混排) |
| 保护区 | 正式、技术或引用文本容易被误改 | [场景例外与保护区](general-ai-trace-guide.md#10-场景例外与保护区) |

## 排序规则

1. 先报会误导读者或损害可信度的高置信问题。
2. 再报反复出现、明显影响阅读的结构型问题。
3. 上下文型问题必须结合场景判断，单次出现通常不构成结论。
4. 同类问题合并举例，最多给出 Top 5-10，不用逐句列举。
