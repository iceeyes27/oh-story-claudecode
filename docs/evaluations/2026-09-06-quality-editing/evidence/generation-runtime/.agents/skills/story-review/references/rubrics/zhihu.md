# 知乎盐言故事审查参考

先按 `quality-rubric.md` 确定题材、本书承诺与当前单元功能。使用作者批准的视角与篇幅；平台名称不构成第一人称、反转或每段情绪变化的硬要求。

| 观察项 | 适用时检查 | 不适用或可保留 |
|--------|------------|----------------|
| 视角与代入 | 既定视角的知识、态度和距离是否稳定，切换是否可辨 | 第三人称、多视角和角色主观判断可以成立 |
| 情绪兑现 | 变化由人物选择、处境或关系触发，承诺的回报有后果 | 克制、平稳、余波可以成立，不要求每段变化 |
| 信息与反转 | 本书确实设计反转时，揭示有前因且改变理解 | 没有反转的关系故事可记 N/A，不为达标添秘密 |
| 开头进入 | 当前人物、处境、欲望或异常使读者能进入故事 | 第一行描写有功能可保留，不以句型判跳失 |
| 结尾落点 | 本篇承诺得到准确回应，后果与已写选择相连 | 开放、封闭、反思、余韵均可，不强留悬念 |
| 格式与篇幅 | 按明确发布要求和本篇内容验证可读性与字数 | 没有明确平台要求时记录未确定，不把经验范围当规定 |

适用项用 PASS / WARN / FAIL；不适用项标 N/A 并说明原因，证据不足单列。仅作 advisory，严重度来自具体阅读损失；不从首句或反转数量推算开头跳失率。修改建议优先选择 1～2 个最高阅读损失，避免为情绪频率补停顿、粗话或无功能动作。
