# 人物弧线：从性格到变化

重要角色不是被“设定”出来的，而是在压力下反复作出选择，最后改变选择方式。

## 角色弧线卡

为主角、反派和持续影响主线的重要配角填写：

| 项目 | 要求 |
| --- | --- |
| 基础性格 | 欲望、恐惧、缺陷、外显方式；要能写成行动和台词 |
| 起点状态 | 角色目前相信什么，遇事按什么旧模式自保 |
| 转变压力 | 哪件事会让旧模式失效；失败会付出什么代价 |
| 裂缝 | 他开始怀疑旧信念，却仍抗拒改变的具体表现 |
| 关键选择 | 在高代价处选择新做法，而不是重复旧模式 |
| 新习惯 | 结尾再次遇到同类压力时，用行动证明变化稳定 |

反派也需要弧线：可以在压力下坚持旧信念并坠落，但必须让读者看见他拒绝改变的理由和代价。

## 五阶段

`未触发 → 受压 → 裂缝 → 选择 → 新习惯`

- **未触发**：用一次冲突展示旧模式，不解释标签。
- **受压**：旧模式第一次造成真实损失。
- **裂缝**：角色意识到问题，但仍做出半步后退或自我辩解。
- **选择**：面对更高代价时，主动选择不同做法。
- **新习惯**：安排与起点相似的压力，展示新选择已成为本能。

阶段可以跨多章停留，但不能跳级。每次推进都必须有本章冲突造成的原因。

## 章节落地

在大纲和 `02-写作计划.json` 中为每个弧线节点写：角色、阶段、可见证据。证据只能是以下形式：

- 关键选择：救谁、相信谁、放弃什么、承担什么。
- 可见动作：把旧习惯改成新动作，或在相同刺激下作出不同反应。
- 现实代价：失去机会、关系受损、承担责任、计划失败。

不要把“他成长了”“她终于释然”当作证据。用后续场景验证；角色不出场，阶段不更新。

## 快速检查

- 每个重要角色是否有一条与基础缺陷直接相关的变化？
- 起点和终点是否能用两场相似压力下的不同选择对照？
- 每次转变是否先有压力和代价？
- 本章是否写出了可见证据，而非作者解释？
