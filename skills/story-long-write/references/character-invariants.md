# character-invariants.md：角色不变量

角色不变量用于控制长篇连载中的动机漂移、认知泄漏和口吻突变。它是**负向约束**——记录角色绝不会做什么、当前不能知道什么——补充角色档案，不替代角色档案。属于「长篇稳定性验收」机制的一部分（总览见 `longform-stability.md`）。

**与既有文件的分工**：

| 文件 | 记录什么 | 回答什么问题 |
|------|---------|-------------|
| `设定/角色/{角色名}.md` | 人物基础信息（外貌、背景、性格、动机） | 这个角色是谁 |
| `追踪/角色状态.md` | 当前状态快照（身份、能力、关系、位置） | 这个角色现在怎么样 |
| `设定/角色不变量/{角色名}.md` | 稳定性边界（红线、禁知、语言边界） | 这个角色**绝不会**怎么样 |

## 何时建立

- 启用长篇稳定性验收时（正文超过 10 章自动启用），先为主角、主要反派、核心配角各建一份。
- 新角色开始承担连续剧情功能（多章出场、持有关键信息）时补建。
- 角色经历重大转折（黑化、身份揭露、认知升级）后更新。

一次性路人不建。写入位置固定为 `设定/角色不变量/{角色名}.md`，文件名必须用角色在正文中的称呼（脚本按文件名扫描正文）。

## 模板

```md
## 角色不变量：{角色名}

### 底层欲望
- {驱动一切行为的根本欲望，全书基本不变}

### 当前阶段目标
- {当前卷/阶段在追求什么}

### 行为红线
- 不会：{正文可字面匹配的具体行为短语}
- 除非：{触发例外的前置事件；无则写"无"}

### 认知边界
- 当前知道：{已掌握的关键信息}
- 当前不知道：{尚未掌握的关键信息}
- 不能提前知道：{正文可字面匹配的禁知短语}

### 语言边界
- 常用表达：{口头禅、称呼习惯}
- 不会使用的表达：{与身份/时代/性格冲突的词}

### 可变化区域
- 可成长：{允许变化的方向}
- 可误判：{允许犯的错}
- 可被迫妥协：{允许在压力下让步的事}
```

## 可 grep 格式规则（脚本依赖，必须遵守）

`node scripts/stability-audit.js` 会对「行为红线」的 `不会：` 行和「认知边界」的 `不能提前知道：` 行做**字面匹配扫描**——短语出现在该角色的扫描视野内即报错。因此：

1. **写具体短语，不写抽象概括**。`不能提前知道：陈叔的转账记录` 可以被 grep；`不能提前知道：幕后真相` 扫不出任何东西（正文不会出现"幕后真相"四个字）。选正文一旦泄漏就必然出现的词：人名+物件、地点、数字、专名。
2. **一行一条**，冒号后只放一个短语。多条禁知写多行 `- 不能提前知道：`。
3. 短语里不要带标点和空格，避免匹配碎裂。
4. 允许误报侧倾斜：这个检查是"宁可误报、人工豁免"，扫出命中后先判断是否真泄漏（例如叙述者视角提及但角色本人不知情，可用 POV 标记隔离，见下节）。

| 风险 | 触发行 | 错误码 |
|------|--------|--------|
| 角色知道了不该知道的信息 | `不能提前知道：X` 且 X 出现在其视野 | `Knowledge_Leak` |
| 角色越过行为红线 | `不会：X` 且 X 出现在其视野 | `Motivation_Drift` |
| 行动不符合底层欲望/阶段目标 | （LLM 门控审查，脚本不判） | `Motivation_Drift` |
| 语言风格突变且非剧情所需 | （LLM 门控审查，脚本不判） | `Motivation_Drift` |

## 多角色 / 多 POV 扫描视野

正文可以用显式 POV 标记限定后续段落的视角归属：

```md
## POV：江临

江临只知道任务文本有异常。

## POV：沈岚

沈岚根据自己的线索做出判断。
```

脚本按角色生成扫描视野：

- 没有 POV 标记的章节，按全章检查所有角色不变量。
- 出现 `POV：角色名` 或 `视角：角色名` 后，该段落只纳入对应角色的检查视野。
- 首个 POV 标记之前的公共叙述，所有角色都视为可见。
- 某角色 POV 段落里出现**另一角色**的禁知词，不判定后者泄漏；必须出现在后者自己的 POV 或公共叙述中才触发。

POV 标记是可选的：单视角流水正文不需要加；只有多 POV 且禁知词会在他人视角合法出现时才用它隔离。

**POV 标记与成稿纯净度**：`## POV：角色名` 是写作工程标记，与「正文元信息隔离」原则同源——它可以留在项目内的正文文件里供审计，但**不属于发布内容**。默认不使用：单视角项目直接全章扫描；多视角项目优先靠"公共叙述里不写他人禁知词"来隔离，确实做不到再加标记。发布/导出时用副本删除标记行，项目内文件保留标记（删了标记再跑审计会退回全章视野，可能出现需人工豁免的误报）。

## 更新规则

- 角色成长可以改变「当前阶段目标」，不能无说明地改写「底层欲望」。
- 「认知边界」只能因为正文中的事件、对话、调查、传承、误导而变化——正文哪一章解锁了哪条认知，更新时在行尾注明（如 `当前知道：陈叔的转账记录（第 041 章解锁）`）。
- 更新不变量时，必须在当章漂移门控的 State Delta 里记录原因（见 `longform-stability.md`「漂移门控」）。
- 回炉修改正文导致认知时间点变化时，同步回改不变量，再重跑稳定性审计。
