# 第002章 这边放鱼

## 章节契约

- 来源细纲：大纲/细纲_第002章.md
- 最终正文字数目标：2500 字
- 目标情绪：温情；护短争执，转为能一起做事的松快
- 读者获得：看见鱼箱和食材取用的实际矛盾如何化解；钱付明白后，彼此从顶嘴变为搭手。
- 禁止提前释放：不修好冷柜，不收尾款，不追加维修收费，不恶人化店主；临存限定30元且傍晚前搬走。
- 开场动作：承接包子铺门口，小满向陈望提出借冷藏位置。
- 章尾钩子：父亲来电准备给建议，小满先说自己已安排好保货与待修，他听完让她照自己的判断做。

## 场景 1

- 时空与人物：上午，包子铺后间；小满、何桂香、陈望
- 场景目标：谈到双方愿意执行的临存办法
- 阻力：陈望怕串味和取馅受挡；何桂香把鱼味听成贬低货物
- 动作链：请求借位 -> 陈望拒绝混放 -> 何桂香护货顶嘴 -> 小满问位置与取用时间 -> 何桂香取来干净密闭空箱 -> 陈望验箱指定位置 -> 三人定价限时
- 结果变化：陈望同意在指定位置临存，何桂香付三十元并接受傍晚前取回
- 情绪转折：彼此不肯退话 -> 条件有实物可验证
- 信息/伏笔：只用鱼摊自备干净密闭周转箱；与包子铺食材分开
- 台词意图与潜台词：陈望说明自己要用的位置；何桂香证明箱子干净，不肯被说货臭；小满改用具体问题，避免当调解老师
- 正文字数预算：1400 字

## 场景 2

- 时空与人物：上午，鱼摊与包子铺之间、修理铺门口；小满、何桂香、陈望；周建国电话
- 场景目标：落实存放，确认后续修理准备，独立接住父亲关心
- 阻力：搬运空间有限，陈望仍需拿到自己的食材；小满容易习惯向父亲求决定
- 动作链：密封装箱 -> 三人搬四箱并清点 -> 何桂香发现挡取馅路线主动转箱 -> 陈望帮扶说实在话 -> 关柜保货 -> 小满确认配件 -> 接父亲电话说出已做好安排
- 结果变化：鱼货暂时保住，三人由争嘴转为合作；父亲尊重她的独立判断
- 情绪转折：紧绷算账 -> 搭手后放松 -> 能独立负责的踏实
- 信息/伏笔：四只周转箱仅作这批货的清点单位；供货电话不增加新出场角色
- 台词意图与潜台词：陈望的笑话来自拿馅和鱼箱，不嘲讽；父亲准备叮嘱后改为听，小满不报流水账
- 正文字数预算：1100 字
