## G04 最小隔离复现

执行者：guide_state_logic。采用 Python -B 载入当前 novel.py，在两个独立临时书稿目录比较 confirm-plan 与 rebind-plan；未修改仓库或实际书稿，结束后清理临时目录。以下保留执行者返回的操作和关键结果。

两组共同步骤：

1. 创建空状态表和含连续场景 01、02 的第一章细纲。
2. 执行 confirm_plan(root, 1)，再 begin(root, 1, 1)，写入非空首场候选。
3. 使用测试原因和模拟授权撤回首场。
4. 确认所有场景和收尾均为未开始，首场 withdrawals 数量为 1。
5. 修改细纲，仅保留场景 01，删除尚未开始的场景 02。
6. 分别执行 confirm_plan，或带模拟授权的 rebind_plan。

| 观察项 | confirm-plan | rebind-plan |
| --- | --- | --- |
| 是否允许 | 是 | 是 |
| 首场撤回历史数量，操作前 | 1 | 1 |
| 首场撤回历史数量，操作后 | 0 | 1 |
| 第二场状态行仍存在 | 否 | 否 |
| 首场候选保持不变 | 是 | 是 |
| 撤回日志仍存在 | 是 | 是 |

已复现 confirm-plan 丢弃状态行撤回历史。未复现删除已开始场景的绕过；两种操作删除的都是尚未开始的场景 02。连续编号仍要求保留场景 01。该问题在本次指引整理中未修复。
