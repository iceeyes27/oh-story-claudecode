# 新增长篇章节骨架模式

## Goal

把 `story-write long` 的默认章节产物从成品正文改为可执行的章节骨架。项目负责设定、大纲、细纲、场景设计与连续性验证；最终遣词造句由作者或独立写作模型完成，确认后的正文才进入正稿并推进追踪。

## Background

- 当前开书流程已默认停在 Phase 3，不自动生成正文。
- 当前 Phase 4 仍以生成成品正文和扫描 AI 句式为主；确定性扫描只能发现已登记模式，不能证明正文自然。
- 已有候选系统提供“作者采用后才推进追踪”的机制，但当前主分支把候选目录从书根 `候选/` 改回 `正文/候选/`，同时移除了采用前质量检查，导致 `scripts/test-candidate-commit.py` 13 项中 10 项失败。

## Requirements

### R1 默认章节骨架

- 长篇场景中，“写第 N 章”“续写”“继续写”“日更”默认生成章节骨架，不生成成品正文。
- 只有明确包含“成稿”“最终正文”“直接写正文”等意图时，才进入成品正文流程。
- 短篇流程不变。

### R2 骨架产物与边界

- 骨架保存为 `{书名}/骨架/第NNN章_章名.md`，不得放入 `正文/`。
- 骨架必须包含章节契约、3～6 个场景卡、细纲覆盖表和扩写约束。
- 场景卡只写目标、阻力、动作链、结果变化、情绪转折、信息或伏笔、台词意图与潜台词、最终正文字数预算；不得写成连续叙事段落或完整台词。
- 骨架不得推进 `_tracking-state.json`，不得生成逐章追踪事务。

### R3 确定性骨架验证

- 新增独立脚本验证骨架的文件命名、必需章节、场景数量、场景字段、细纲覆盖和字数预算。
- 阻断项返回非零退出码；完整台词等可疑内容作为提示，不声称已经判断文风自然。
- 验证器必须有正常、缺字段、场景数量越界、预算不一致和未覆盖细纲项的回归测试。

### R4 流程状态

- `flow-state.js` 能区分“需要生成骨架”“骨架待扩写”“候选正文待审”三种状态。
- 书根 `候选/` 与 `骨架/` 不得被计入已完成正文章号。
- 只有正稿 `正文/` 中的正式章节可以推进下一章检测。

### R5 外部成稿接入

- 作者或独立模型完成的正文进入书根 `候选/`。
- 项目先核对骨架覆盖、连续性、标题、字数和确定性扫描结果，再根据实际正文构造追踪事务。
- `candidate-commit.py promote` 成功后正文才进入 `正文/`，追踪才推进。

### R6 候选系统回归修复

- 恢复书根 `候选/` 目录契约，避免写后 Hook 和递归章节扫描把候选误认为正稿。
- 恢复采用前 `check-ai-patterns.js` 与 `check-degeneration.js` 阻断检查及显式跳过参数。
- 保持 promote 失败时正文移回候选、追踪不推进的可重试语义。

### R7 检查结论边界

- 正文扫描结果只能表述为“已知确定性模式未发现阻断项”，不得据此声称“无 AI 味”或“文风自然”。
- 骨架阶段不运行正文 AI 词句扫描，只运行结构验证。

### R8 兼容与发布边界

- 不新增 `story-long-*` Skill，不修改短篇流程，不修改 narrative-writer agent，不提升 `agents_version`。
- 只编辑 `.agents/skills/` 指向的规范 Skill 源及本仓库测试、Trellis 任务文件；平台 Skill 入口由适配工具维护。
- 不创建 GitHub Actions。

## Acceptance Criteria

- [x] AC1：长篇“写第 1 章”在存在细纲与追踪时生成 `骨架/第001章_*.md`，`正文/` 与 `_tracking-state.json` 不变。
- [x] AC2：骨架包含 3～6 个完整场景卡，场景字数预算总和等于章节目标，验证脚本返回 0。
- [x] AC3：缺字段、场景数量越界、预算不一致或细纲覆盖项未完成时，验证脚本返回非零并指出文件与问题。
- [x] AC4：`flow-state.js` 在无骨架、已有骨架、已有候选三种状态下分别返回 `write_chapter_skeleton`、`expand_chapter_skeleton`、`review_candidate`。
- [x] AC5：书根 `候选/` 与 `骨架/` 不改变正式章号；正式正文仍能推进下一章。
- [x] AC6：候选系统 13 项既有回归测试全部通过，采用前质量检查与失败回滚有效。
- [x] AC7：Skill 契约明确扫描能力边界，不再把扫描通过等同于自然文笔。
- [ ] AC8：Skill 快速验证、流程状态测试、骨架验证测试、候选测试、当前契约检查、静态检查和适配检查通过。

AC8 例外：仓库权威静态检查、流程、骨架、候选、契约、部署与适配检查均通过；通用 Skill Creator 验证器不接受仓库既有 frontmatter 扩展字段，统一 Skill 上游漂移属于本次执行期间出现的独立同步变化。

## Out of Scope

- 自动调用外部写作模型或接入新的模型 API。
- 让确定性扫描器判断所有上下文相关的 AI 文风问题。
- 修改短篇写作流程、Dashboard 或浏览器界面。
- 新建 CI 工作流。
