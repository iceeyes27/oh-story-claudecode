| 回避问话：“‘坐一会儿就行，你们忙。’亚瑟看向灶边。”以及“埃德蒙没问，转身去拿灶旁的空铜壶。” | 前者把疼痛话题转向家务，后者把儿子的反应落实为行动。“没问”交代这次交流选择，没有替双方展开解释。 |
| 添火：“母亲这才停下揉面的手，往灶膛里添了一截柴。火苗往上蹿了蹿，她转回身，继续揉面。” | 停手、添柴、恢复家务构成完整协作动作；揉面重现标明母亲回到原先的事情，并非原地重复。 |
| 收尾：“父亲还伸着左腿，正把坐皱的衣摆一点点抻平。”随后“过了一会儿，铜壶里的水开始细细作响。” | 前一句补出父亲等待时整理衣服的动作，也维持伤腿姿势；壶声交代等待经过，符合样本以实物与动作承压的节奏，没有总结人物意义。 |

### 保留项

| 接包：“‘给我吧。’”“亚瑟的胳膊松了松。”“‘也没多沉。’” | 短对白与动作完成接包，同时保留父亲淡化负担的语气。省略和短段均有现场功能，不需要补齐书面句式。 |
| 准备落座：“把桌旁的椅子拉开，腾出父亲放腿的地方，再回去扶住他。” | 椅子与腿的空间安排为之后伸腿落座提供行动前提，不能因动作细致就判累赘。 |
| 跨门槛：“父亲嘴上这么说，手却搭到了他肩头。左脚跨门槛时，那只手忽然压重了。” | “嘴上……却……”把口头坚持与实际需要帮助连接起来，手的压力进一步定位跨门槛时的困难；不是无功能套用对照句式。 |
| 落座：“右脚收到了椅子底下，左脚却留在外头。他的手仍按着左膝，不敢再弯。”随后“‘就这一下疼。’” | 两脚位置区分正常收腿与伤腿伸直，按膝及不再弯腿说明当下回避疼痛的状态；对白又表现父亲缩小问题的说法。这里没有把不同动作压成重复情绪标签。 |
| 提壶：“空壶轻，一提就起来了。”随后“水添进去，手上也有了分量。” | 前后分别交代空壶与注水后的重量变化，信息发生了改变，不能仅因均写重量而合并判重复。表达仍依附取水动作。 |
| 母亲添火：“‘往旁边站站。’”“埃德蒙让开一步。她往灶膛里添了两块煤，拨了拨火，又回去揉那团面。” | 口语指令、让位及添煤形成明确动作承接，母亲的照料通过处理眼前家务呈现，没有额外的情绪解读。 |
| 收尾：“父亲还伸着左腿，扶在椅边的手松开了。”以及“铜壶里的水，开始细细地响。” | 伸腿维持尚未消退的不适，松手提供坐稳后的状态变化；壶声收束等待动作。短句与停顿可由样本短段及实物节奏支持，不因处在结尾就判总结腔。 |
